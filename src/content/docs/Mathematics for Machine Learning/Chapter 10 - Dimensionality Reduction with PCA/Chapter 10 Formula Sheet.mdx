## §10.1 Problem setting

| what | equation |
| --- | --- |
| data covariance matrix | $\mathbf{S} = \frac1N\sum_n\mathbf{x}_n\mathbf{x}_n^\top$ — **10.1**, **mean $\mathbf{0}$ assumed** |
| the code | $\mathbf{z}_n = \mathbf{B}^\top\mathbf{x}_n \in \mathbb{R}^M$ — **10.2** |
| the projection matrix | $\mathbf{B} = [\mathbf{b}_1,\ldots,\mathbf{b}_M] \in \mathbb{R}^{D\times M}$, orthonormal columns — **10.3** |
| the reconstruction | $\tilde{\mathbf{x}} = \mathbf{B}\mathbf{B}^\top\mathbf{x} \in \mathbb{R}^D$ |
| the layout | $\mathbf{X} \in \mathbb{R}^{D\times N}$ — data points are the **columns** |

:::caution[Equation 10.1 is a covariance only if the mean is zero]
Applied to raw data it exceeds the covariance by $\boldsymbol\mu\boldsymbol\mu^\top$ — measured to
$5.7\times10^{-14}$. On the digit-"8" images that inflates the trace from $741.158872$ to $4020.390805$,
a factor of $5.4245$, and swings the leading direction $87.9996^\circ$ onto the **mean image**
($0.2851^\circ$ from it).
:::

## §10.2 Maximum variance perspective

| what | equation |
| --- | --- |
| variance of the first coordinate | $V_1 = \frac1N\sum_n z_{1n}^2$, $z_{1n} = \mathbf{b}_1^\top\mathbf{x}_n$ — **10.7**, **10.8** |
| in matrix form | $V_1 = \mathbf{b}_1^\top\mathbf{S}\mathbf{b}_1$ — **10.9b** |
| the constrained problem | $\max\ \mathbf{b}_1^\top\mathbf{S}\mathbf{b}_1$ s.t. $\lVert\mathbf{b}_1\rVert^2 = 1$ — **10.10** |
| the Lagrangian | $\mathfrak{L} = \mathbf{b}_1^\top\mathbf{S}\mathbf{b}_1 + \lambda_1(1-\mathbf{b}_1^\top\mathbf{b}_1)$ — **10.11** |
| stationarity | $\mathbf{S}\mathbf{b}_1 = \lambda_1\mathbf{b}_1$ — **10.13** |
| **the variance kept** | $V_1 = \lambda_1$ — **10.15** |
| the deflation | $\hat{\mathbf{X}} = \mathbf{X} - \sum_{i<m}\mathbf{b}_i\mathbf{b}_i^\top\mathbf{X}$ — **10.17** |
| shared eigenvectors | $\hat{\mathbf{S}}\mathbf{b}_m = \mathbf{S}\mathbf{b}_m = \lambda_m\mathbf{b}_m$ — **10.21** |
| used-up directions | $\hat{\mathbf{S}}\mathbf{b}_i = \mathbf{0}$ for $i<m$ — **10.22** |
| total kept, total lost | $V_M = \sum_{m\le M}\lambda_m$, $J_M = \sum_{j>M}\lambda_j$ — **10.24**, **10.25** |

:::tip[The eigendecomposition prices every choice of M at once]
$\mathbf{b}_m^\top\mathbf{S}\mathbf{b}_m$ against $\lambda_m$, first six components: largest gap
$8.5\times10^{-14}$. **No projection has to be formed** to know how much variance a component keeps.

Searching for the maximum instead: $200{,}000$ random unit vectors in $\mathbb{R}^{64}$ reach
$56.351776$, which is $37.18\%$ of $\lambda_1 = 151.568412$. Power iteration reaches it exactly in $500$
steps.
:::

## §10.3 Projection perspective

| what | equation |
| --- | --- |
| the objective | $J_M = \frac1N\sum_n\lVert\mathbf{x}_n-\tilde{\mathbf{x}}_n\rVert^2$ — **10.29** |
| the reconstruction | $\tilde{\mathbf{x}}_n = \sum_m z_{mn}\mathbf{b}_m = \mathbf{B}\mathbf{z}_n$ — **10.28** |
| **the optimal coordinates** | $z_{in} = \mathbf{b}_i^\top\mathbf{x}_n$ — **10.32** |
| the general projection | $\tilde{\mathbf{x}} = \mathbf{B}(\mathbf{B}^\top\mathbf{B})^{-1}\mathbf{B}^\top\mathbf{x} = \mathbf{B}\mathbf{B}^\top\mathbf{x}$ — **10.34** |
| the displacement | $\mathbf{x}_n - \tilde{\mathbf{x}}_n = \sum_{j>M}(\mathbf{b}_j^\top\mathbf{x}_n)\mathbf{b}_j$ — **10.38b** |
| the projector | $\sum_{m\le M}\mathbf{b}_m\mathbf{b}_m^\top = \mathbf{B}\mathbf{B}^\top$, symmetric, rank $M$ — **10.39** |
| equivalently | $J_M = \frac1N\sum_n\lVert(\mathbf{I}-\mathbf{B}\mathbf{B}^\top)\mathbf{x}_n\rVert^2$ — **10.40b** |
| as a trace | $J_M = \sum_{j>M}\mathbf{b}_j^\top\mathbf{S}\mathbf{b}_j = \mathrm{tr}\big(\big(\sum_{j>M}\mathbf{b}_j\mathbf{b}_j^\top\big)\mathbf{S}\big)$ — **10.43a**, **10.43b** |
| **the minimum** | $J_M = \sum_{j>M}\lambda_j$ — **10.44** |
| the auto-encoder | $\frac1N\sum_n\lVert\mathbf{x}_n - \mathbf{B}^\top\mathbf{B}\mathbf{x}_n\rVert^2$ — **10.76** |

:::caution[Equation 10.32 is what Equation 10.34 collapses to, and not a general formula]
The inverse factor is the identity **only** for orthonormal columns. On five columns spanning the correct
subspace but rescaled — $\mathbf{G}^\top\mathbf{G}$ off the identity by $3.84$ — the reconstruction
error is $24.728409$ against an available $16.316272$. No error is raised. `np.linalg.qr` costs nothing
and restores the guarantee.
:::

:::tip[Why Equation 10.32 is a minimum, not just a stationary point]
For orthonormal $\mathbf{B}$ and **any** $\mathbf{z}$:

$$
\lVert\mathbf{x}-\mathbf{B}\mathbf{z}\rVert^2
= \lVert\mathbf{x}-\mathbf{B}\mathbf{B}^\top\mathbf{x}\rVert^2 + \lVert\mathbf{B}^\top\mathbf{x}-\mathbf{z}\rVert^2
$$

Measured over $200{,}000$ random $\mathbf{z}$ at four scales: worst relative gap $1.7\times10^{-15}$. The
first term is what §10.3.3 minimises over bases; the second is the entire cost of not projecting
orthogonally.
:::

## §10.6 Key steps in practice

| step | equation |
| --- | --- |
| 1. subtract the mean | — |
| 2. divide by $\sigma_d$ | $x_*^{(d)} \leftarrow (x_*^{(d)}-\mu_d)/\sigma_d$ — **10.58** |
| 3. eigendecompose $\mathbf{S}$ | §10.4 |
| 4. project | $\tilde{\mathbf{x}}_* = \mathbf{B}\mathbf{B}^\top\mathbf{x}_*$, $\mathbf{z}_* = \mathbf{B}^\top\mathbf{x}_*$ — **10.59**, **10.60** |
| 5. undo the standardization | $\tilde{x}_*^{(d)} \leftarrow \tilde{x}_*^{(d)}\sigma_d + \mu_d$ — **10.61** |
| the error as a function of $M$ | $\frac1N\sum_n\lVert\mathbf{x}_n-\tilde{\mathbf{x}}_n\rVert^2 = \sum_{i>M}\lambda_i$ — **10.62** |

:::caution[Both of the failure modes in Step 2 are silent]
**Units.** Height in metres gives $\mathbf{b}_1 = [0.003887, 0.999992]$; in millimetres,
$[0.976750, 0.214380]$ — $77.3982^\circ$ apart, on data that never moved. After Step 2 three unit choices
agree to $1.2\times10^{-6}$ degrees, and the standardised covariance **is** the correlation matrix
(measured to $6.7\times10^{-16}$) with trace exactly $D$.

**A zero standard deviation.** $12$ of the $64$ digit pixels are black in every image, so Equation 10.58
computes $0/0$ — $\mathbf{2{,}088}$ NaNs, no exception.

**The wrong statistics.** Standardising a test set with its own mean and sd reports $15.400250$ where the
honest figure is $15.781992$. The leak makes the model look **better**.
:::

## §10.7 Latent variable perspective

| what | equation |
| --- | --- |
| the model | $\mathbf{x} = \mathbf{B}\mathbf{z} + \boldsymbol\mu + \boldsymbol\epsilon$, $\boldsymbol\epsilon\sim\mathcal{N}(\mathbf{0},\sigma^2\mathbf{I})$ — **10.63** |
| the generative process | $\mathbf{z}_n\sim\mathcal{N}(\mathbf{0},\mathbf{I})$; $\mathbf{x}_n\mid\mathbf{z}_n\sim\mathcal{N}(\mathbf{B}\mathbf{z}_n+\boldsymbol\mu,\sigma^2\mathbf{I})$ — **10.65**, **10.66** |
| the likelihood | $\mathbb{E}[\mathbf{x}] = \boldsymbol\mu$, $\mathbb{V}[\mathbf{x}] = \mathbf{B}\mathbf{B}^\top+\sigma^2\mathbf{I}$ — **10.69**, **10.70b** |
| the cross-covariance | $\mathrm{Cov}[\mathbf{x},\mathbf{z}] = \mathbf{B}$ — **10.71** |
| the joint | $\mathcal{N}\!\big([\boldsymbol\mu;\mathbf{0}],\ [\mathbf{B}\mathbf{B}^\top+\sigma^2\mathbf{I},\ \mathbf{B};\ \mathbf{B}^\top,\ \mathbf{I}]\big)$ — **10.72** |
| the posterior mean | $\mathbf{m} = \mathbf{B}^\top(\mathbf{B}\mathbf{B}^\top+\sigma^2\mathbf{I})^{-1}(\mathbf{x}-\boldsymbol\mu)$ — **10.74** |
| the posterior covariance | $\mathbf{C} = \mathbf{I}-\mathbf{B}^\top(\mathbf{B}\mathbf{B}^\top+\sigma^2\mathbf{I})^{-1}\mathbf{B}$ — **10.75**, **no $\mathbf{x}$ in it** |
| ML parameters | $\boldsymbol\mu_{\mathrm{ML}} = \bar{\mathbf{x}}$; $\mathbf{B}_{\mathrm{ML}} = \mathbf{T}(\boldsymbol\Lambda-\sigma^2\mathbf{I})^{1/2}\mathbf{R}$; $\sigma^2_{\mathrm{ML}} = \frac{1}{D-M}\sum_{j>M}\lambda_j$ — **10.77**–**10.79** |

:::tip[Two closed forms the book does not give]
**Woodbury on Equation 10.75.** $\mathbf{C} = \sigma^2(\mathbf{B}^\top\mathbf{B}+\sigma^2\mathbf{I})^{-1}$,
measured agreement $9.7\times10^{-16}$, inverting $5\times5$ instead of $64\times64$. For
$\mathbf{B}_{\mathrm{ML}}$ this is **diagonal with $C_{mm} = \sigma^2/\lambda_m$** — the posterior is
uncertain in inverse proportion to the variance each axis carries, and it knows this before seeing data.

**The shrinkage.** PPCA's reconstruction is PCA's, scaled per axis by $(\lambda_m-\sigma^2)/\lambda_m$ —
measured to six decimals across four noise levels and five axes. At $\sigma^2 = 40$: $0.736093$ on axis
$1$ down to $0.236834$ on axis $5$.
:::

## The chapter in twelve lines

1. **Equation 10.1 is a covariance only if you centre.** Skip it and the leading direction becomes the mean, $0.2851^\circ$ from it.
2. **§10.1 fixes $M$ and chooses nothing else.** Example 10.1's vector gives errors $5$, $3$ and $0$ under three orthonormal bases.
3. **Variance is a quadratic form**, so maximising it under a norm constraint is an eigenvalue problem — Equation 10.15 makes the answer readable off the spectrum.
4. **The deflation in Equation 10.17 is a proof, not an algorithm.** One eigendecomposition gives every component.
5. **§10.3 minimises something different and lands in the same place**, because $V_M + J_M = \mathrm{tr}(\mathbf{S})$ is fixed.
6. **The optimal coordinates are the orthogonal projection** — geometry, not data — which is why §10.3.3 has only half a problem left.
7. **Equation 10.32 assumes orthonormality and fails quietly without it**, $24.73$ against $16.32$.
8. **The objective sees $\mathbf{B}\mathbf{B}^\top$, not $\mathbf{B}$.** Hence Equation 10.78's arbitrary $\mathbf{R}$, and hence ICA.
9. **Use the SVD of $\mathbf{X}$, not the eigendecomposition of $\mathbf{S}$**, whenever the small eigenvalues matter.
10. **When $N \ll D$, decompose the $N\times N$ Gram matrix** — $4565\times$ faster at $D = 4000$ — and remember to normalise.
11. **Standardising is a modelling decision.** $77.3982^\circ$ says so, and so does the fact that the raw trace has no units.
12. **PPCA is PCA with a story attached**, and the story buys imputation, novelty and a posterior whose width you know in advance.
