Text explains an idea. A **running sketch** lets the reader poke at it. Python
Central Hub ships two ways to show, not just tell: **p5.js** for live,
interactive canvases and **mermaid** for diagrams — both themed to match the
site and both authored with a plain fenced code block.

## p5.js sketches

Write an ordinary p5 sketch (global style — `setup`, `draw`, and the usual
bare calls) inside a `p5` code block. Add `title`, `desc`, and `height` to the
fence for a labelled panel. Each sketch gets **Pause** and **Restart**
controls, runs only when it scrolls into view, and holds still for readers who
prefer reduced motion.

````text
```p5 title="Bouncing balls" desc="Click to drop another." height="340"
let balls = [];
function setup() { createCanvas(600, 340); noStroke(); }
function draw() {
  background(13, 17, 23);
  for (const b of balls) { /* … update + render … */ }
}
function mousePressed() { balls.push(makeBall(mouseX, mouseY)); }
```
````

Here it is for real — **click the canvas** to drop another ball:

```p5 title="Bouncing balls" desc="Gravity, walls, and a little bounce. Click anywhere on the canvas to drop another ball." height="340"
let balls = [];
function makeBall(x, y) {
  return { x, y, vx: random(-3, 3), vy: 0, r: random(12, 26) };
}
function setup() {
  createCanvas(600, 340);
  noStroke();
  for (let i = 0; i < 6; i++) balls.push(makeBall(random(width), random(height / 2)));
}
function draw() {
  background(13, 17, 23);
  for (const b of balls) {
    b.vy += 0.25;
    b.x += b.vx;
    b.y += b.vy;
    if (b.y + b.r > height) { b.y = height - b.r; b.vy *= -0.8; }
    if (b.x < b.r || b.x > width - b.r) b.vx *= -1;
    fill(75, 139, 190);
    circle(b.x, b.y, b.r * 2);
    fill(255, 211, 67);
    circle(b.x, b.y, b.r * 0.7);
  }
}
function mousePressed() {
  if (mouseX >= 0 && mouseX <= width && mouseY >= 0 && mouseY <= height) {
    balls.push(makeBall(mouseX, mouseY));
  }
}
```

A calmer one — three sine waves in the Python palette, drifting on
`frameCount`:

```p5 title="Sine field" desc="Three waves in Python blue and amber, animated over time." height="280"
function setup() { createCanvas(600, 280); }
function draw() {
  background(13, 17, 23);
  noFill();
  strokeWeight(2.5);
  for (let k = 0; k < 3; k++) {
    if (k === 1) stroke(255, 211, 67, 220);
    else stroke(107, 169, 221, 200);
    beginShape();
    for (let x = 0; x <= width; x += 8) {
      const y = height / 2 + sin(x * 0.02 + frameCount * 0.03 + k * 1.2) * (60 - k * 14);
      vertex(x, y);
    }
    endShape();
  }
}
```

## mermaid diagrams

A `mermaid` block renders a themed diagram. Add `title` and `desc` for the
panel header and caption.

```mermaid title="How Python runs your code" desc="Your source becomes bytecode, then the virtual machine executes it — the loop every program follows."
flowchart LR
  A[".py source"] --> B["Compile"]
  B --> C[".pyc bytecode"]
  C --> D["Python VM"]
  D --> E["Output"]
```

```mermaid title="A request through Flask" desc="What happens between a click and a rendered page."
sequenceDiagram
  participant U as Browser
  participant F as Flask
  participant V as View
  U->>F: GET /home
  F->>V: match route
  V-->>F: render template
  F-->>U: HTML response
```

## Code blocks

Ordinary fenced blocks are framed the same way, with highlighted lines called
out by a blue rail — handy for pointing at the line that matters:

```python title="gravity.py" {3-5}
def step(ball):
    ball.vy += GRAVITY        # accelerate downward
    ball.y += ball.vy         # move
    if ball.y > FLOOR:        # hit the floor?
        ball.vy *= -0.8       # bounce, losing energy
    return ball
```
