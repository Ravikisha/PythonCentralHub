:::note[Measured: the same worker, one flag apart]
A worker that sleeps in a loop for one second and then prints `FINISHED`, with the main thread
exiting immediately after starting it:

| `daemon=` | Output |
| --- | --- |
| `True` | *(nothing — the thread was killed at interpreter shutdown)* |
| `False` | `FINISHED` — the process stayed alive until the worker was done |

The daemon thread was not asked to stop and did not get a chance to clean up; it simply ceased
to exist. Nothing was logged and no exception was raised.

So the rule is about consequences, not about tidiness: **if abandoning the work half-done is
harmless, a daemon thread is right.** If it is writing a file, holding a lock, or has a record
in flight, use a normal thread and `join()` it — or give it a `threading.Event` to check so it
can shut itself down deliberately.
:::

## What is a daemon thread?

A **daemon thread** is a background thread.

- If only daemon threads are left running, Python can exit.
- Non-daemon threads keep the program alive.

## Example

```python title="daemon_thread.py" showLineNumbers{1}
import threading
import time


def background():
    while True:
        print("background working...")
        time.sleep(0.5)


t = threading.Thread(target=background, daemon=True)
t.start()

time.sleep(2)
print("Main thread exiting")
```

## When to use daemon threads

- logging/reporting loops
- background monitoring

## When NOT to use them

Don’t use daemon threads for work that **must finish** (e.g., writing critical data).

```p5 title="The moment the main thread exits" desc="Two runs of the same worker, which needs one second and prints FINISHED at the end. The main thread starts it and immediately exits. const DUR = 1.0;
let t0 = 0;
const CYCLE = 3200;

function setup() {
  createCanvas(620, 400);
  textFont("monospace");
  t0 = millis();
}

function draw() {
  background(13, 17, 23);
  const el = ((millis() - t0) % CYCLE) / CYCLE;
  const t = el * 1.4;                 // virtual seconds, 0 .. 1.4

  noStroke();
  fill(200);
  textSize(12);
  textAlign(LEFT, TOP);
  text("main starts a 1.0 s worker, then exits immediately", 20, 14);

  const X = 150, W = 400, SEC = W / 1.4;
  const mainEnd = 0.05;

  // main thread
  fill(205);
  textSize(11);
  textAlign(LEFT, CENTER);
  text("main thread", 20, 66);
  fill(26, 31, 38);
  rect(X, 52, W, 26, 3);
  fill(88, 166, 255);
  rect(X, 52, Math.min(t, mainEnd) * SEC, 26, 3);
  if (t >= mainEnd) {
    stroke(255, 123, 114);
    line(X + mainEnd * SEC, 40, X + mainEnd * SEC, 300);
    noStroke();
    fill(255, 123, 114);
    textSize(9);
    textAlign(LEFT, TOP);
    text("main exits here", X + mainEnd * SEC + 4, 32);
  }

  // two workers
  const rows = [
    { label: "daemon=False", killed: false, tone: [140, 210, 160], y: 116 },
    { label: "daemon=True",  killed: true,  tone: [255, 123, 114], y: 186 },
  ];
  for (let i = 0; i < 2; i++) {
    const r = rows[i];
    const stop = r.killed ? mainEnd : DUR;
    const done = Math.min(t, stop);

    fill(205);
    textSize(11);
    textAlign(LEFT, CENTER);
    text(r.label, 20, r.y + 13);

    fill(26, 31, 38);
    rect(X, r.y, W, 26, 3);
    fill(r.tone[0], r.tone[1], r.tone[2]);
    rect(X, r.y, (done / 1.4) * W, 26, 3);

    // where it should have reached
    stroke(60);
    drawingContext.setLineDash([3, 3]);
    line(X + DUR * SEC, r.y - 4, X + DUR * SEC, r.y + 30);
    drawingContext.setLineDash([]);
    noStroke();

    if (r.killed && t > mainEnd) {
      fill(255, 123, 114);
      textSize(10);
      textAlign(LEFT, TOP);
      text("KILLED -- no exception, no finally, no flush", X + mainEnd * SEC + 8, r.y + 32);
    }
    if (!r.killed && t >= DUR) {
      fill(140, 210, 160);
      textSize(12);
      textAlign(LEFT, CENTER);
      text("FINISHED", X + DUR * SEC + 10, r.y + 13);
    }
  }

  fill(90, 100, 112);
  textSize(9);
  textAlign(CENTER, TOP);
  text("1.0 s -- where the work would have ended", X + DUR * SEC, 246);

  stroke(50);
  line(20, 280, 600, 280);
  noStroke();
  fill(200);
  textSize(11);
  textAlign(LEFT, TOP);
  text("measured: daemon=True printed nothing at all; daemon=False printed FINISHED", 20, 292);
  fill(150);
  textSize(10);
  text("The daemon thread was not asked to stop. When the last non-daemon thread ended, the", 20, 316);
  text("interpreter shut down and the thread simply ceased to exist mid-statement.", 20, 332);
  fill(219, 171, 90);
  text("Safe to abandon -- a heartbeat, a metrics poller? A daemon is right.", 20, 356);
  text("Writing a file, holding a lock, a record in flight? Use a normal thread and join() it.", 20, 372);
}
