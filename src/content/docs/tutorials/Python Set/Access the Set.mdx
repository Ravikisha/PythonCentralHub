## Access the Set
In python, we can not access the set elements using the index number. Because the set is an unordered collection of items. So, we can not access the set elements using the index number. But we can access the set elements using the `for` loop. 

```python title="tuple_index.py" showLineNumbers{1} {1-5}
data = {'a', 'b', 'c', 'd', 'e', 'f', 'g'}
for i in data:
    print(i)
```

Output:

```cmd title="command" showLineNumbers{1} {2-8}
C:\Users\username>python tuple_index.py
a
e
b
d
g
f
c
```

In this example, we declare a set and assign it to the variable `data`. We then print the set elements using the `for` loop. The output shows that the set elements are accessed using the `for` loop.

```p5 title="Why a set trades indexing for membership" desc="A list keeps its elements in order, so finding one means walking until you hit it. A set stores each value in a slot chosen by its hash, so it can jump straight to where the value would be -- which is why there is nothing sensible for s[0] to mean. The measured cost of an absent-value lookup is on the right." height="400"
const SIZES = [
  { n: 100,   list: 3.10,   set_: 0.170 },
  { n: 10000, list: 413.02, set_: 0.192 },

let idx = 0, last = 0, scan = 0;
function setup() { createCanvas(620, 400); textFont("monospace"); }
function draw() {
  background(13, 17, 23);
  if (millis() - last > 2400) { last = millis(); idx = (idx + 1) % SIZES.length; }
  scan = (scan + 0.35) % 13;
  const s = SIZES[idx];
  noStroke(); fill(200); textSize(12); textAlign(LEFT, TOP);
  text("looking for a value that is NOT present", 20, 14);

  // list: walk
  fill(150); textSize(11); textAlign(LEFT, TOP); text("list -- walk from the start", 20, 46);
  for (let i = 0; i < 12; i++) {
    const visited = i < scan;
    fill(visited ? color(255, 123, 114) : color(38, 45, 54));
    rect(20 + i * 40, 66, 34, 30, 3);
  }
  fill(255, 123, 114); textSize(10); textAlign(LEFT, TOP);
  text("every element compared before it can say no", 20, 102);

  // set: hash jump
  fill(150); textSize(11); textAlign(LEFT, TOP); text("set -- hash, then look in one place", 20, 138);
  for (let i = 0; i < 12; i++) {
    const target = i === 7;
    fill(target ? color(140, 210, 160) : color(30, 36, 44));
    rect(20 + i * 40, 158, 34, 30, 3);
  }
  stroke(140, 210, 160); line(120, 200, 300, 192); noStroke();

  // measured
  fill(150); textSize(11); textAlign(LEFT, TOP);
  text("measured, one lookup, n = " + s.n.toLocaleString(), 20, 240);
  const X = 150, W = 340, MAX = 420;
  const bars = [["list", s.list, [255,123,114]], ["set", s.set_, [140,210,160]]];
  for (let i = 0; i < 2; i++) {
