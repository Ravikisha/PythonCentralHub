Escape characters in Python are special characters that don't get printed as-is but instead signal some specific action. They allow you to include special characters in strings or control the formatting of text. In this comprehensive guide, we'll explore the world of escape characters in Python and how they can be used to enhance text manipulation.

## Basics of Escape Characters

Escape characters are denoted by a backslash (`\`) followed by a specific character or sequence. The backslash tells Python that the character following it has a special meaning.

#### Escape Characters in Python
|Sequence|Escape Character|Escape Character Name|Description|
|:---|:---|:---| :---|
|1|`\n`|Newline|Inserts a new line|
|2|`\t`|Tab|Inserts a tab|
|3|`\r`|Carriage Return|Inserts a carriage return|
|4|`\b`|Backspace|Inserts a backspace|
|5|`\f`|Form Feed|Inserts a form feed|
|6|`\v`|Vertical Tab|Inserts a vertical tab|
|7|`\\`|Backslash|Inserts a backslash|
|8|`\'`|Single Quote|Inserts a single quote|
|9|`\"`|Double Quote|Inserts a double quote|
|10|`\a`|Bell|Inserts a bell|
|11|`\0`|Null Byte|Inserts a null byte|
|12|`\N{name}`|Unicode Character|Inserts a Unicode character|
|13|`\xhh`|Hexadecimal Character|Inserts a hexadecimal character|
|14|`\uhhhh`|Unicode 16-bit Hexadecimal Character|Inserts a Unicode 16-bit hexadecimal character|
|15|`\Uhhhhhhhh`|Unicode 32-bit Hexadecimal Character|Inserts a Unicode 32-bit hexadecimal character|
|16|`\ooo`|Octal Character|Inserts an octal character|

## Newline Escape Character

The newline escape character (`\n`) inserts a new line into a string. It's useful for formatting text and creating line breaks. For example, you can use it to print a string on multiple lines:

```python title="strings.py" showLineNumbers{1} {2}
# print string on multiple lines
print('This is a string\non multiple lines')
```

Output

```cmd title="command" showLineNumbers{1} {2}
C:\Users\Your Name> python strings.py
This is a string
on multiple lines
```

```p5 title="The backslash is an instruction, until you turn it off" desc="In an ordinary literal the parser consumes the backslash and produces one character, so the text you typed and the string you got are different lengths. A raw string skips that step entirely. Watch the character count change as the same source text is read both ways." height="400"
const CASES = [
  { src: "'a\\nb'",       raw: false, chars: ["a", "NL", "b"],        len: 3, note: "backslash-n became ONE newline character" },
  { src: "r'a\\nb'",      raw: true,  chars: ["a", "\\", "n", "b"],   len: 4, note: "no escape processing -- two separate characters" },
  { src: "'C:\\path'",    raw: false, chars: ["C", ":", "?", "a", "t", "h"], len: 6, note: "backslash-p is not an escape, so it survives -- but do not rely on that" },
  { src: "r'C:\\path'",   raw: true,  chars: ["C", ":", "\\", "p", "a", "t", "h"], len: 7, note: "the literal Windows path, unambiguously" },
];
let idx = 0, last = 0;
function setup() { createCanvas(620, 400); textFont("monospace"); }
function draw() {
  background(13, 17, 23);
  if (millis() - last > 2100) { last = millis(); idx = (idx + 1) % CASES.length; }
  const c = CASES[idx];
  noStroke(); fill(200); textSize(12); textAlign(LEFT, TOP);
  text("what you type in the source", 20, 14);
  fill(88, 166, 255); textSize(24); text(c.src, 20, 36);

  fill(c.raw ? color(140,210,160) : color(219,171,90));
  textSize(12); textAlign(LEFT, TOP);
  text(c.raw ? "raw -- the parser leaves backslashes alone"
             : "normal -- the parser interprets escapes", 20, 76);

  fill(150); textSize(11); textAlign(LEFT, TOP); text("the characters you actually get", 20, 110);
  for (let i = 0; i < c.chars.length; i++) {
    const special = c.chars[i] === "NL" || c.chars[i] === "\\";
    fill(special ? color(219,171,90) : color(52, 60, 70));
    rect(20 + i * 54, 132, 46, 44, 5);
    fill(special ? 13 : 210); textSize(14); textAlign(CENTER, CENTER);
    text(c.chars[i], 43 + i * 54, 154);
  }

  fill(150); textSize(11); textAlign(LEFT, TOP); text("len()", 20, 194);
  fill(140, 210, 160); textSize(28); text(c.len, 80, 186);

  fill(210, 200, 160); textSize(11); textAlign(LEFT, TOP);
  text(c.note, 20, 228);

  stroke(50); line(20, 262, 600, 262); noStroke();
  fill(200); textSize(11); textAlign(LEFT, TOP);
  text("why regexes and Windows paths are written raw", 20, 274);
  fill(150); textSize(10);
  text("A regex like \\d needs the backslash to reach the regex engine. Without a raw string you", 20, 296);
  text("would write it twice, once for Python and once for the engine.", 20, 312);
  fill(255,123,114); textSize(10);
  text("The one thing a raw string cannot do is END with a backslash -- r'C:\\' is a SyntaxError,", 20, 338);
  text("because the backslash still escapes the closing quote for the tokenizer.", 20, 354);
}
