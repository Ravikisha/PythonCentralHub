## What is a semaphore?

A semaphore controls access to a limited resource.

Example: only 3 workers may access an API at once.

## Example

```python title="semaphore.py" showLineNumbers{1}
import threading
import time

sem = threading.Semaphore(3)


def worker(i: int) -> None:
    with sem:
        print("start", i)
        time.sleep(0.5)
        print("end", i)


threads = [threading.Thread(target=worker, args=(i,)) for i in range(10)]
for t in threads:
    t.start()
for t in threads:
    t.join()
```

const JOB = 0.05;
const CAPS = [2, 3];
const MEASURED = { 2: 0.31, 3: 0.21 };

let t0 = 0;
const CYCLE = 5000;

function setup() {
  createCanvas(620, 400);
  textFont("monospace");
  t0 = millis();

  const cap = CAPS[capIdx];

  const span = waves * JOB;               // ideal seconds

  const el = (millis() - t0) % CYCLE;
  const virt = (el / CYCLE) * (span * 1.15);

  noStroke();
  fill(200);
  textSize(12);
  textAlign(LEFT, TOP);
  text(N + " jobs of " + JOB + "s, Semaphore(" + cap + ")", 20, 14);
  fill(90, 100, 112);
  textSize(10);
  text("click to change the permit count", 20, 32);

  const X = 92, W = 470;
  const secToPx = W / (span * 1.15);

  let inflight = 0;
  for (let i = 0; i < N; i++) {
    const wave = Math.floor(i / cap);
    const start = wave * JOB;
    const y = 60 + i * 18;
    const w = JOB * secToPx;
    const x = X + start * secToPx;
    const frac = Math.max(0, Math.min(1, (virt - start) / JOB));
    const active = virt >= start && virt < start + JOB;
    if (active) inflight += 1;

    fill(70, 78, 90);
    textSize(9);
    textAlign(RIGHT, CENTER);
    text("job " + i, X - 8, y + 7);

    noStroke();
    fill(26, 31, 38);
    rect(X, y, W, 14, 2);
    fill(28, 34, 41);
    rect(x, y, w, 14, 2);
    if (frac > 0) {
      fill(active ? color(140, 210, 160) : color(70, 110, 88));
      rect(x, y, w * frac, 14, 2);
    }
  }

  // the clock
  const cx = X + virt * secToPx;
  stroke(255);
  line(cx, 56, cx, 60 + N * 18);
  noStroke();

  // permits
  fill(150);
  textSize(11);
  textAlign(LEFT, TOP);
  text("permits in use", 20, 292);
  for (let i = 0; i < cap; i++) {
    fill(i < inflight ? color(219, 171, 90) : color(34, 40, 48));
    rect(120 + i * 26, 292, 20, 16, 3);
  }
  fill(inflight > cap ? color(255, 123, 114) : color(205));
  textSize(12);
  textAlign(LEFT, TOP);
  text(inflight + " of " + cap + " in flight", 120 + cap * 26 + 12, 292);

  stroke(50);
  line(20, 320, 600, 320);
  noStroke();

  fill(200);
  textSize(12);
  textAlign(LEFT, TOP);
  text(waves + " waves x " + JOB + "s = " + span.toFixed(2) + "s ideal, measured " +
       MEASURED[cap].toFixed(2) + "s", 20, 332);
  fill(150);
  textSize(10);
  text("Peak in-flight measured at exactly " + cap + " -- the ceiling is not approximate.", 20, 356);
  fill(219, 171, 90);
  text("A semaphore limits concurrency; it does not create it. Raising the count past what the", 20, 376);
  text("resource can take just moves the queue somewhere less visible.", 20, 390);
}

## BoundedSemaphore

`BoundedSemaphore` raises an error if you release too many times.

Use it to catch bugs.

```python title="bounded_semaphore.py" showLineNumbers{1}
import threading

sem = threading.BoundedSemaphore(1)
sem.acquire()
sem.release()
# sem.release()  # would raise ValueError
```


## A counter with a waiting room

A `Semaphore` holds a number of permits. `acquire()` takes one, and if none are left the thread waits. `release()` gives one back. Unlike a `Lock`, which lets in exactly one thread, a `Semaphore(3)` lets in up to three. A lock is simply a semaphore with one permit.

Think of a cafe with three tables. New customers sit down while a table is free, and otherwise queue at the door. When someone leaves, the next person in line is seated.

## Reading the example

Ten threads start, but only three can be inside `with sem:` at any moment. You will see three `start` lines immediately, then after about half a second three `end` lines, and the next three `start` lines follow as permits are released. The tenth thread runs alone in the final wave. The `with` block acquires on entry and releases on exit, even when an error happens inside.

## A practical case: limiting API calls

Many web APIs refuse too many simultaneous requests. A semaphore keeps you inside their limit while still allowing some parallelism:

```python title="limit_requests.py" showLineNumbers{1}
import threading
import time

sem = threading.Semaphore(2)   # at most 2 downloads at once
active = 0
peak = 0
guard = threading.Lock()


def download(i: int) -> None:
    global active, peak
    with sem:
        with guard:
            active += 1
            peak = max(peak, active)
        time.sleep(0.2)        # pretend to download
        with guard:
            active -= 1


threads = [threading.Thread(target=download, args=(i,)) for i in range(6)]
for t in threads:
    t.start()
for t in threads:
    t.join()
print("most at once:", peak)  # 2
```

The counters, protected by a small lock, prove that the peak never exceeds two.

## Semaphore versus BoundedSemaphore

A plain `Semaphore` lets you release more times than you acquired, silently raising the number of permits above the limit. That is nearly always a bug. `BoundedSemaphore` raises `ValueError` when this happens, so the mistake is caught immediately. Use it by default.

## Common mistakes

- **Releasing without acquiring**, which grows the permit count. Use `with sem:` and `BoundedSemaphore`.
- **Confusing a semaphore with a lock.** A semaphore with more than one permit does not protect shared data from concurrent changes; you still need a lock for that.
- **Forgetting the release on an error path.** Using `with` avoids this.
- **Setting the count too high**, so it limits nothing.

## When to use it

Use a semaphore to cap access to a limited resource: database connections, API rate limits, open files, or CPU-heavy sections that should not run all at once.
