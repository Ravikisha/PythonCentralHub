## What is the event loop?

The event loop is the “engine” that:

- runs coroutines
- pauses them at await points
- resumes them when I/O is ready

## asyncio.run

`asyncio.run(coro)`:

- creates an event loop
- runs the coroutine until complete
- closes the loop

```python title="asyncio_run.py" showLineNumbers{1}
import asyncio


async def main():
    await asyncio.sleep(0.1)
    return 123


print(asyncio.run(main()))
```

## Running multiple coroutines

To run multiple coroutines concurrently, you’ll use:

- tasks
- gather

(covered in next pages)

## Common mistake in notebooks

Some notebook environments already have an event loop running.

If `asyncio.run` fails there, use notebook-safe patterns.

In normal Python scripts, prefer `asyncio.run`.

## Visualize it

`asyncio.run` starts the **event loop**. It runs one coroutine until that coroutine hits an
`await`, at which point the coroutine **suspends** and hands control back to the loop, which
picks the next ready task. Nothing runs in parallel — the loop just never sits idle waiting:

```mermaid title="await hands control back to the loop" desc="Each coroutine runs until await, suspends, and the event loop schedules the next ready task."
flowchart LR
  A["asyncio.run(main)"] --> B["Event loop"]
  B --> C["Run a coroutine"]
  C -->|hits await| D["Suspend & save state"]
  D --> B
  C -->|returns| E["Task done"]
```

Here the loop juggles three coroutines: one runs, hits `await`, yields, and the loop moves
on to the next:

```p5 title="The event loop juggles tasks" desc="One coroutine runs until it hits await, then yields control back to the loop, which runs the next ready task." height="260"
let t = 0;
const tasks = ["fetch A", "fetch B", "fetch C"];
let active = 0;
let phase = 0;
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  textAlign(CENTER, CENTER);
}
function draw() {
  background(13, 17, 23);
  const cx = width / 2, cy = 138, R = 86;
  noFill();
  stroke(60, 70, 84);
  strokeWeight(2);
  ellipse(cx, cy, R * 2, R * 2);
  noStroke();
  fill(107, 169, 221);
  textSize(13);
  text("event loop", cx, cy);
  for (let i = 0; i < tasks.length; i++) {
    const a = -HALF_PI + i * TWO_PI / tasks.length;
    const x = cx + cos(a) * R, y = cy + sin(a) * R;
    const isActive = i === active;
    noStroke();
    fill(isActive ? color(75, 139, 190) : color(30, 40, 54));
    ellipse(x, y, 78, 46);
    fill(isActive ? 255 : 150);
    textSize(12);
    text(tasks[i], x, y);
  }
  fill(255, 211, 67);
  textSize(14);
  text(phase === 0 ? tasks[active] + " running…" : tasks[active] + " hit await → yield", cx, 240);
  t++;
  if (t % 45 === 0) {
    if (phase === 0) phase = 1;
    else { phase = 0; active = (active + 1) % tasks.length; }
  }
}
```
