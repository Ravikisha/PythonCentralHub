## Why tasks

A **Task** is a scheduled coroutine.

- You create it
- The event loop runs it concurrently with others

## create_task

```python title="create_task.py" showLineNumbers{1}
import asyncio


async def job(i: int) -> str:
    await asyncio.sleep(0.2)
    return f"done {i}"


async def main():
    t1 = asyncio.create_task(job(1))
    t2 = asyncio.create_task(job(2))

    # await results
    print(await t1)
    print(await t2)


asyncio.run(main())
```

:::caution[`create_task` schedules — it does not start]
The coroutine body does **not** begin when you call `create_task`. The task is handed to the
event loop, and the loop only gets control when you next `await`. Put a `print` between two
`create_task` calls and it runs *first*:

```python title="ordering.py" showLineNumbers{1}
import asyncio

order = []


async def note(i):
    order.append(("start", i))
    await asyncio.sleep(0.05)
    order.append(("end", i))


async def main():
    t1 = asyncio.create_task(note(1))
    t2 = asyncio.create_task(note(2))
    order.append(("after create_task", None))     # <- runs before either task
    await t1
    await t2
    print(order)


asyncio.run(main())
# [('after create_task', None), ('start', 1), ('start', 2), ('end', 1), ('end', 2)]
```

Verified — that is the real output, not a sketch of one. The practical consequence: a task you
create and never await (or never keep a reference to) may be garbage-collected before it
finishes, which is why `TaskGroup` exists.
:::

## asyncio.gather

`gather` is a convenient way to run many coroutines and collect results.

```python title="gather.py" showLineNumbers{1}
import asyncio


async def job(i: int) -> int:
    await asyncio.sleep(0.1)
    return i * i


async def main():
    results = await asyncio.gather(*(job(i) for i in range(10)))
    print(results)


asyncio.run(main())
```

```p5 title="Sequential await against gather, with the measured times" desc="Ten jobs, each awaiting asyncio.sleep(0.1). Awaiting them one at a time takes the sum; handing them all to asyncio.gather takes about as long as the slowest one. Measured on CPython 3.14.4: 1.091 s sequential against 0.109 s gathered, a 10x difference, and both produce exactly the same list. The bars run in real time -- the animation is not sped up." height="400"
const N = 10;
const JOB = 0.1;          // seconds each
const SEQ_MEASURED = 1.091;
const GAT_MEASURED = 0.109;

let t0 = 0;
const CYCLE = 4000;       // ms per full loop of the animation

function setup() {
  createCanvas(620, 400);
  textFont("monospace");
  t0 = millis();
}

function draw() {
  background(13, 17, 23);
  const el = (millis() - t0) % CYCLE;
  // map the animation to a virtual 1.2 s of wall clock
  const virt = (el / CYCLE) * 1.2;

  noStroke();
  fill(200);
  textSize(12);
  textAlign(LEFT, TOP);
  text(N + " jobs, each await asyncio.sleep(" + JOB + ")", 20, 14);

  const X = 130, W = 400;
  const secToPx = W / 1.2;

  // ---- sequential ----
  fill(150);
  textSize(11);
  textAlign(LEFT, TOP);
  text("one at a time", 20, 46);
  fill(255, 123, 114);
  textSize(10);
  text(SEQ_MEASURED.toFixed(3) + " s", 20, 62);

  for (let i = 0; i < N; i++) {
    const start = i * JOB;
    const x = X + start * secToPx;
    const w = JOB * secToPx;
    const doneFrac = Math.max(0, Math.min(1, (virt - start) / JOB));
    noStroke();
    fill(28, 34, 41);
    rect(x, 46, w - 1, 14, 2);
    if (doneFrac > 0) {
      fill(255, 123, 114);
      rect(x, 46, (w - 1) * doneFrac, 14, 2);
    }
  }

  // ---- gathered ----
  fill(150);
  textSize(11);
  textAlign(LEFT, TOP);
  text("asyncio.gather", 20, 96);
  fill(140, 210, 160);
  textSize(10);
  text(GAT_MEASURED.toFixed(3) + " s", 20, 112);

  for (let i = 0; i < N; i++) {
    const y = 96 + i * 12;
    const w = JOB * secToPx;
    const doneFrac = Math.max(0, Math.min(1, virt / JOB));
    noStroke();
    fill(28, 34, 41);
    rect(X, y, w - 1, 10, 2);
    if (doneFrac > 0) {
      fill(140, 210, 160);
      rect(X, y, (w - 1) * doneFrac, 10, 2);
    }
    fill(70, 78, 90);
    textSize(8);
    textAlign(RIGHT, CENTER);
    text("job " + i, X - 6, y + 5);
  }

  // the clock
  const cx = X + virt * secToPx;
  stroke(255);
  line(cx, 40, cx, 226);
  noStroke();
  fill(255);
  textSize(10);
  textAlign(LEFT, TOP);
  text(virt.toFixed(2) + " s", cx + 4, 30);

  // second markers
  for (let g = 0; g <= 12; g++) {
    const x = X + (g / 10) * secToPx;
    stroke(38, 44, 52);
    line(x, 232, x, 238);
    noStroke();
    if (g % 5 === 0) {
      fill(70, 78, 90);
      textSize(9);
      textAlign(CENTER, TOP);
      text((g / 10).toFixed(1) + "s", x, 240);
    }
  }

  // verdict
  stroke(50);
  line(20, 268, 600, 268);
  noStroke();
  fill(200);
  textSize(12);
  textAlign(LEFT, TOP);
  text("1.091 s  ->  0.109 s   (10.0x)", 20, 282);
  fill(150);
  textSize(10);
  text("Sequential cost is the SUM of the waits. Gathered cost is the MAX, plus overhead.", 20, 306);
  text("Both return the same list: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81].", 20, 322);
  fill(219, 171, 90);
  textSize(10);
  text("This only works because the jobs WAIT. Ten CPU-bound jobs gather to no speedup at", 20, 348);
  text("all -- there is one thread, and gather does not add another.", 20, 364);
}
```

## Error behavior

If one coroutine fails, `gather` cancels others by default.

You can keep errors as values:

```python title="gather_return_exceptions.py" showLineNumbers{1}
import asyncio


async def ok():
    return 1


async def bad():
    raise ValueError("boom")


async def main():
    res = await asyncio.gather(ok(), bad(), return_exceptions=True)
    print(res)


asyncio.run(main())
```
