:::note[The observed order]
```text
__aenter__ , body , __aexit__ , gen start , got 0 , got 1 , gen end
```

`__aenter__` and `__aexit__` are **awaited**, so both may do I/O — opening a connection and
closing it cleanly, which is the usual reason to write one. `__aexit__` runs when the body
raises as well, and returning a truthy value from it suppresses that exception.

Two mistakes worth naming:

**A synchronous context manager will not work with `async with`.** The method names are
different entirely. Python 3.14 says so precisely:

```text
TypeError: 'SyncCM' object does not support the asynchronous context manager
protocol (missed __aexit__ method) but it supports the context manager protocol.
Did you mean to use 'with'?
```

**An async generator needs `async for`.** A plain `for` over one gives
`TypeError: 'async_generator' object is not iterable`, because `__anext__` returns an awaitable
rather than a value. The generator's body does not begin until the first iteration, exactly like
a synchronous generator.
:::

## Async context managers (`async with`)

You use `async with` when acquiring/releasing a resource needs `await`.

Common examples:

- `aiohttp.ClientSession()`
- async database connections
- async locks (`asyncio.Lock`)

### Example: sessions and responses

```python title="aiohttp_context_manager.py" showLineNumbers{1}
import asyncio
import aiohttp


async def main():
    async with aiohttp.ClientSession() as session:
        async with session.get("https://api.github.com") as resp:
            data = await resp.json()
            print(resp.status)
            print("keys:", list(data.keys())[:5])


asyncio.run(main())
```

### Writing your own async context manager

Use `@asynccontextmanager` for a clean pattern.

```python title="custom_async_context_manager.py" showLineNumbers{1}
import asyncio
from contextlib import asynccontextmanager


@asynccontextmanager
async def managed_resource(name: str):
    print("acquire", name)
    await asyncio.sleep(0.1)
    try:
        yield {"name": name}
    finally:
        print("release", name)
        await asyncio.sleep(0.1)


async def main():
    async with managed_resource("db-conn") as res:
        print(res)


asyncio.run(main())
```

## Async generators (`async def` + `yield`)

An async generator is a generator that can `await` between yields.

It’s perfect for **streaming** data without loading everything into memory.

### Example: async generator + `async for`

```python title="async_generator.py" showLineNumbers{1}
import asyncio


async def ticker(n: int, delay: float = 0.2):
    for i in range(n):
        await asyncio.sleep(delay)
        yield i


async def main():
    async for value in ticker(5):
        print(value)


asyncio.run(main())
```

## Important gotchas

- Use `async with` only with objects that implement `__aenter__` / `__aexit__`.
- Use `async for` only on async iterables (implement `__aiter__`).
- Don’t forget to close async resources (sessions, connections). `async with` helps you avoid leaks.
