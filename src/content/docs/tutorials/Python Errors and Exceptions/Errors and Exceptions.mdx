## What are errors and exceptions?

When Python can’t execute your code, it stops and reports a problem.

- **Syntax errors** happen when Python can’t even *parse* the code.
- **Exceptions** happen while the program is running (runtime problems).

## Syntax Error

A syntax error occurs when Python sees invalid code structure.

```python title="syntax_error.py" showLineNumbers{1}
# Missing colon
if 10 > 5
    print("10 is greater")
```

Typical output:

```text title="Traceback" showLineNumbers{1}
  File "syntax_error.py", line 2
    if 10 > 5
             ^
SyntaxError: expected ':'
```

## Exception (runtime error)

Example: division by zero.

```python title="zero_division.py" showLineNumbers{1}
print(10 / 0)
```

```text title="Traceback" showLineNumbers{1}
Traceback (most recent call last):
  File "zero_division.py", line 1, in <module>
    print(10 / 0)
ZeroDivisionError: division by zero
```

## How to read a traceback

A traceback tells you:

1. **Where** the error occurred (file and line number)
2. The **call stack** (which functions were called)
3. The **exception type** and message

## Common exception types

- `NameError` – variable not defined
- `TypeError` – wrong type used (e.g., add str + int)
- `ValueError` – correct type, invalid value (e.g., int("abc"))
- `IndexError` – list index out of range
- `KeyError` – dict key missing
- `FileNotFoundError` – file path not found

```python title="common_exceptions.py" showLineNumbers{1}

But raising and catching an exception is expensive, so when the key is usually missing the check wins by a lot.   { key: "key MISSING", eafp: 129.7, lbyl: 18.0, winner: "lbyl",
    note: "raising and catching is real work: about 7x the cost of just asking first" },

let last = 0;

function setup() {
  createCanvas(620, 380);
  textFont("monospace");

function draw() {

  noStroke();
  fill(200);
  textSize(12);
  textAlign(LEFT, TOP);

      textSize(10);
      textAlign(LEFT, TOP);
      text("faster here", X, y + 34);

  }

  fill(210, 200, 160);
  textSize(11);
  textAlign(LEFT, TOP);
  text(c.note, 20, 246);

  stroke(50);
  line(20, 274, 600, 274);
  noStroke();
  fill(200);
  textSize(11);
  textAlign(LEFT, TOP);
  text("the rule this gives you", 20, 286);
  fill(150);
  textSize(10);
  text("Exceptions should be exceptional. If the miss is rare, try/except is both faster and", 20, 308);
  text("cleaner -- it does the lookup once instead of twice. If the miss is common, check first.", 20, 324);
  fill(219, 171, 90);
  text("And when you just want a default, d.get(k, default) beats both and says what you mean.", 20, 348);
}
