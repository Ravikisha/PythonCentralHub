## Understanding the Tuple Unpacking

What you understand by unpacking the tuple? It is a process of assigning the values of the tuple to the variables. The unpacking of the tuple is a very useful feature in Python. It allows us to assign the values of the tuple to the variables.


## Creating a Tuple
First, We need to learn how to create a tuple. We can create a tuple using the following syntax.

1. Using the `()` brackets.
    You can create a tuple using the `()` brackets. The tuple elements are separated by the comma (,) operator. The following example shows how to create a tuple using the `()` brackets.

    ```python title="tuple.py" showLineNumbers{1} {1}
    data = ('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j')
    print(data)
    ```

    Output:

    ```cmd title="command" showLineNumbers{1} {2-5}
    C:\Users\username>python tuple.py
    ('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j')
    ```

2. Using the `tuple()` constructor.
   You can also create a tuple using the `tuple()` constructor. The following example shows how to create a tuple using the `tuple()` constructor.

    ```python title="tuple_constructor.py" showLineNumbers{1} {1}
    data = tuple(('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j'))
    print(data)
    ```

    Output:

    ```cmd title="command" showLineNumbers{1} {2-5}
    C:\Users\username>python tuple_constructor.py
    ('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j')
    ```
3. using the `,` operator.
    You can also create a tuple using the `,` operator. The following example shows how to create a tuple using the `,` operator.

    ```python title="tuple_comma.py" showLineNumbers{1} {1}
    data = 'a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j'
    print(data)
    ```

    Output:

    ```cmd title="command" showLineNumbers{1} {2-5}
    C:\Users\username>python tuple_comma.py
    ('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j')
    ```

## Unpacking the Tuple
Unpacking the tuple is a process of assigning the values of the tuple to the variables. The unpacking of the tuple is a very useful feature in Python. It allows us to assign the values of the tuple to the variables.

```python title="tuple_unpack.py" showLineNumbers{1} {1-15}
data = ('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j')
a, b, c, d, e, f, g, h, i, j = data
print(a)
print(b)
print(c)
print(d)
print(e)
print(f)
print(g)
print(h)
print(i)
print(j)
```

Output:

```cmd title="command" showLineNumbers{1} {2-11}
C:\Users\username>python tuple_unpack.py
a
b
c
d
e
f
g
h
i
j
```

In this example, we declare a tuple and assign it to the variable `data`. We then unpack the tuple and assign the values of the tuple to the variables `a`, `b`, `c`, `d`, `e`, `f`, `g`, `h`, `i`, `j`. We then print the values of the variables. The output shows that the values of the tuple are assigned to the variables.

## Unpacking the Tuple using the Asterisk Operator
We can also unpack the tuple using the asterisk operator.

```python title="tuple_unpack_asterisk.py" showLineNumbers{1} {1-15}
data = ('a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j')
a, b, c, *d = data
print(a)
print(b)
print(c)
print(d)
```

Output:

```cmd title="command" showLineNumbers{1} {2-5}
C:\Users\username>python tuple_unpack_asterisk.py

b
c
['d', 'e', 'f', 'g', 'h', 'i', 'j']
```

In this example, we declare a tuple and assign it to the variable `data`. We then unpack the tuple and assign the values of the tuple to the variables `a`, `b`, `c`, `d`. We then print the values of the variables. The output shows that the values of the tuple are assigned to the variables. `*` operator is used to unpack the tuple and assign the remaining values to the variable `d`.

```p5 title="Unpacking is a shape check, and the star absorbs the rest" desc="The left-hand side describes a shape and Python checks the right-hand side against it. Too many or too few values raises immediately, at the assignment, rather than producing something subtly wrong further on. One starred name may absorb whatever the fixed names do not need -- and it always produces a list, even when there is nothing left." height="400"
const CASES = [
  { lhs: "a, b",        rhs: "(1, 2)",       ok: true,  out: "a=1  b=2" },
  { lhs: "a, b",        rhs: "(1, 2, 3)",    ok: false, out: "ValueError: too many values to unpack (expected 2, got 3)" },
  { lhs: "a, b, c",     rhs: "(1, 2)",       ok: false, out: "ValueError: not enough values to unpack (expected 3, got 2)" },
  { lhs: "a, *rest",    rhs: "(1, 2, 3, 4)", ok: true,  out: "a=1  rest=[2, 3, 4]" },
  { lhs: "a, *rest",    rhs: "(1,)",         ok: true,  out: "a=1  rest=[]" },
  { lhs: "*init, last", rhs: "(1, 2, 3)",    ok: true,  out: "init=[1, 2]  last=3" },
  { lhs: "a, (b, c)",   rhs: "(1, (2, 3))",  ok: true,  out: "a=1  b=2  c=3" },
];
let idx = 0, last = 0;
function setup() { createCanvas(620, 400); textFont("monospace"); }
function draw() {
  background(13, 17, 23);
  if (millis() - last > 1800) { last = millis(); idx = (idx + 1) % CASES.length; }
  const c = CASES[idx];
  noStroke(); fill(200); textSize(12); textAlign(LEFT, TOP);
  text("the left side is a SHAPE; the right side must match it", 20, 14);
  fill(88, 166, 255); textSize(22);
  text(c.lhs + " = " + c.rhs, 20, 40);

  // the values
  const vals = c.rhs.replace(/[()]/g, "").split(",").map(s => s.trim()).filter(Boolean);
  fill(150); textSize(11); textAlign(LEFT, TOP); text("values on the right", 20, 92);
  for (let i = 0; i < vals.length; i++) {
    fill(c.ok ? color(88,166,255) : color(255,123,114));
    rect(20 + i * 62, 112, 54, 36, 4);
    fill(13); textSize(13); textAlign(CENTER, CENTER);
    text(vals[i], 47 + i * 62, 130);
  }

  // names
  const names = c.lhs.split(",").map(s => s.trim());
  fill(150); textSize(11); textAlign(LEFT, TOP); text("names on the left", 20, 166);
  for (let i = 0; i < names.length; i++) {
    const starred = names[i].indexOf("*") === 0;
    fill(starred ? color(219,171,90) : color(52,60,70));
    rect(20 + i * 92, 186, 84, 34, 4);
    fill(starred ? 13 : 205); textSize(12); textAlign(CENTER, CENTER);
    text(names[i], 62 + i * 92, 203);
  }

  fill(24, 29, 36); rect(20, 238, 580, 56, 6);
  fill(c.ok ? color(140,210,160) : color(255,123,114)); rect(20, 238, 4, 56, 2, 0, 0, 2);
  fill(c.ok ? color(140,210,160) : color(255,123,114)); textSize(14); textAlign(LEFT, TOP);
  text(c.out, 38, 256);

  stroke(50); line(20, 310, 600, 310); noStroke();
  fill(200); textSize(11); textAlign(LEFT, TOP);
  text("a mismatch raises at the assignment, which is the point", 20, 322);
  fill(150); textSize(10);
  text("If a function's return signature changes, the unpacking fails on the line that reads it --", 20, 344);
  text("not three steps later with a confusing value.", 20, 360);
  fill(219,171,90); textSize(10);
  text("A starred name always yields a LIST, and yields [] rather than being absent.", 20, 384);
}
