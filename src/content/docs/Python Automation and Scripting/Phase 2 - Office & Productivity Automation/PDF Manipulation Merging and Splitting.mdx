## Library choice

A common modern option is `pypdf` (successor of PyPDF2). Older tutorials use `PdfMerger`, which newer versions of `pypdf` have removed. Use `PdfWriter` as below.

## Merge PDFs

```python title="pdf_merge.py" showLineNumbers{1}
from pypdf import PdfWriter

writer = PdfWriter()
writer.append("a.pdf")
writer.append("b.pdf")

with open("merged.pdf", "wb") as f:
    writer.write(f)
writer.close()
```

## Split a PDF

```python title="pdf_split.py" showLineNumbers{1}
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")

for i, page in enumerate(reader.pages, start=1):
    writer = PdfWriter()
    writer.add_page(page)
    with open(f"page_{i}.pdf", "wb") as f:
        writer.write(f)
```

## Merging with the current API

`PdfMerger` was deprecated and removed in recent `pypdf` releases, and `PdfWriter` now does everything. This version works on current `pypdf`, and lets you pick pages.

```python title="pdf_merge_writer.py" showLineNumbers{1}
from pathlib import Path
from pypdf import PdfWriter

writer = PdfWriter()
for name in ["a.pdf", "b.pdf"]:
    writer.append(name)                 # adds every page

writer.append("c.pdf", pages=(0, 2))    # only pages 1 and 2 of c.pdf

with Path("merged.pdf").open("wb") as f:
    writer.write(f)
writer.close()
```

`pages=(0, 2)` is a range of zero-based page numbers, where the end is not included, like `range`. So `(0, 2)` means the first two pages. If your installed `pypdf` is old and lacks `PdfWriter.append`, upgrade it with `pip install -U pypdf`.

## Splitting by page range

The split example writes one file per page. Often you want a section instead, such as pages 3 to 5.

```python title="pdf_extract_pages.py" showLineNumbers{1}
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

for index in range(2, 5):               # pages 3, 4, 5
    writer.add_page(reader.pages[index])

with open("section.pdf", "wb") as f:
    writer.write(f)
```

Check `len(reader.pages)` first. Asking for a page that does not exist raises `IndexError`.

## Other useful operations

- **Rotate.** `page.rotate(90)` turns a page clockwise before you add it to the writer.
- **Metadata.** `reader.metadata` gives the title and author, and `writer.add_metadata({...})` sets them.
- **Bookmarks.** `writer.add_outline_item("Chapter 1", page_number=0)` adds a navigation entry.
- **Encrypted files.** Call `reader.decrypt("password")` before reading pages.

## Common mistakes

- **Merging in the wrong order.** Files sorted with `sorted(Path(".").glob("*.pdf"))` go in name order. `10.pdf` sorts before `2.pdf`, so use zero-padded names.
- **Writing the output into the folder you are globbing.** The next run merges the old merged file into the new one.
- **Confusing page numbers.** Humans count from 1, `pypdf` from 0.
- **Not closing the file.** Use `with` for the output file.
- **Overwriting an original.** Always write to a new name.

## Adapting it

Merge every PDF in a folder into one report, split a scanned book into chapters, or extract the first page of many invoices into a summary file. Combine it with the previous lesson to extract text from each part.
