```mermaid title="which shutil function keeps what" desc="The four copying functions differ in what they carry across and what they accept as a destination. copyfile is bytes only and needs a filename; copy adds permissions and will accept a directory; copy2 additionally preserves the timestamps, which is what you want when the mtime is meaningful. Choosing the wrong one is how a backup ends up with every file dated today."
flowchart TD
  A["copyfile(src, dst)"] --> B["contents only -- dst must be a FILE path"]
  C["copy(src, dst)"] --> D["contents + permissions"]
  E["copy2(src, dst)"] --> F["contents + permissions + timestamps"]
  G["copytree(src, dst)"] --> H["a whole directory, recursively"]
  I["move(src, dst)"] --> J["rename if possible, else copy+delete"]
  D --> K["dst may be a directory -- it copies INTO it"]
  F --> K
  J --> K
  L["rmtree(path)"] --> M["deletes recursively, with no confirmation and no undo"]
```

:::note[`copy` loses the modification time; `copy2` keeps it — verified]
| Function | mtime preserved |
| --- | --- |
| `shutil.copy` | **no** |
| `shutil.copy2` | **yes** |

That single difference decides whether a backup, a sync script or an archive keeps any record of
when files were actually written. `copytree` uses `copy2` by default, so a directory copy keeps
timestamps while a file-by-file loop with `copy` does not — an inconsistency that is easy to
introduce without noticing.

Also confirmed: given an existing directory as the destination, both `copy` and `move` place the
file **inside** it rather than replacing it. Given an existing *file*, `move` overwrites it
silently. There is no prompt and no backup, which is the argument for the dry-run pattern on
the safety page.
:::

## What `shutil` is for

`shutil` (shell utilities) helps with:

- copying files/folders
- moving files
- removing directory trees

## Copying files

```python title="copy_file.py" showLineNumbers{1}
import shutil

shutil.copy2("source.txt", "backup_source.txt")
```

`copy2` attempts to preserve metadata.

## Copying folders

```python title="copy_tree.py" showLineNumbers{1}
import shutil

shutil.copytree("my_folder", "my_folder_backup", dirs_exist_ok=True)
```

## Moving files

```python title="move_file.py" showLineNumbers{1}
import shutil

shutil.move("old/name.txt", "new/name.txt")
```

## Deleting folders (danger!)

```python title="remove_tree.py" showLineNumbers{1}
import shutil

shutil.rmtree("danger_folder")
```

Always do a dry run before destructive operations.
