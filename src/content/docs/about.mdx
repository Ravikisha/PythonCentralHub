Python Central Hub is a free, self-paced place to learn programming, data and
machine learning with Python. Every course is written to be read in a browser and practised in
the same page: the code examples run, the exercises are checked as you go, and
nothing needs installing.

## What you can study

Ten courses, from a first `print()` to deep learning:

- **Python Programming** (PY 101), then **Python Projects** (PY 150) and
  **Automation and Scripting** (PY 180)
- **Web Development with Flask** (WEB 201) and **Software Testing and
  Quality** (SE 230)
- **Data Analytics with Python** (DATA 110)
- **Mathematics for Machine Learning** (MATH 120), **Machine Learning**
  (ML 210) and **Deep Learning** (DL 310)
- **Data Structures and Algorithms** (CS 220), for interviews and for the
  thinking behind fast code

Not sure where to start? The [learning roadmap](/guides/roadmap/) puts them in
order and says roughly how long each one takes.

## How the courses are made

- **Runnable everywhere.** Python runs in your browser through Pyodide, so a
  lesson works the same on a school laptop as on a workstation.
- **Checked practice.** Most lessons end with exercises that are graded the
  moment you submit them, and quizzes that explain every answer.
- **Measured, not guessed.** Numbers quoted in a lesson come from running its
  code. Where an exercise is smaller than the lesson's example so that it runs
  quickly in a browser, it says so.
- **Honest certificates.** A certificate needs 90% of a course's lessons
  completed. The assessment certificate also needs the final assessment
  passed, graded on our server against a key your browser never sees. Anyone
  can check a certificate at [/verify/](/verify/).

## What it costs

Nothing. There are no paid tiers, no ads and no tracking cookies. You can learn
without an account; an account only adds syncing between devices, the final
assessments and certificates. See the [privacy policy](/policy/) for exactly
what is stored.
