This is LeetCode's official plan, and it differs from the community sheets in
one important way: it includes the **implementation problems** the pattern-first
sheets skip. Text Justification, Roman numerals, Simplify Path, Zigzag
Conversion -- unglamorous, no clever insight, purely careful code.

Those get asked. Not because they are interesting, but because they test whether
you can write correct fiddly code under pressure, which is a real part of the job.
A candidate who has only done pattern problems is often visibly thrown by them.

**Use it if** you have finished a pattern-first sheet and want to close that gap,
or if you are targeting Microsoft or Bloomberg, where careful implementation is
weighted more heavily than clever algorithms.

## Track it here

Your progress is shared with every other list on this site -- tick a problem off
here and it is ticked off on its pattern page and in every other sheet that
includes it. That is the point of tracking them in one place.
