## Goal

From HR data, answer:

- Attrition rate
- Attrition by department/job role
- Salary and tenure differences

## Analysis pipeline

```mermaid title="HR analytics pipeline" desc="From raw employee records to attrition insights by segment."
flowchart LR
  A["Raw HR data<br/>(attrition 0/1)"] --> B["Rate<br/>(overall attrition %)"]
  B --> C["Segment<br/>(department, role)"]
  C --> D["Visualize<br/>(attrition by segment)"]
  D --> E["Conclude<br/>(interventions)"]
```

:::tip[From the book]
McKinney builds a two-way `pivot_table` (movie title x gender) instead of running
several separate `groupby` calls, because it puts both dimensions side by side in
one readable table. The same move works here: `df.pivot_table("attrition",
index="department", columns="job_role", aggfunc="mean")` shows every
department/role combination's attrition rate at once.
:::

## Step 1: Load

```python title="Load HR data" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/hr.csv")
print(df.head())
```

## Step 2: Attrition rate

```python title="Attrition" showLineNumbers{1}
rate = df["attrition"].mean()  # assuming attrition is 0/1
print("Attrition rate:", rate)
```

## Step 3: Bar plots by segment

```python title="Attrition by dept" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 4))
sns.barplot(data=df, x="department", y="attrition")
plt.title("Attrition rate by department")
plt.xticks(rotation=20)
plt.tight_layout()
plt.show()
```

## Step 4: Box plots for numeric features

```python title="Salary vs attrition" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
sns.boxplot(data=df, x="attrition", y="salary")
plt.title("Salary vs attrition")
plt.tight_layout()
plt.show()
```

## Visualize it

```p5 title="Attrition rate by department" desc="Departments with taller amber bars need attention first." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 60, gy = 20, gw = 480, gh = 190;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  const depts = ["Sales", "R&D", "HR", "Support"];
  const rates = [0.28, 0.12, 0.20, 0.15];
  const bw = gw / depts.length;
  depts.forEach((d, i) => {
    const h = rates[i] * gh * 2.2;
    fill(rates[i] > 0.2 ? [255, 211, 67] : [75, 139, 190]);
    rect(gx + i * bw + 15, gy + gh - h, bw - 30, h);
    fill(205);
    textSize(12);
    textAlign(CENTER, TOP);
    text(d, gx + i * bw + bw / 2, gy + gh + 10);
    text(Math.round(rates[i] * 100) + "%", gx + i * bw + bw / 2, gy + gh - h - 16);
  });
}
```
