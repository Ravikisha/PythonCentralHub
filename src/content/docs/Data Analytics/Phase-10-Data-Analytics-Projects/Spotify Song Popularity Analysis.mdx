## Goal

Given Spotify song features, answer:

- What does popularity distribution look like?
- Which audio features correlate with popularity?
- Do genres differ in average popularity?

## Analysis pipeline

```mermaid title="Spotify popularity analysis pipeline" desc="From raw audio features to the traits that correlate with a hit."
flowchart LR
  A["Raw features<br/>(danceability, energy, ...)"] --> B["Explore<br/>(describe, distribution)"]
  B --> C["Correlate<br/>(features vs popularity)"]
  C --> D["Visualize<br/>(heatmap)"]
  D --> E["Conclude<br/>(what predicts popularity)"]
```

## Step 1: Load

```python title="Load spotify data" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/spotify.csv")
print(df.head())
```

## Step 2: Popularity distribution

```python title="Popularity distribution" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
sns.histplot(df["popularity"], bins=30, kde=True)
plt.title("Popularity distribution")
plt.tight_layout()
plt.show()
```

:::tip[From the book]
McKinney only trusts a ranking after filtering out low-sample noise — in the
MovieLens example he drops movies with fewer than 250 ratings before ranking them,
since a single 5-star rating can look like a "top movie" by accident. Apply the
same skepticism to correlations: a strong `corr()` value driven by a couple of
outlier songs isn't a real pattern. Check the scatter, not just the number.
:::

## Step 3: Correlations

```python title="Correlation" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

num = df.select_dtypes(include="number")

plt.figure(figsize=(8, 6))
sns.heatmap(num.corr(), cmap="coolwarm", center=0)
plt.title("Correlation heatmap")
plt.tight_layout()
plt.show()
```

## Visualize it

```p5 title="Popularity distribution" desc="Most songs cluster in the middle; only a few reach very high popularity." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 50, gy = 20, gw = 500, gh = 190;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  const bins = 20;
  const bw = gw / bins;
  for (let i = 0; i < bins; i++) {
    const x = i / bins;
    const val = Math.exp(-Math.pow((x - 0.55) * 3, 2)); // bell-ish, skewed toward mid-high
    fill(255, 211, 67);
    const h = val * gh * 0.9;
    rect(gx + i * bw + 1, gy + gh - h, bw - 2, h);
  }
  fill(205);
  textSize(12);
  textAlign(CENTER, TOP);
  text("popularity: 0 -----------------> 100", gx + gw / 2, gy + gh + 10);
}
```
