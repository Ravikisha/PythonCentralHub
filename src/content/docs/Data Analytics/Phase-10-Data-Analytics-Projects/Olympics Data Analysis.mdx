## Goal

Use Olympics medals/athletes data to:

- Rank countries by medals
- See trends over years
- Identify top sports

## Analysis pipeline

```mermaid title="Olympics medal analysis pipeline" desc="From raw results to a ranked leaderboard of countries and sports."
flowchart LR
  A["Raw results"] --> B["Count<br/>(medals per country)"]
  B --> C["Rank<br/>(sort_values, top 10)"]
  C --> D["Visualize<br/>(bar chart)"]
  D --> E["Trend<br/>(medals by year)"]
```

:::tip[From the book]
Ranking countries by medal count is the same `top_counts()` idea McKinney builds
by hand in the Bitly section — group, count, then sort and take the top N. pandas
gets you there in one line: `df.groupby("country").size().sort_values(ascending=False).head(10)`
is the tidy version of writing your own `(count, key)` tuple sort.
:::

## Step 1: Load

```python title="Load" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/olympics.csv")
print(df.head())
```

## Step 2: Basic counts

```python title="Medal counts" showLineNumbers{1}
medals = df.groupby("country").size().sort_values(ascending=False).head(10)
print(medals)
```

## Step 3: Plot top countries

```python title="Top countries" showLineNumbers{1}
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 4))
plt.bar(medals.index, medals.values)
plt.title("Top 10 countries by medals")
plt.xticks(rotation=25)
plt.tight_layout()
plt.show()
```

## Visualize it

```p5 title="Top countries by medal count" desc="Horizontal bars rank countries from most to fewest medals." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const countries = ["USA", "China", "Russia", "GB", "Germany"];
  const medals = [113, 88, 71, 64, 50];
  const maxV = Math.max(...medals);
  const gx = 100, gy = 20, gw = 420, rowH = 38;
  noStroke();
  countries.forEach((c, i) => {
    const w = (medals[i] / maxV) * gw;
    fill(i === 0 ? [255, 211, 67] : [75, 139, 190]);
    rect(gx, gy + i * rowH, w, rowH - 10);
    fill(205);
    textSize(12);
    textAlign(RIGHT, CENTER);
    text(c, gx - 10, gy + i * rowH + (rowH - 10) / 2);
    textAlign(LEFT, CENTER);
    fill(230);
    text(medals[i], gx + w + 8, gy + i * rowH + (rowH - 10) / 2);
  });
}
```
