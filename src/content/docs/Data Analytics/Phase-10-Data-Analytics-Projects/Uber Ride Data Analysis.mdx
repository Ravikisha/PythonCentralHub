## Goal

Given Uber ride/trip records:

- Find peak hours and weekdays
- Visualize trip volume over time
- Identify hotspots (if location data exists)

## Analysis pipeline

```mermaid title="Uber demand analysis pipeline" desc="From raw trip timestamps to peak-hour demand patterns."
flowchart LR
  A["Raw trips<br/>(timestamps)"] --> B["Extract<br/>(hour, weekday)"]
  B --> C["Count<br/>(trips per hour/day)"]
  C --> D["Visualize<br/>(demand curve)"]
  D --> E["Conclude<br/>(peak hours/days)"]
```

:::tip[From the book]
McKinney's Bitly example counts raw frequencies with `Counter(time_zones).most_common(10)`
— a plain tally of how often each value shows up. Counting trips per hour is the exact
same idea: `df["hour"].value_counts()` (or a `countplot`) turns thousands of timestamps
into one simple frequency table you can read at a glance.
:::

## Step 1: Load and parse timestamps

```python title="Load trips" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/uber.csv")

df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")
print(df.head())
```

## Step 2: Extract time features

```python title="Time features" showLineNumbers{1}
df["hour"] = df["timestamp"].dt.hour
df["weekday"] = df["timestamp"].dt.day_name()
```

## Step 3: Plot trips by hour

```python title="Trips by hour" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(8, 4))
sns.countplot(data=df, x="hour")
plt.title("Trips by hour")
plt.tight_layout()
plt.show()
```

## Step 4: Trend over dates

```python title="Trips by day" showLineNumbers{1}
import matplotlib.pyplot as plt

daily = df.dropna(subset=["timestamp"]).groupby(df["timestamp"].dt.date).size()

plt.figure(figsize=(10, 4))
plt.plot(daily.index, daily.values)
plt.title("Trips over time")
plt.xticks(rotation=20)
plt.tight_layout()
plt.show()
```

## Visualize it

```p5 title="Trips by hour of day" desc="Tall bars around commute hours reveal the demand peaks." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 40, gy = 20, gw = 540, gh = 190;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  const hours = 24;
  const bw = gw / hours;
  for (let h = 0; h < hours; h++) {
    // two commute bumps: ~8am and ~6pm
    const morning = Math.exp(-Math.pow(h - 8, 2) / 4);
    const evening = Math.exp(-Math.pow(h - 18, 2) / 6);
    const val = 0.15 + 0.55 * Math.max(morning, evening);
    const isPeak = val > 0.5;
    fill(isPeak ? [255, 211, 67] : [75, 139, 190]);
    const barH = val * gh;
    rect(gx + h * bw + 1, gy + gh - barH, bw - 2, barH);
  }
  fill(205);
  textSize(11);
  textAlign(CENTER, TOP);
  text("0h", gx, gy + gh + 6);
  text("12h", gx + gw / 2, gy + gh + 6);
  text("23h", gx + gw - 10, gy + gh + 6);
}
```
