## Goal

Given tweets and sentiment labels (or sentiment scores):

- Clean text
- Explore sentiment distribution
- Visualize sentiment over time (if timestamps exist)

## Analysis pipeline

```mermaid title="Twitter sentiment analysis pipeline" desc="From raw noisy tweets to a clean sentiment distribution."
flowchart LR
  A["Raw tweets"] --> B["Clean text<br/>(urls, mentions, hashtags)"]
  B --> C["Explore<br/>(sentiment counts)"]
  C --> D["Visualize<br/>(distribution / trend)"]
  D --> E["Conclude<br/>(dominant sentiment)"]
```

:::tip[From the book]
McKinney faces the same problem parsing Bitly's `"a"` (user agent) field: one raw
string packs URLs, symbols, and noise together, so he strips it down to the first
useful token before counting anything. Tweets need the same treatment — strip URLs,
`@mentions`, and `#` symbols with regex *before* you count or model sentiment, or
the noise will drown out the signal.
:::

## Step 1: Load

import pandas as pd

## Step 2: Basic text cleaning

```python title="Clean text" showLineNumbers{1}
import re

def clean_tweet(s: str) -> str:
    s = re.sub(r"http\S+", "", s)       # remove URLs
    s = re.sub(r"@\w+", "", s)         # remove mentions
    s = re.sub(r"#", "", s)            # remove hashtag symbol
    s = re.sub(r"\s+", " ", s).strip() # normalize whitespace
    return s

if "text" in df.columns:
    df["text_clean"] = df["text"].astype(str).apply(clean_tweet)
```

## Step 3: Sentiment distribution

```python title="Sentiment counts" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
sns.countplot(data=df, x="sentiment")
plt.title("Sentiment distribution")
plt.tight_layout()
plt.show()
```

## Visualize it

```p5 title="Sentiment distribution" desc="Bar height shows how many tweets fall into each sentiment bucket." height="250"
function setup() {
  createCanvas(600, 250);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 80, gy = 20, gw = 420, gh = 170;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  const labels = ["Positive", "Neutral", "Negative"];
  const vals = [0.55, 0.3, 0.15];
  const colors = [[255, 211, 67], [140, 148, 158], [75, 139, 190]];
  const bw = gw / labels.length;
  labels.forEach((l, i) => {
    const h = vals[i] * gh;
    fill(colors[i][0], colors[i][1], colors[i][2]);
    rect(gx + i * bw + 25, gy + gh - h, bw - 50, h);
    fill(205);
    textAlign(CENTER, TOP);
    textSize(12);
    text(l, gx + i * bw + bw / 2, gy + gh + 10);
    text(Math.round(vals[i] * 100) + "%", gx + i * bw + bw / 2, gy + gh - h - 16);
  });
}
```
