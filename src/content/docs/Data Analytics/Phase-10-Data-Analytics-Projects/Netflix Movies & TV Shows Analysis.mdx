## Step 1: Load and parse dates

```python title="Load dataset" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/netflix_titles.csv")

if "date_added" in df.columns:
    df["date_added"] = pd.to_datetime(df["date_added"], errors="coerce")

print(df.shape)
print(df.head())
```

## Step 2: Clean multi-valued country/genre

The dataset often stores multiple values separated by commas.

```python title="Split and explode" showLineNumbers{1}
# Countries
if "country" in df.columns:
    countries = (
        df.dropna(subset=["country"])
          .assign(country=df["country"].str.split(","))
          .explode("country")
    )
    countries["country"] = countries["country"].str.strip()

# Genres
if "listed_in" in df.columns:
    genres = (
        df.dropna(subset=["listed_in"])
          .assign(genre=df["listed_in"].str.split(","))
          .explode("genre")
    )
    genres["genre"] = genres["genre"].str.strip()
```

:::tip[From the book]
McKinney parses the Bitly `"a"` (user agent) field by splitting on whitespace and
keeping just the first token, because the raw string packs too much into one cell.
`country` and `listed_in` have the same problem here — one cell holds several
values joined by commas. `str.split(",")` + `explode()` turns each into its own
row so `value_counts()` can count them correctly, one country/genre at a time.
:::

## Step 4: Top countries

```python title="Top countries" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

if "country" in df.columns:
    top_c = countries["country"].value_counts().head(10).reset_index()
    top_c.columns = ["country", "count"]

    plt.figure(figsize=(10, 4))
    sns.barplot(data=top_c, x="count", y="country")
    plt.title("Top 10 countries by number of titles")
    plt.tight_layout()
    plt.show()
```

## Step 5: Additions over time

```python title="Titles added by year" showLineNumbers{1}
import matplotlib.pyplot as plt

if "date_added" in df.columns:
    yearly = df.dropna(subset=["date_added"]).groupby(df["date_added"].dt.year).size()

    plt.figure(figsize=(8, 4))
    plt.plot(yearly.index, yearly.values, marker="o")
    plt.title("Titles added by year")
    plt.xlabel("Year")
    plt.ylabel("Count")
    plt.tight_layout()
    plt.show()
```
