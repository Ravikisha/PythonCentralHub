## Goal

Perform EDA on the Titanic dataset and produce:

- Data quality findings (missing values, types)
- A handful of clear plots
- Insights about survival patterns

## Analysis pipeline

Every EDA project follows the same rhythm: load the raw file, fix the messy parts,
ask simple questions of the clean data, draw a picture, then write down what you saw.

```mermaid title="Titanic EDA pipeline" desc="From raw CSV to survival insights, one stage at a time."
flowchart LR
  A["Raw CSV<br/>(Titanic passengers)"] --> B["Clean<br/>(fill Embarked, flag Cabin)"]
  B --> C["Explore<br/>(value_counts, groupby)"]
  C --> D["Visualize<br/>(survival by sex/class/fare)"]
  D --> E["Conclude<br/>(who survived, and why)"]
```

Focus on missing in:

- `Age`
- `Cabin`
- `Embarked`

:::tip[From the book]
McKinney's Bitly example hits the exact same wall: the first pass at counting time
zones crashes with a `KeyError` because some records simply don't have a `tz` field.
His fix is to keep the gap instead of hiding it — filter it in a list comprehension,
or bucket it as `"Unknown"` before counting. Do the same here: `Cabin` is missing on
most passengers, so turn "missing" into a signal (`has_cabin`) rather than deleting it.
:::

## Step 3: Clean minimal issues

### Handle missing Embarked (small)

```python title="Embarked fill" showLineNumbers{1}
if "Embarked" in df.columns:
    df["Embarked"] = df["Embarked"].fillna(df["Embarked"].mode().iloc[0])
```

### Keep Cabin as “has cabin” flag

```python title="Cabin flag" showLineNumbers{1}
if "Cabin" in df.columns:
    df["has_cabin"] = df["Cabin"].notna()
```

## Visualize it

A `pivot_table` collapses "survival by sex" and "survival by class" into a single
matrix — the same trick McKinney uses to get mean movie ratings by gender in one
line instead of several separate `groupby` calls.

```python title="Survival matrix" showLineNumbers{1}
matrix = df.pivot_table("Survived", index="Pclass", columns="Sex", aggfunc="mean")
print(matrix)
```

```p5 title="Survival rate by class and sex" desc="Taller amber bars mean a higher survival rate for that class/sex group." height="280"
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  // rough survival rates per (class, sex) — illustrative, not live data
  const rates = {
    female: [0.97, 0.92, 0.5],
    male: [0.37, 0.16, 0.14],
  };
  const classes = ["1st", "2nd", "3rd"];
  const groupW = 160, barW = 46, gx = 60, gy = 30, gh = 200;
  stroke(60, 70, 84);
  line(gx - 10, gy + gh, gx + groupW * 3, gy + gh);
  noStroke();
  for (let c = 0; c < 3; c++) {
    const baseX = gx + c * groupW;
    ["female", "male"].forEach((sex, i) => {
      const rate = rates[sex][c];
      const h = rate * gh;
      fill(sex === "female" ? [255, 211, 67] : [75, 139, 190]);
      rect(baseX + i * (barW + 10), gy + gh - h, barW, h);
      fill(205);
      textSize(11);
      textAlign(CENTER, TOP);
      text(Math.round(rate * 100) + "%", baseX + i * (barW + 10) + barW / 2, gy + gh - h - 16);
    });
    fill(205);
    textSize(13);
    textAlign(CENTER, TOP);
    text(classes[c] + " class", baseX + barW + 5, gy + gh + 10);
  }
  fill(255, 211, 67);
  textAlign(LEFT, TOP);
  text("amber = female", 20, 8);
  fill(75, 139, 190);
  text("blue = male", 160, 8);
}
```
