## Goal

Given a customer dataset with `churn` (0/1), analyze:

- Overall churn rate
- Churn by segment (plan, region)
- Numeric differences (tenure, usage)


## Step 2: Churn rate

```python title="Overall churn" showLineNumbers{1}
rate = df["churn"].mean()
print("Churn rate:", rate)
```

:::tip[From the book]
A neat idiom that shows up throughout the book: the mean of a 0/1 column is a rate.
`df["churn"].mean()` isn't just an average — it's literally "the fraction of
customers who churned." Combine it with `groupby("plan")["churn"].mean()` and you
get a churn rate *per plan* with the same one-line pattern McKinney uses for group
means everywhere in this chapter.
:::

## Visualize it

```p5 title="Stayed vs churned" desc="A donut chart makes the overall churn rate easy to read at a glance." height="250"
function setup() {
  createCanvas(600, 250);
  textFont("monospace");
  angleMode(DEGREES);
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const cx = 150, cy = 125, r = 85;
  const churnPct = 0.27; // illustrative
  noStroke();
  fill(255, 211, 67);
  arc(cx, cy, r * 2, r * 2, 0, 360 * churnPct);
  fill(75, 139, 190);
  arc(cx, cy, r * 2, r * 2, 360 * churnPct, 360);
  fill(13, 17, 23);
  circle(cx, cy, r);
  fill(230);
  textAlign(CENTER, CENTER);
  textSize(15);
  text(Math.round(churnPct * 100) + "%\nchurned", cx, cy);

  textAlign(LEFT, TOP);
  textSize(13);
  fill(255, 211, 67);
  text("amber = churned", 300, 100);
  fill(75, 139, 190);
  text("blue = stayed", 300, 122);
}
```
