:::tip[From the book]
McKinney always checks a column's shape with `frame.info()` before doing anything
else, because dtypes and missing values quietly break later steps. Housing prices
are a classic case where the raw distribution is also worth a look: prices are
usually right-skewed (a few very expensive homes stretch the tail), which is why
many regression pipelines model `log(price)` instead of raw price.
:::

## Visualize it

```p5 title="House price distribution (right-skewed)" desc="Most homes cluster on the left; a long tail of expensive homes stretches right." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 50, gy = 20, gw = 500, gh = 190;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  const bins = 24;
  const bw = gw / bins;
  for (let i = 0; i < bins; i++) {
    const x = i / bins;
    // right-skewed shape: peak near the low end, long thin tail to the right
    const val = Math.exp(-x * 4.5) + 0.03;
    fill(75, 139, 190);
    const h = Math.min(1, val) * gh * 0.9;
    rect(gx + i * bw + 1, gy + gh - h, bw - 2, h);
  }
  fill(205);
  textSize(12);
  textAlign(CENTER, TOP);
  text("price: low -----------------------------------> high (few, expensive homes)", gx + gw / 2, gy + gh + 10);
}
```
