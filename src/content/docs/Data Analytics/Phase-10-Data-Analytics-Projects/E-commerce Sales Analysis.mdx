## Goal

Given an e-commerce orders dataset, answer:

- Overall revenue and order trends
- Top products / categories
- Average order value (AOV)
- Revenue by segment (city, category)

## Analysis pipeline

```mermaid title="E-commerce sales pipeline" desc="From raw orders to the revenue drivers behind them."
flowchart LR
  A["Raw orders<br/>(CSV)"] --> B["Clean<br/>(parse dates, revenue = qty * price)"]
  B --> C["KPIs<br/>(orders, AOV)"]
  C --> D["Visualize<br/>(monthly trend, top products)"]
  D --> E["Conclude<br/>(main revenue drivers)"]
```

## Example columns

- `order_id`, `order_date`, `customer_id`
- `product`, `category`, `qty`, `price`
- `city`, `status`

## Step 1: Load and basic prep

```python title="Load" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/orders.csv")

df["order_date"] = pd.to_datetime(df["order_date"], errors="coerce")

df["revenue"] = df["qty"] * df["price"]

print(df.shape)
print(df.head())
```

:::tip[From the book]
McKinney's FEC donations example builds a derived column (`over_386`) then groups by
it to answer real questions, instead of eyeballing raw rows. Do the same here:
`revenue = qty * price` is a derived column too — build it once, then every KPI
(total revenue, AOV, top products) is just a `groupby`/`sum`/`mean` away.
:::

## Step 2: KPIs

```python title="KPIs" showLineNumbers{1}
orders = df["order_id"].nunique()
customers = df["customer_id"].nunique()
revenue = df["revenue"].sum()
aov = revenue / orders

print("orders:", orders)
print("customers:", customers)
print("revenue:", revenue)
print("aov:", aov)
```

## Step 3: Revenue trend

```python title="Monthly revenue" showLineNumbers{1}
import matplotlib.pyplot as plt

monthly = (
    df.dropna(subset=["order_date"])
      .groupby(df["order_date"].dt.to_period("M"))
      .agg(revenue=("revenue", "sum"), orders=("order_id", "nunique"))
      .reset_index()
)

monthly["order_date"] = monthly["order_date"].astype(str)

plt.figure(figsize=(10, 4))
plt.plot(monthly["order_date"], monthly["revenue"], marker="o")
plt.title("Monthly revenue")
plt.xticks(rotation=30)
plt.tight_layout()
plt.show()
```

## Step 4: Top products

```python title="Top products" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

top = (
    df.groupby("product")
      .agg(revenue=("revenue", "sum"))
      .sort_values("revenue", ascending=False)
      .head(10)
      .reset_index()
)

plt.figure(figsize=(10, 4))
sns.barplot(data=top, x="revenue", y="product")
plt.title("Top 10 products by revenue")
plt.tight_layout()
plt.show()
```

```p5 title="Monthly revenue trend" desc="A rising line means revenue is growing month over month; dips are worth investigating." height="260"
function setup() {

function draw() {
  background(13, 17, 23);
  const gx = 50, gy = 20, gw = 520, gh = 190;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  line(gx, gy, gx, gy + gh);
  const pts = [0.3, 0.35, 0.32, 0.42, 0.5, 0.48, 0.58, 0.55, 0.68, 0.72, 0.66, 0.85];
  noFill();
  stroke(255, 211, 67);
  strokeWeight(2.5);
  beginShape();
  pts.forEach((v, i) => vertex(gx + (i / (pts.length - 1)) * gw, gy + gh - v * gh));
  endShape();
  noStroke();
  fill(75, 139, 190);
  pts.forEach((v, i) => circle(gx + (i / (pts.length - 1)) * gw, gy + gh - v * gh, 6));
  fill(205);
  textSize(12);
  textAlign(CENTER, TOP);
  text("Jan -> Dec (monthly revenue)", gx + gw / 2, gy + gh + 12);
}
```
