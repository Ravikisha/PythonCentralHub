## Goal

Use GTD-like incident data to:

- Visualize incidents over time
- Compare regions
- Identify major trend changes

## Important note

This is a sensitive dataset. Focus on **high-level aggregated analysis** and avoid sensationalizing.

## Analysis pipeline

```mermaid title="GTD trend analysis pipeline" desc="From raw incident records to a responsible, aggregated summary."
flowchart LR
  A["Raw incidents"] --> B["Aggregate<br/>(by year, region)"]
  B --> C["Visualize<br/>(trend line, top regions)"]
  C --> D["Caveat<br/>(missing/reporting bias)"]
  D --> E["Conclude<br/>(high-level summary)"]
```

:::caution[From the book]
When McKinney hits missing values in the Bitly `tz` field, he doesn't silently drop
them — he buckets them as `"Unknown"` so the count is honest about what's actually
known. Do the same with incident data: a region with sparse or inconsistent
reporting isn't necessarily "safer," it may just be under-recorded. Always caption
aggregated charts with a note about missingness and reporting bias.
:::

## Step 1: Load

```python title="Load" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/gtd.csv")
print(df.head())
```

## Step 2: Incidents by year

```python title="Incidents per year" showLineNumbers{1}
import matplotlib.pyplot as plt

yearly = df.groupby("year").size()

plt.figure(figsize=(10, 4))
plt.plot(yearly.index, yearly.values)
plt.title("Incidents by year")
plt.xlabel("Year")
plt.ylabel("Count")
plt.tight_layout()
plt.show()
```

## Step 3: Compare regions

```python title="Top regions" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

regions = df["region"].value_counts().head(10).reset_index()
regions.columns = ["region", "count"]

plt.figure(figsize=(10, 4))
sns.barplot(data=regions, x="count", y="region")
plt.title("Top regions by incident count")
plt.tight_layout()
plt.show()
```

## Visualize it

```p5 title="Incidents by year" desc="A single amber line shows the overall trend across years; annotate any sharp turns." height="250"
function setup() {
  createCanvas(600, 250);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 50, gy = 20, gw = 500, gh = 170;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  line(gx, gy, gx, gy + gh);
  const pts = [0.15, 0.18, 0.22, 0.3, 0.45, 0.62, 0.8, 0.7, 0.55, 0.4, 0.35, 0.3];
  noFill();
  stroke(255, 211, 67);
  strokeWeight(2.5);
  beginShape();
  pts.forEach((v, i) => vertex(gx + (i / (pts.length - 1)) * gw, gy + gh - v * gh));
  endShape();
  noStroke();
  fill(205);
  textSize(11);
  textAlign(CENTER, TOP);
  text("years -->  (peak mid-series, decline after)", gx + gw / 2, gy + gh + 10);
}
```
