## Goal

Given daily stock prices, compute:

- Daily returns
- Rolling averages
- Volatility
- Compare multiple stocks

## Analysis pipeline

```mermaid title="Stock analysis pipeline" desc="From raw daily prices to a smoothed trend with a volatility measure."
flowchart LR
  A["Raw prices<br/>(date, close)"] --> B["Returns<br/>(pct_change)"]
  B --> C["Smooth<br/>(20/50-day MA)"]
  C --> D["Visualize<br/>(price + MA lines)"]
  D --> E["Volatility<br/>(rolling std)"]
```

:::tip[From the book]
The whole point of this final chapter, McKinney says, is that the *same handful of
tools* — load, derive a column, group or roll, then plot — solves very different
problems. `pct_change()` for daily returns and `.rolling(20).mean()` for a moving
average are just vectorized versions of "compare today to yesterday" and "average
the last N days," so you never need a manual loop over rows.
:::

## Dataset columns

- `date`, `close` (and optionally open/high/low/volume)

## Step 1: Load and parse

```python title="Load prices" showLineNumbers{1}
import pandas as pd

df = pd.read_csv("data/stock.csv")
df["date"] = pd.to_datetime(df["date"], errors="coerce")
df = df.sort_values("date")
print(df.head())
```

## Step 2: Daily returns

```python title="Returns" showLineNumbers{1}
df["return"] = df["close"].pct_change()
print(df[["date", "close", "return"]].head(10))
```

## Step 3: Moving averages

```python title="Moving averages" showLineNumbers{1}
df["ma20"] = df["close"].rolling(20).mean()
df["ma50"] = df["close"].rolling(50).mean()
```

## Step 4: Plot

```python title="Plot price + MA" showLineNumbers{1}
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 4))
plt.plot(df["date"], df["close"], label="close")
plt.plot(df["date"], df["ma20"], label="MA20")
plt.plot(df["date"], df["ma50"], label="MA50")
plt.title("Price and moving averages")
plt.legend()
plt.xticks(rotation=20)
plt.tight_layout()
plt.show()
```

## Step 5: Volatility (rolling std)

```python title="Volatility" showLineNumbers{1}
df["volatility_20"] = df["return"].rolling(20).std()
```

## Visualize it

```p5 title="Close price with moving averages" desc="The raw close price (blue) vs its smoother 20-day (amber) and 50-day (green) averages." height="270"
function setup() {
  createCanvas(600, 270);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 50, gy = 20, gw = 520, gh = 190;
  stroke(60, 70, 84);
  line(gx, gy + gh, gx + gw, gy + gh);
  line(gx, gy, gx, gy + gh);

  let seed = 11;
  function rnd() { seed = (seed * 9301 + 49297) % 233280; return seed / 233280; }
  const n = 60;
  const close = [];
  for (let i = 0; i < n; i++) {
    close.push(0.4 + i / (n * 1.6) + Math.sin(i / 6) * 0.08 + (rnd() - 0.5) * 0.06);
  }
  function ma(window) {
    const out = [];
    for (let i = 0; i < n; i++) {
      const start = Math.max(0, i - window + 1);
      let s = 0, c = 0;
      for (let k = start; k <= i; k++) { s += close[k]; c++; }
      out.push(s / c);
    }
    return out;
  }
  const ma20 = ma(20), ma50 = ma(50);
  function plotLine(series, col, weight) {
    noFill();
    stroke(col[0], col[1], col[2]);
    strokeWeight(weight);
    beginShape();
    series.forEach((v, i) => vertex(gx + (i / (n - 1)) * gw, gy + gh - v * gh));
    endShape();
  }
  plotLine(close, [75, 139, 190], 1);
  plotLine(ma20, [255, 211, 67], 2.5);
  plotLine(ma50, [120, 200, 120], 2.5);

  noStroke();
  fill(205);
  textSize(11);
  textAlign(LEFT, TOP);
  text("blue = close   amber = MA20   green = MA50", gx, 4);
}
```
