## What is Google Colab?

**Google Colab (Colaboratory)** is a free, cloud-hosted Jupyter Notebook environment.

It allows you to:

- Run Python in the browser (no local install)
- Use **free GPUs/TPUs** (great for ML workloads)
- Share notebooks easily
- Connect to Google Drive

For data analytics, Colab is excellent when:

- Your machine is slow
- You want a quick setup
- You want to share a notebook link with others

## Create a new notebook

1. Go to: https://colab.research.google.com/
2. Sign in with a Google account
3. Click **New notebook**

A notebook opens with a default code cell.

## Understanding Colab interface

Key menus you’ll use:

- **Runtime**: run cells, restart runtime, change hardware
- **File**: save a copy, download `.ipynb`, download `.py`
- **Edit**: find/replace, shortcuts

Colab runs notebooks on remote servers called a **runtime**.

## Run your first code

In a code cell:

```python title="hello" showLineNumbers{1}
print("Hello from Colab")
```

Run with `Shift + Enter`.

## Uploading datasets

You have a few common options.

### Option 1: Upload directly (temporary)

- Left sidebar → **Files**
- Click **Upload** and choose your CSV

Important:

- Uploaded files are stored in the runtime temporary disk.
- If the runtime resets, uploaded files are gone.

### Option 2: Google Drive (recommended)

Mount your Drive:

```python title="mount-drive" showLineNumbers{1}
from google.colab import drive
drive.mount('/content/drive')
```

Then access files like:

```python title="read-csv" showLineNumbers{1}
import pandas as pd
path = "/content/drive/MyDrive/data/titanic.csv"
df = pd.read_csv(path)
df.head()
```

### Option 3: Download from a URL

```python title="download" showLineNumbers{1}
import pandas as pd
url = "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv"
df = pd.read_csv(url)
df.head()
```

## Installing packages in Colab

Colab has many libraries installed, but not everything.

Use `pip` inside a notebook:

```python title="pip-install" showLineNumbers{1}
!pip install yfinance
```

Or make it a bit quieter:

```python title="pip-install-q" showLineNumbers{1}
!pip -q install yfinance
```

:::note
Colab resets
If your runtime restarts, you may need to reinstall packages.
It’s normal.
:::

## Changing runtime hardware (GPU/TPU)

1. `Runtime` → `Change runtime type`
2. Set:
   - Hardware accelerator: **GPU** (or TPU)

You can confirm GPU availability:

```python title="check-gpu" showLineNumbers{1}
import torch
print("CUDA available:", torch.cuda.is_available())
```

(If you don’t use PyTorch, you can also check with other tools.)

## Saving and exporting your work

### Save to Drive

- `File` → `Save a copy in Drive`

### Download notebook

- `File` → `Download` → `.ipynb`

### Export to Python

- `File` → `Download` → `.py`

## Visualize it

A Colab notebook is the same execute-explore experience as local Jupyter, just running on a remote machine.

```mermaid title="Colab runtime lifecycle" desc="From opening a new notebook to a connected, ready-to-run cloud runtime"
flowchart LR
  A["Open colab.research.google.com"] --> B["New notebook"]
  B --> C["Connect to a runtime (CPU/GPU/TPU)"]
  C --> D["Mount Drive or upload data"]
  D --> E["Run cells with Shift+Enter"]
  E --> F["Save to Drive / download .ipynb"]
```

:::note[From the book]
McKinney's book was written around a local IPython/Jupyter setup, but the underlying model is identical in Colab: a **kernel process runs your code and keeps variables alive between cells**, while the notebook document just records the code, Markdown, and output. Everything you learned about cells, kernels, and the `In [n]:` execution counter transfers directly — the only difference is that Colab's kernel lives on Google's servers instead of your laptop.
:::

## Colab tips for data analytics

### Quickly preview data

```python title="preview" showLineNumbers{1}
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "city": ["Delhi", "Mumbai", "Pune"],
    "sales": [120, 90, 150]
})

df
```

### Display full columns/rows (Pandas)

```python title="pandas-options" showLineNumbers{1}
import pandas as pd
pd.set_option("display.max_columns", None)
pd.set_option("display.max_rows", 100)
```
