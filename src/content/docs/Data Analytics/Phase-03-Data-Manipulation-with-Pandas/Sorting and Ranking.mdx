## Two different questions: sort vs rank

- **Sorting** rearranges rows so they appear in order.
- **Ranking** assigns each value a position number (1st, 2nd, 3rd...) *without*
  rearranging anything — the rank becomes a new column or Series aligned to the
  original order.

Both are everyday analytics needs: sorting a leaderboard, ranking students by score.

## Sorting by index: sort_index

```python title="sort_index" showLineNumbers{1}
import pandas as pd
import numpy as np

obj = pd.Series([4, 7, -3, 2, np.nan], index=["d", "a", "c", "b", "e"])
print(obj.sort_index())  # sorted lexicographically by label
```

## Sorting by value: sort_values

```python title="sort_values" showLineNumbers{1}
print(obj.sort_values())
```

Missing values sort to the **end** by default. Use `na_position="first"` to flip that:

```python title="Controlling where NaN lands" showLineNumbers{1}
print(obj.sort_values(na_position="first"))
```

## Sorting a DataFrame by one or more columns

```python title="Sort a DataFrame by column values" showLineNumbers{1}
frame = pd.DataFrame({"b": [4, 7, -3, 2], "a": [0, 1, 0, 1]})

print(frame.sort_values("b"))          # single column
print(frame.sort_values(["a", "b"]))   # tie-break: sort by "a" first, then "b"
```

## Ranking: rank()

`rank()` assigns each value a position from 1 through the number of valid points,
starting at the lowest value. Ties are handled by **averaging** their ranks by default:

```python title="rank() with default tie-breaking" showLineNumbers{1}
s = pd.Series([7, -5, 7, 4, 2, 0, 4])
print(s.rank())
```

Both `7`s tie for ranks 6 and 7, so they each get the average, `6.5`. Other tie-break
rules are available via `method`:

```python title="Tie-breaking methods" showLineNumbers{1}
print(s.rank(method="first"))  # ties broken by order of appearance
print(s.rank(method="min"))    # ties get the lowest rank in the group
print(s.rank(ascending=False)) # rank from highest to lowest instead
```

| `method` | What it does |
|----------|---------------|
| `"average"` | Default — tied values share the mean rank |
| `"min"` | Tied values all get the lowest rank in the group |
| `"max"` | Tied values all get the highest rank in the group |
| `"first"` | Ties broken by the order values appear in the data |
| `"dense"` | Like `"min"`, but ranks always increase by exactly 1 between groups |

## Common pitfalls

- `sort_values()` on a Series with `NaN` puts them last — easy to miss if you don't
  scroll to the bottom of a big result.
- `rank()`'s default `"average"` method can produce fractional ranks (`6.5`) — if you
  need whole-number ranks for display, use `method="first"` or `method="dense"`.
- Sorting returns a **new** object; it doesn't sort in place unless you pass
  `inplace=True` (and even then, prefer reassigning — it's clearer).

```p5 title="Bars reordering by sort_values" desc="The faded bars show the original order; the solid bars show the same values after sort_values() rearranges them ascending." height="240"
function setup() {
  createCanvas(600, 240);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const values = [40, 70, -30, 20];
  const sortedValues = [-30, 20, 40, 70];
  const n = values.length;
  const barW = 50;
  const gap = 30;
  const baseY = 200;
  const maxV = 70, minV = -30;

  textSize(11);
  fill(180);
  noStroke();
  text("before sort_values()", 20, 20);
  text("after sort_values()", 320, 20);

  for (let i = 0; i < n; i++) {
    const h = map(Math.abs(values[i]), 0, maxV, 10, 90);
    const x = 30 + i * (barW + gap);
    fill(255, 211, 67, 90);
    rect(x, baseY - h, barW, h, 4);
    fill(200);
    textAlign(CENTER, CENTER);
    text(values[i], x + barW / 2, baseY + 15);
  }

  for (let i = 0; i < n; i++) {
    const h = map(Math.abs(sortedValues[i]), 0, maxV, 10, 90);
    const x = 320 + i * (barW + gap);
    fill(75, 139, 190, 220);
    rect(x, baseY - h, barW, h, 4);
    fill(230);
    textAlign(CENTER, CENTER);
    text(sortedValues[i], x + barW / 2, baseY + 15);
  }
}
```

:::tip[From the book]
McKinney notes that `rank()`'s default tie-breaking method, `"average"`, means two
tied values each receive the mean of the ranks they would have occupied. If you've
ever wondered why a rank column has decimals like `6.5`, this is why — switch to
`method="first"` or `method="min"` if you need whole numbers.
:::
