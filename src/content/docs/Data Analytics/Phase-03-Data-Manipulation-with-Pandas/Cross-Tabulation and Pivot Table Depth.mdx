## One question, three tools

"How many rows fall into each combination of category A and category B?" is one of
the most common analytics questions — and pandas has three ways to answer it:
`groupby`, `pivot_table`, and `crosstab`. They overlap on purpose; picking the right
one is mostly about which shape of answer you want.

:::tip[From the book]
McKinney describes `pivot_table` as "a convenience interface to `groupby`, combined
with reshape operations" — under the hood it's doing the same split-apply-combine
work you already know, just arranging the group keys as rows and columns instead of
a single index. `crosstab`, in turn, is "a special case of a pivot table that
computes group frequencies" — it's `pivot_table` with `aggfunc="count"` built in.
:::

## Example dataset

```python title="A small survey" showLineNumbers{1}
import pandas as pd

survey = pd.DataFrame({
    "nationality": ["USA", "Japan", "USA", "Japan", "Japan", "USA"],
    "handedness": ["Right", "Left", "Right", "Right", "Left", "Right"],
})

print(survey)
```

## crosstab: counting combinations

`pd.crosstab(rows, columns)` counts how many times each combination of two (or more)
categorical values occurs — no `values=` or `aggfunc=` needed, it's frequency by
default:

```python title="Basic crosstab" showLineNumbers{1}
print(pd.crosstab(survey["nationality"], survey["handedness"]))
```

### Adding row/column totals with margins

```python title="crosstab with margins" showLineNumbers{1}
print(pd.crosstab(survey["nationality"], survey["handedness"], margins=True))
```

The `"All"` row and column are the totals across that dimension — 3 Japanese
respondents, 3 American respondents, 6 total.

### Normalizing into proportions

Raw counts don't tell you whether a pattern is proportionally strong. Pass
`normalize="index"` to turn each **row** into percentages that sum to 1:

```python title="crosstab with normalize" showLineNumbers{1}
print(pd.crosstab(survey["nationality"], survey["handedness"], normalize="index"))
```

Now you can see that 100% of the American respondents in this sample are
right-handed, versus about 33% of the Japanese respondents.

## pivot_table: aggregating a numeric column by category

`pivot_table` answers a related but different question: not "how many rows,"
but "what's the **sum** (or mean, or any aggregate) of some numeric column,"
broken down by category:

```python title="pivot_table: sum of amount by city and category" showLineNumbers{1}
sales = pd.DataFrame({
    "city": ["pune", "pune", "delhi", "delhi", "delhi", "pune"],
    "category": ["A", "B", "A", "A", "B", "A"],
    "amount": [100, 200, 150, 120, 300, 80],
})

summary = sales.pivot_table(index="city", columns="category", values="amount", aggfunc="sum")
print(summary)
```

### margins and multiple aggregations

Just like `crosstab`, `pivot_table` accepts `margins=True` for row/column totals. It
also accepts a **list** of aggregation functions to compute several statistics at once:

```python title="pivot_table with margins" showLineNumbers{1}
print(sales.pivot_table(index="city", columns="category", values="amount", aggfunc="sum", margins=True))
```

```python title="pivot_table with multiple aggfuncs" showLineNumbers{1}
print(sales.pivot_table(index="city", values="amount", aggfunc=["sum", "mean"]))
```

## crosstab vs pivot_table vs groupby

| Tool | Best for | Default aggregation |
|------|----------|----------------------|
| `groupby(...).agg(...)` | Full control, any number of metrics/columns | You choose |
| `pivot_table` | A numeric column, aggregated by 1-2 categorical keys, arranged as a grid | `"mean"` |
| `crosstab` | Just counting how often category combinations occur | `"count"` |

Anything `crosstab` can do, `pivot_table(..., aggfunc="count")` can also do — reach
for `crosstab` when you specifically want frequencies, since it reads more clearly.

## Common pitfalls

- `pivot_table`'s default `aggfunc` is `"mean"` — if you actually want totals, you
  must pass `aggfunc="sum"` explicitly, or you'll get a quietly wrong answer.
- Empty (index, column) combinations become `NaN` unless you pass `fill_value=0`.
- `margins=True`'s `"All"` row/column is computed over the **entire** dataset, not
  just an average of the other rows/columns you can see — don't average it in by hand.

```p5 title="A contingency grid: counts per combination" desc="Each cell counts how many survey rows share that row category and that column category - the core idea behind crosstab." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const rowLabels = ["Japan", "USA", "All"];
  const colLabels = ["Left", "Right", "All"];
  const grid = [
    [2, 1, 3],
    [0, 3, 3],
    [2, 4, 6],
  ];
  const cellW = 110, cellH = 44;
  const originX = 160, originY = 60;

  textAlign(CENTER, CENTER);
  textSize(12);
  fill(255, 211, 67);
  text("handedness ->", originX + cellW * 1.5, originY - 30);

  for (let c = 0; c < colLabels.length; c++) {
    fill(255, 211, 67);
    text(colLabels[c], originX + c * cellW + cellW / 2, originY - 10);
  }
  for (let r = 0; r < rowLabels.length; r++) {
    fill(255, 211, 67);
    textAlign(RIGHT, CENTER);
    text(rowLabels[r], originX - 12, originY + r * cellH + cellH / 2);
  }

  for (let r = 0; r < rowLabels.length; r++) {
    for (let c = 0; c < colLabels.length; c++) {
      const x = originX + c * cellW;
      const y = originY + r * cellH;
      const isMargin = r === 2 || c === 2;
      noStroke();
      fill(isMargin ? color(255, 255, 255, 10) : color(75, 139, 190, 60));
      rect(x, y, cellW - 6, cellH - 6, 4);
      fill(230);
      textAlign(CENTER, CENTER);
      textSize(13);
      text(grid[r][c], x + (cellW - 6) / 2, y + (cellH - 6) / 2);
    }
  }
}
```
