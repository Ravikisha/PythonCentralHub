## What resampling means

**Resampling** converts a time series from one frequency to another:

- **Downsampling** — high frequency → low frequency (minute data → daily totals). This
  always needs an aggregation, because many points collapse into one bucket.
- **Upsampling** — low frequency → high frequency (weekly data → daily rows). This
  creates new rows, which start out empty unless you fill them.

`.resample()` has a similar API to `.groupby()`: call `resample()` to define the
buckets, then call an aggregation like `.sum()` or `.mean()`.

## Downsampling: many points into one bucket

```python title="Minute data into 5-minute buckets" showLineNumbers{1}
import pandas as pd

idx = pd.date_range("2024-01-01", periods=12, freq="min")
ts = pd.Series(range(12), index=idx)

print(ts.resample("5min").sum())
```

Two choices control how buckets are formed:

- `closed` — which edge of each interval is inclusive (`"left"` or `"right"`).
- `label` — whether the result is labeled with the left or right edge.

```python title="closed and label options" showLineNumbers{1}
print(ts.resample("5min", closed="right").sum())
print(ts.resample("5min", closed="right", label="right").sum())
```

## OHLC: a finance-flavored aggregation

For price data, a common summary per bucket is **open, high, low, close** — computed
in one call:

```python title="OHLC resampling" showLineNumbers{1}
print(ts.resample("5min").ohlc())
```

## Upsampling: creating new rows

Going from weekly to daily creates rows that don't exist yet — they start as `NaN`
unless you tell pandas how to fill them:

```python title="Upsampling with asfreq vs ffill" showLineNumbers{1}
weekly = pd.DataFrame(
    {"a": [1, 2]},
    index=pd.date_range("2024-01-03", periods=2, freq="W-WED"),
)

print(weekly.resample("D").asfreq())  # new rows are NaN
print(weekly.resample("D").ffill())   # new rows carry the last known value forward
```

## resample vs groupby

Both split data into buckets and apply a function — the difference is what defines a
bucket:

- `groupby("column")` groups by the **values** in a column.
- `resample("2D")` groups by **fixed time intervals**, regardless of how many rows
  fall into each one.

```python title="A resample call, side by side with what groupby does" showLineNumbers{1}
sales = pd.DataFrame(
    {"amount": [10, 20, 30, 40, 50]},
    index=pd.date_range("2024-01-01", periods=5, freq="D"),
)

print(sales.resample("2D").sum())
```

## Common pitfalls

- Downsampling needs an aggregation (`.sum()`, `.mean()`, `.ohlc()`, ...); calling
  `.resample("5min")` alone just returns a lazy resampler object, not data.
- The default for `closed`/`label` is `"left"` for most frequencies but `"right"` for
  a handful (`"ME"`, `"YE"`, `"QE"`, `"W"`) — always check the output on real data.
- Upsampling with `.asfreq()` introduces `NaN`; you must explicitly choose `.ffill()`
  or another fill strategy if you don't want gaps.

```p5 title="High-frequency points collapsing into buckets" desc="Twelve minute-level points (amber) are grouped by resample into three 5-minute buckets, each collapsed to one summary bar (blue)." height="280"
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const n = 12;
  const startX = 40;
  const stepX = 44;
  const dotY = 60;
  const barBaseY = 230;
  const bucketSize = 5;

  textSize(11);
  fill(180);
  noStroke();
  textAlign(LEFT, CENTER);
  text("minute-level points", 20, 20);
  text("resample('5min').sum()", 20, 160);

  // sum of each bucket precomputed from Series(range(12)) resampled 5min: [10, 35, 21]
  const bucketSums = [10, 35, 21];
  const maxSum = 35;

  for (let i = 0; i < n; i++) {
    const x = startX + i * stepX;
    const bucket = Math.floor(i / bucketSize);
    const cols = [color(255, 211, 67), color(75, 139, 190), color(255, 211, 67)];
    fill(cols[bucket % cols.length]);
    ellipse(x, dotY, 12, 12);

    // connecting line down to its bucket bar
    stroke(90, 100, 116, 90);
    const barX = 90 + bucket * 170;
    line(x, dotY + 8, barX, barBaseY - 40);
    noStroke();
  }

  // bucket bars
  for (let b = 0; b < 3; b++) {
    const barX = 90 + b * 170;
    const h = map(bucketSums[b], 0, maxSum, 10, 120);
    fill(75, 139, 190, 200);
    rect(barX - 30, barBaseY - h, 60, h, 4);
    fill(230);
    textAlign(CENTER, CENTER);
    textSize(12);
    text("sum=" + bucketSums[b], barX, barBaseY - h - 12);
  }
}
```

:::tip[From the book]
McKinney points out that `resample`'s bin edges are **half-open**: a data point can
belong to only one interval, and the union of all intervals covers the whole time
range. This is why, for the default `closed="left"`, a value stamped exactly at
`00:05:00` belongs to the *next* 5-minute bucket, not the one ending at `00:05:00`.
:::
