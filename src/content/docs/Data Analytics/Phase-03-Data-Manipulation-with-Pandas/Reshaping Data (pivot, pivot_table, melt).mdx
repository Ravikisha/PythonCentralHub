## Long vs wide (why reshaping exists)

- **Long format**: one row per observation (better for analysis/plotting)
- **Wide format**: values spread across columns (good for reporting)

:::tip[From the book]
McKinney frames `stack`/`unstack` and `pivot`/`melt` as the same idea at two levels: `stack`
rotates columns into rows (wide → long), `unstack` rotates rows back into columns
(long → wide). `pivot` is really just "set an index, then unstack" — and it will **raise an
error** if your (index, columns) pair isn't unique. Use `pivot_table` instead when you need
to aggregate duplicate combinations.
:::

## Example: long format

```python title="Long format" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({
    "date": ["2025-01-01", "2025-01-01", "2025-01-02", "2025-01-02"],
    "city": ["pune", "delhi", "pune", "delhi"],
    "sales": [100, 120, 90, 150],
})

print(df)
```

## `pivot`: reshape when data is unique

```python title="pivot" showLineNumbers{1}
wide = df.pivot(index="date", columns="city", values="sales")
print(wide)
```

If the combination of (`index`, `columns`) isn't unique, `pivot` throws an error.

## `pivot_table`: reshape with aggregation

```python title="pivot_table" showLineNumbers{1}
wide = df.pivot_table(index="date", columns="city", values="sales", aggfunc="sum")
print(wide)
```

## `melt`: wide → long

```python title="melt" showLineNumbers{1}
wide = pd.DataFrame({
    "date": ["2025-01-01", "2025-01-02"],
    "pune": [100, 90],
    "delhi": [120, 150],
})

long = wide.melt(id_vars=["date"], var_name="city", value_name="sales")
print(long)
```

## Practical notes

- Many ML/EDA workflows prefer long format.
- Pivoted tables often have a multi-index for columns—use `reset_index()` or `wide.columns` renaming if needed.

function setup() {
  createCanvas(600, 300);
  textFont("monospace");
  noLoop();

function draw() {
  background(13, 17, 23);
  textSize(11);
  textAlign(LEFT, CENTER);
  fill(255, 211, 67);
  text("wide", 60, 16);
  text("long", 400, 16);

  // wide table: date, pune, delhi
  const wideRows = [
    ["date", "pune", "delhi"],
    ["01-01", "100", "120"],
    ["01-02", "90", "150"],
  ];
  for (let r = 0; r < wideRows.length; r++) {
    for (let c = 0; c < 3; c++) {
      const x = 30 + c * 70;
      const y = 46 + r * 32;
      noStroke();
      fill(r === 0 ? color(255, 211, 67, 50) : color(255, 255, 255, 12));
      rect(x, y - 13, 65, 26, 3);
      fill(230);
      textAlign(CENTER, CENTER);
      text(wideRows[r][c], x + 32, y);
    }
  }

  // arrow with labels
  stroke(90, 100, 116);
  strokeWeight(1.2);
  line(250, 90, 350, 60);
  line(250, 130, 350, 200);
  noStroke();
  fill(75, 139, 190);
  textAlign(CENTER, CENTER);
  textSize(10);
  text("melt()", 300, 55);
  text("pivot()", 300, 205);

  // long table: date, city, sales
  const longRows = [
    ["date", "city", "sales"],
    ["01-01", "pune", "100"],
    ["01-01", "delhi", "120"],
    ["01-02", "pune", "90"],
    ["01-02", "delhi", "150"],
  ];
  for (let r = 0; r < longRows.length; r++) {
    for (let c = 0; c < 3; c++) {
      const x = 380 + c * 65;
      const y = 40 + r * 26;
      noStroke();
      fill(r === 0 ? color(255, 211, 67, 50) : color(255, 255, 255, 12));
      rect(x, y - 11, 60, 22, 3);
      fill(230);
      textAlign(CENTER, CENTER);
      textSize(9);
      text(longRows[r][c], x + 30, y);
    }
  }
}
