## What correlation and covariance answer

Both measure how two variables move **together**:

- **Covariance** tells you the *direction* of the relationship (positive or negative)
  but its size depends on the scale of your data, which makes it hard to compare
  across different variables.
- **Correlation** rescales covariance into a number between **-1 and 1**, so it's
  directly comparable no matter what units the original data was in.

A correlation near `1` means "moves up together," near `-1` means "one goes up as
the other goes down," and near `0` means "no clear linear relationship."

## Series.corr and Series.cov

```python title="Correlation and covariance of two Series" showLineNumbers{1}
import pandas as pd

ad_spend = pd.Series([1, 2, 3, 4, 5])
sales = pd.Series([2, 4, 6, 8, 10])  # perfectly proportional to ad_spend

print(round(ad_spend.corr(sales), 2))  # 1.0 — perfectly correlated
print(ad_spend.cov(sales))             # 5.0 — positive, but scale-dependent
```

Both methods automatically use only the **overlapping, non-missing, aligned-by-index**
values from the two Series — you don't need to clean them up first.

## DataFrame.corr and DataFrame.cov: full matrices

Call `.corr()` (or `.cov()`) directly on a DataFrame to get every pairwise
combination of columns at once:

```python title="A full correlation matrix" showLineNumbers{1}
df = pd.DataFrame({
    "x": [1, 2, 3, 4, 5],
    "y": [2, 4, 6, 8, 10],
    "z": [5, 3, 4, 2, 1],
})

print(df.corr())
```

The diagonal is always `1.0` — every column is perfectly correlated with itself.
`z` here trends *opposite* to `x` and `y`, so its correlation with them is negative.

## corrwith: one column against many

`corrwith` computes the correlation of every column in a DataFrame against a single
Series (or another DataFrame's matching columns) — useful for quickly checking which
columns move with a target metric:

```python title="corrwith against a target column" showLineNumbers{1}
print(df.corrwith(df["x"]))
```

## Common pitfalls

- Correlation measures a **linear** relationship only — two variables can have a
  strong non-linear pattern (like a U-shape) and still show a correlation near `0`.
- A high correlation is not causation — McKinney's book pairs this topic with data
  alignment precisely because spurious correlations often come from misaligned data.
- `corrwith(axis="columns")` compares row-by-row instead of column-by-column —
  easy to reach for the wrong axis by habit.

```p5 title="Scatter plots at different correlation strengths" desc="As points hug a straight line more tightly, the correlation moves toward +1 or -1; a shapeless cloud sits near 0." height="280"
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  drawScatter(100, 0.98, "corr ≈ 0.98");
  drawScatter(320, 0.0, "corr ≈ 0.0");
  drawScatter(540, -0.95, "corr ≈ -0.95");
}

function drawScatter(cx, targetCorr, label) {
  const size = 140;
  const top = 40;
  noFill();
  stroke(90, 100, 116);
  rect(cx - size / 2, top, size, size);

  randomSeed(Math.floor(targetCorr * 1000) + 7);
  noStroke();
  for (let i = 0; i < 40; i++) {
    const t = random(-1, 1);
    const noiseAmt = 1 - Math.abs(targetCorr);
    const x = t;
    const y = targetCorr * t + random(-1, 1) * noiseAmt * 0.6;
    const px = cx + x * (size / 2 - 10);
    const py = top + size / 2 - y * (size / 2 - 10);
    fill(targetCorr >= 0 ? color(255, 211, 67, 200) : color(75, 139, 190, 200));
    ellipse(px, py, 6, 6);
  }

  fill(210);
  textAlign(CENTER, CENTER);
  textSize(12);
  text(label, cx, top + size + 20);
}
```

:::tip[From the book]
McKinney demonstrates `corr` and `cov` on real stock return data (`returns["MSFT"].corr(returns["IBM"])`),
computed from **percent changes**, not raw prices. That's an important habit: raw
price series usually trend together simply because both are rising over time, which
inflates correlation. Converting to returns (or percent change) first isolates the
actual co-movement you care about.
:::
