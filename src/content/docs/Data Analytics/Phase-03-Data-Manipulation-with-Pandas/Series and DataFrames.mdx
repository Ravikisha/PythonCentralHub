## Creating a Series

A **Series** is a labeled 1D array. Think of it as a single spreadsheet column: every value
has a matching row label sitting to its left, called the **index**.

```python title="Create a Series" showLineNumbers{1}
import pandas as pd

s = pd.Series([10, 20, 30], name="scores")
print(s)
```

### With a custom index

```python title="Series with explicit index" showLineNumbers{1}
import pandas as pd

s = pd.Series([10, 20, 30], index=["a", "b", "c"], name="scores")
print(s)
print("Index:", s.index)
```

:::tip[From the book]
McKinney describes a Series as "a fixed-length, ordered dictionary" — it maps index labels
to values, so you can look values up by label (`s["a"]`) just like a dict, but it also supports
vectorized math and keeps its index aligned through operations like filtering and arithmetic.
:::

## Creating a DataFrame

A **DataFrame** is a labeled 2D table — literally a dictionary of Series that all share the
same row index. That's why every column can have a different dtype, but `df.index` is one
shared set of row labels for the whole table.

### From a dictionary of columns

```python title="DataFrame from dict" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meera"],
    "age": [23, 28, 26],
    "city": ["Pune", "Delhi", "Bengaluru"],
})

print(df)
```

### From a list of dictionaries (records)

```python title="DataFrame from records" showLineNumbers{1}
import pandas as pd

rows = [
    {"name": "Asha", "age": 23, "city": "Pune"},
    {"name": "Ravi", "age": 28, "city": "Delhi"},
]

df = pd.DataFrame(rows)
print(df)
```

## Understanding index and columns

- `df.index` labels rows
- `df.columns` labels columns

```python title="Index and columns" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({"a": [1, 2], "b": [3, 4]})
print("index:", df.index)
print("columns:", df.columns)
```

## Dtypes: why they matter

Pandas stores each column using a data type (`dtype`).

```python title="Check dtypes" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({
    "age": [20, 21, 22],
    "score": [90.5, 88.0, 91.0],
    "passed": [True, True, False],
})

print(df.dtypes)
```

### Common dtype pitfalls

- A numeric column can become `object` if it contains mixed types like `"N/A"`.
- Dates start as strings unless you parse them.

We’ll fix these issues later in the phase.

## Visualize it

A Series is a single labeled column; a DataFrame stacks several Series side by side that
all share the same row index.

```mermaid title="Series vs DataFrame" desc="A DataFrame is a collection of Series that all share one row index."
flowchart LR
  S1["Series: name"] --> DF["DataFrame"]
  S2["Series: age"] --> DF
  S3["Series: city"] --> DF
  DF --> IDX["Shared index (row labels)"]
```

```p5 title="Series index → value, DataFrame columns" desc="A Series pairs each index label with one value; a DataFrame is several Series lined up on a shared index." height="280"
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const rows = ["a", "b", "c"];
  const vals = [10, 20, 30];

  // Series on the left
  fill(230);
  textSize(13);
  textAlign(LEFT, CENTER);
  text("Series", 40, 24);
  for (let i = 0; i < rows.length; i++) {
    const y = 60 + i * 40;
    noStroke();
    fill(75, 139, 190, 90);
    rect(30, y - 14, 40, 28, 4);
    fill(255, 211, 67, 90);
    rect(80, y - 14, 60, 28, 4);
    fill(230);
    textAlign(CENTER, CENTER);
    text(rows[i], 50, y);
    text(vals[i], 110, y);
  }

  // Arrow
  stroke(150, 160, 175);
  strokeWeight(1.5);
  line(200, 140, 260, 140);
  line(255, 135, 260, 140);
  line(255, 145, 260, 140);
  noStroke();

  // DataFrame on the right: index + 3 columns
  const cols = ["name", "age", "city"];
  const data = [["Asha", "23", "Pune"], ["Ravi", "28", "Delhi"], ["Meera", "26", "Bengaluru"]];
  const colX = [340, 400, 470];
  fill(230);
  textSize(13);
  textAlign(LEFT, CENTER);
  text("DataFrame", 340, 24);
  for (let c = 0; c < cols.length; c++) {
    fill(255, 211, 67);
    textAlign(CENTER, CENTER);
    text(cols[c], colX[c] + 25, 46);
  }
  for (let i = 0; i < rows.length; i++) {
    const y = 60 + i * 40;
    fill(75, 139, 190, 90);
    rect(300, y - 14, 30, 28, 4);
    fill(230);
    textAlign(CENTER, CENTER);
    text(rows[i], 315, y);
    for (let c = 0; c < cols.length; c++) {
      noStroke();
      fill(255, 255, 255, 18);
      rect(colX[c], y - 14, 55, 28, 4);
      fill(230);
      text(data[i][c], colX[c] + 27, y);
    }
  }
  noStroke();
  fill(150);
  textSize(10);
  textAlign(LEFT, CENTER);
  text("same index shared by every column", 300, 210);
}
```
