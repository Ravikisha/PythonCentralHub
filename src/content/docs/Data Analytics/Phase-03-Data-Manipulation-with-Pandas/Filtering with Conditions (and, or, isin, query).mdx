## Setup

A boolean filter works in two steps: first you build a **mask** — a Series of `True`/`False`,
one per row — then you use that mask to keep only the `True` rows.

```python title="Setup DataFrame" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({
    "name": ["Asha", "Ravi", "Meera", "Zoya", "Kabir"],
    "age": [23, 28, 26, 31, 22],
    "city": ["Pune", "Delhi", "Delhi", "Pune", "Mumbai"],
    "score": [88, 91, 77, 95, 60],
})

print(df)
```

## Basic boolean filtering

```python title="Single condition" showLineNumbers{1}
print(df[df["age"] >= 25])
```

## Multiple conditions: AND / OR

Pandas uses bitwise operators:

- AND: `&`
- OR: `|`

Always use parentheses:

```python title="AND filter" showLineNumbers{1}
mask = (df["city"] == "Delhi") & (df["score"] >= 80)
print(df[mask])
```

```python title="OR filter" showLineNumbers{1}
mask = (df["city"] == "Mumbai") | (df["score"] >= 90)
print(df[mask])
```

## `isin()` for membership checks

```python title="isin" showLineNumbers{1}
mask = df["city"].isin(["Pune", "Delhi"])
print(df[mask])
```

## `between()` for range filters

```python title="between" showLineNumbers{1}
mask = df["age"].between(23, 30, inclusive="both")
print(df[mask])
```

## `query()` for readable filters

`query()` can be easier to read, especially in notebooks.

```python title="query" showLineNumbers{1}
result = df.query('city == "Delhi" and score >= 80')
print(result)
```

### Variables inside query

```python title="query with variable" showLineNumbers{1}
min_score = 85
result = df.query('score >= @min_score')
print(result)
```

## Common mistakes

- Using `and` / `or` instead of `&` / `|` (will error)
- Forgetting parentheses around conditions
- Comparing strings with extra spaces (clean using `.str.strip()`)

:::caution[Common pitfall]
`df[(df["a"] > 1) & (df["b"] < 5)]` needs the parentheses around each condition — Python's
`&` binds tighter than `>`/`<`, so `df["a"] > 1 & df["b"] < 5` silently does the wrong thing
instead of raising an error. Always parenthesize each side of `&`/`|`.
:::

```p5 title="A condition becomes a keep/drop mask" desc="Each row is tested against the condition; only rows where the mask is True survive the filter." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const scores = [88, 91, 77, 95, 60];
  const keep = scores.map(s => s >= 80);
  const rowH = 34, startY = 40;

  textAlign(LEFT, CENTER);
  textSize(11);
  fill(255, 211, 67);
  text("score", 40, 20);
  text("score >= 80", 160, 20);
  text("kept?", 340, 20);

  for (let i = 0; i < scores.length; i++) {
    const y = startY + i * rowH;
    noStroke();
    fill(255, 255, 255, 14);
    rect(30, y - 12, 90, 24, 4);
    fill(230);
    text(scores[i], 45, y);

    fill(keep[i] ? color(75, 139, 190) : color(120));
    text(keep[i] ? "True" : "False", 160, y);

    fill(keep[i] ? color(255, 211, 67, 200) : color(90, 90, 90, 120));
    rect(330, y - 12, 60, 24, 4);
    fill(keep[i] ? 20 : 180);
    textAlign(CENTER, CENTER);
    text(keep[i] ? "kept" : "dropped", 360, y);
    textAlign(LEFT, CENTER);
  }
}
```
