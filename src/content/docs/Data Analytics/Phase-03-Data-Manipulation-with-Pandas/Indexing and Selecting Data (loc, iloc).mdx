## Why selection matters

Most Pandas bugs come from:

- Selecting the wrong rows
- Accidentally getting a copy instead of a view
- Confusing label-based vs position-based indexing

Pandas provides two primary tools:

- `loc` → label-based
- `iloc` → position-based

:::tip[From the book]
McKinney's advice: prefer `loc` over plain `[]` indexing whenever your index could contain
integers. Regular `[]` indexing treats integers as **labels** if the index itself holds integers,
so behavior silently changes depending on your data. `loc` always means "by label" and
`iloc` always means "by position" — no ambiguity either way.
:::

## Setup example DataFrame

```python title="Sample DataFrame" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame(
    {
        "name": ["Asha", "Ravi", "Meera", "Zoya"],
        "age": [23, 28, 26, 31],
        "city": ["Pune", "Delhi", "Delhi", "Pune"],
        "score": [88, 91, 77, 95],
    },
    index=["u1", "u2", "u3", "u4"],
)

print(df)
```

## Selecting columns

```python title="One column" showLineNumbers{1}
print(df["age"])  # returns a Series
```

```python title="Multiple columns" showLineNumbers{1}
print(df[["name", "score"]])
```

## Selecting rows with `loc` (labels)

```python title="loc by label" showLineNumbers{1}
print(df.loc["u2"])          # one row (Series)
print(df.loc[["u1", "u4"]]) # multiple rows (DataFrame)
```

Selecting rows + columns together:

```python title="loc rows + cols" showLineNumbers{1}
print(df.loc[["u1", "u3"], ["name", "score"]])
```

## Selecting rows with `iloc` (positions)

```python title="iloc by position" showLineNumbers{1}
print(df.iloc[0])      # first row
print(df.iloc[0:2])    # first two rows
print(df.iloc[:, 0:2]) # first two cols
```

## Boolean filtering (most common)

```python title="Filter rows" showLineNumbers{1}
filtered = df[df["city"] == "Delhi"]
print(filtered)
```

Combine conditions:

```python title="Multiple conditions" showLineNumbers{1}
filtered = df[(df["city"] == "Pune") & (df["score"] >= 90)]
print(filtered)
```

## Safer assignment after filtering

When you filter and then assign, prefer `.loc`:

```python title="Safe assignment with loc" showLineNumbers{1}
df.loc[df["city"] == "Delhi", "is_delhi"] = True

df["is_delhi"] = df["is_delhi"].fillna(False)
print(df)
```

## Note on `&` and `|`

In Pandas boolean filters:

- Use `&` for AND, `|` for OR
- Always wrap sub-conditions in parentheses

This avoids operator precedence bugs.

## Visualize it

`loc` reads coordinates as **labels** ("row `u2`, column `age`"); `iloc` reads them as
**positions** ("row 1, column 1") — same grid, two different ways to point at a cell.

```mermaid title="loc vs iloc" desc="loc addresses cells by label, iloc addresses the same cells by integer position."
flowchart LR
  DF["DataFrame grid"] --> L["df.loc['u2', 'age']  (by label)"]
  DF --> I["df.iloc[1, 1]  (by position)"]
  L --> V["Same cell"]
  I --> V
```

```p5 title="Label-based vs position-based selection" desc="loc and iloc point at the exact same cell using two different coordinate systems." height="300"
function setup() {
  createCanvas(600, 300);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const rowLabels = ["u1", "u2", "u3", "u4"];
  const colLabels = ["name", "age", "city", "score"];
  const cellW = 90, cellH = 40;
  const originX = 140, originY = 60;

  // column headers
  textAlign(CENTER, CENTER);
  textSize(11);
  for (let c = 0; c < colLabels.length; c++) {
    fill(255, 211, 67);
    text(colLabels[c], originX + c * cellW + cellW / 2, originY - 18);
    fill(120);
    text(c, originX + c * cellW + cellW / 2, originY - 4);
  }
  // row headers
  for (let r = 0; r < rowLabels.length; r++) {
    fill(255, 211, 67);
    text(rowLabels[r], originX - 40, originY + r * cellH + cellH / 2);
    fill(120);
    text(r, originX - 14, originY + r * cellH + cellH / 2);
  }
  // grid
  for (let r = 0; r < rowLabels.length; r++) {
    for (let c = 0; c < colLabels.length; c++) {
      const x = originX + c * cellW;
      const y = originY + r * cellH;
      const isTarget = (r === 1 && c === 1);
      noStroke();
      fill(isTarget ? color(255, 211, 67, 60) : color(255, 255, 255, 12));
      rect(x, y, cellW - 4, cellH - 4, 4);
      stroke(90, 100, 116);
      strokeWeight(1);
      noFill();
      rect(x, y, cellW - 4, cellH - 4, 4);
    }
  }
  noStroke();
  fill(230);
  textSize(12);
  text("28", originX + 1 * cellW + cellW / 2, originY + 1 * cellH + cellH / 2);

  fill(75, 139, 190);
  textAlign(LEFT, CENTER);
  textSize(11);
  text("df.loc['u2', 'age']   -> label 'u2', label 'age'", 30, 250);
  text("df.iloc[1, 1]         -> position 1, position 1", 30, 270);
}
```
