## The idea

`groupby` answers questions like:

- Average revenue per city?
- Total orders per customer?
- Highest score per class?

Think: **split → apply → combine**.

:::tip[From the book]
McKinney credits Hadley Wickham for the term **split-apply-combine**: Pandas splits your
rows into groups by key, applies a function (like `sum` or `mean`) to each group
independently, then combines the per-group results back into one Series or DataFrame.
Calling `.groupby("city")` alone does nothing yet — it just remembers the grouping until
you call an aggregation like `.mean()`.
:::

## Example dataset

```python title="Sales sample" showLineNumbers{1}
import pandas as pd

sales = pd.DataFrame({
    "city": ["pune", "pune", "delhi", "delhi", "delhi"],
    "category": ["A", "B", "A", "A", "B"],
    "amount": [100, 200, 150, 120, 300],
})

print(sales)
```

## Basic aggregations

### Sum per city

```python title="Sum per city" showLineNumbers{1}
print(sales.groupby("city")["amount"].sum())
```

### Mean per city

```python title="Mean per city" showLineNumbers{1}
print(sales.groupby("city")["amount"].mean())
```

## Multiple aggregations with `agg`

```python title="Multiple metrics" showLineNumbers{1}
summary = (
    sales.groupby("city")
    .agg(
        total_amount=("amount", "sum"),
        avg_amount=("amount", "mean"),
        orders=("amount", "count"),
    )
)

print(summary)
```

## Group by multiple keys

```python title="Group by city and category" showLineNumbers{1}
summary = (
    sales.groupby(["city", "category"])
    .agg(total_amount=("amount", "sum"), orders=("amount", "count"))
    .reset_index()
)

print(summary)
```

## Common gotchas

- After `groupby`, the grouped columns become the index. Use `.reset_index()` if you want them as normal columns.
- Aggregation functions ignore missing numeric values by default (`NaN`) in many cases.

## Mental model

When you write:

```python
sales.groupby("city")["amount"].sum()
```

You are saying:

- Split the rows by `city`
- Select the `amount` column
- Sum within each group

This pattern comes up constantly in analytics.
