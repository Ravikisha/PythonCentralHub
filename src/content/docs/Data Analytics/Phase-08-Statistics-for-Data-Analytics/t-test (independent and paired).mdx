## When to use t-tests

Use t-tests when you want to compare **means**.

- **Independent (two-sample)**: two different groups
- **Paired**: before/after measurements on the same subjects

## Independent two-sample t-test

Example: average spend differs between two groups.

```python title="Independent t-test" showLineNumbers{1}
import numpy as np
from scipy import stats

A = np.array([120, 140, 130, 150, 160])
B = np.array([100, 90, 110, 95, 105])

t_stat, p = stats.ttest_ind(A, B, equal_var=False)  # Welch t-test
print("t:", t_stat)
print("p:", p)
```

### Welch vs pooled variance

- Welch (`equal_var=False`) is safer when variances differ.
- Pooled assumes equal variances.

## Paired t-test

Example: same users before/after a change.

```python title="Paired t-test" showLineNumbers{1}
import numpy as np
from scipy import stats

before = np.array([10, 12, 11, 9, 13])
after  = np.array([11, 12, 12, 10, 14])

t_stat, p = stats.ttest_rel(after, before)
print("t:", t_stat)
print("p:", p)
```

## Assumptions (important)

- Data points are independent (except paired case)
- Approximately normal within each group (CLT helps with larger n)
- No extreme outliers

If assumptions are shaky, consider non-parametric alternatives.

## Which t-test do you need?

```mermaid title="Choosing between t-tests" desc="The decision hinges on whether the two groups share the same subjects."
flowchart TD
  A["Comparing two means?"] --> B["Same subjects,<br/>measured twice?"]
  B -->|"Yes"| C["Paired t-test<br/>(ttest_rel)"]
  B -->|"No"| D["Independent t-test<br/>(ttest_ind)"]
  D --> E["Equal variances?"]
  E -->|"Unsure/No"| F["Welch t-test<br/>(equal_var=False)"]
  E -->|"Yes"| G["Pooled t-test<br/>(equal_var=True)"]
```

:::tip[From the book]
statsmodels' formula API (`smf.ols("y ~ group", data=df)`) can reproduce a two-sample
t-test as a linear regression with one categorical predictor — the t-statistic on that
group coefficient matches `stats.ttest_ind`. It's a useful bridge once you move from
standalone tests toward the modeling libraries covered later.
:::
