## Central tendency

### Mean

- Sensitive to outliers
- Good for symmetric distributions

```python title="Mean" showLineNumbers{1}
import numpy as np

x = np.array([10, 12, 12, 13, 12, 11, 100])
print(np.mean(x))
```

### Median

- Robust to outliers

```python title="Median" showLineNumbers{1}
import numpy as np

x = np.array([10, 12, 12, 13, 12, 11, 100])
print(np.median(x))
```

### Mode

Useful for categorical data.

```python title="Mode (SciPy)" showLineNumbers{1}
import numpy as np
from scipy import stats

x = np.array([1, 1, 2, 2, 2, 3])
print(stats.mode(x, keepdims=True))
```

## Spread (variability)

- **Range**: max - min (very sensitive)
- **Variance**: average squared distance from mean
- **Standard deviation (std)**: sqrt(variance)

```python title="Variance / Std" showLineNumbers{1}
import numpy as np

x = np.array([10, 12, 12, 13, 12, 11, 100])
print("var:", np.var(x, ddof=1))
print("std:", np.std(x, ddof=1))
```

### IQR (interquartile range)

Robust measure of spread.

```python title="IQR" showLineNumbers{1}
import numpy as np

x = np.array([10, 12, 12, 13, 12, 11, 100])
q1 = np.percentile(x, 25)
q3 = np.percentile(x, 75)
print("IQR:", q3 - q1)
```

## Quick checklist

- Use **median/IQR** when outliers exist
- Use **mean/std** when distribution is roughly symmetric
- Always visualize (histogram/boxplot) before trusting summary stats

## How mean and median relate

```mermaid title="Choosing a central tendency measure" desc="A quick decision path for picking mean, median, or mode."
flowchart TD
  A["Do you have outliers<br/>or a skewed shape?"] -->|"Yes"| B["Use median<br/>(robust)"]
  A -->|"No"| C["Use mean<br/>(uses every value)"]
  D["Is the data categorical?"] --> E["Use mode"]
```

:::tip[From the book]
Pandas' own summary tool, `describe()`, prints count, mean, std, min, quartiles, and max in
one call — McKinney recommends running it as a first pass on any new DataFrame before
writing custom aggregation code, precisely because it surfaces skew and outliers at a glance.
:::

## Visualize it

The mean is pulled toward extreme values because it uses every number in the calculation.
The median only cares about the middle position, so it barely moves when one point is far
away. Watch the outlier drag the mean marker to the right while the median stays put:

```p5 title="Mean vs. median on a number line" desc="The mean shifts toward the outlier; the median stays anchored near the middle of the data." height="220"
const data = [10, 12, 12, 13, 12, 11, 100];
function setup() {
  createCanvas(600, 220);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 40, gy = 120, gw = width - 80;
  const lo = 0, hi = 105;
  const toX = (v) => gx + (v - lo) / (hi - lo) * gw;

  stroke(60, 70, 84);
  strokeWeight(1);
  line(gx, gy, gx + gw, gy);
  for (let v = 0; v <= hi; v += 20) {
    line(toX(v), gy - 5, toX(v), gy + 5);
    noStroke();
    fill(150);
    textSize(11);
    textAlign(CENTER, TOP);
    text(v, toX(v), gy + 8);
    stroke(60, 70, 84);
  }

  noStroke();
  fill(75, 139, 190);
  for (const v of data) {
    ellipse(toX(v), gy, 10, 10);
  }

  const sorted = data.slice().sort((a, b) => a - b);
  const median = sorted[Math.floor(sorted.length / 2)];
  const mean = data.reduce((a, b) => a + b, 0) / data.length;

  stroke(255, 211, 67);
  strokeWeight(2);
  line(toX(mean), gy - 40, toX(mean), gy - 10);
  noStroke();
  fill(255, 211, 67);
  textAlign(CENTER, BOTTOM);
  textSize(13);
  text("mean = " + mean.toFixed(1), toX(mean), gy - 44);

  stroke(120, 200, 120);
  strokeWeight(2);
  line(toX(median), gy + 10, toX(median), gy + 40);
  noStroke();
  fill(120, 200, 120);
  textAlign(CENTER, TOP);
  text("median = " + median.toFixed(1), toX(median), gy + 44);
}
```
