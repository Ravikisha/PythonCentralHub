## Why distributions matter

Distributions model uncertainty and randomness.

- Normal: measurement noise, averages
- Binomial: number of successes in N trials (conversions)
- Poisson: counts over time/space (arrivals, events)

## Picking the right distribution

```mermaid title="Choosing a distribution" desc="A quick decision path from the kind of data you have to a matching distribution."
flowchart TD
  A["What are you modeling?"] --> B["Continuous measurement<br/>(height, latency, noise)"]
  A --> C["Count of successes<br/>in a fixed number of trials"]
  A --> D["Count of events<br/>over time or space"]
  B --> E["Normal"]
  C --> F["Binomial"]
  D --> G["Poisson"]
```

:::tip[From the book]
NumPy's `random` module (`np.random.normal`, `np.random.binomial`, `np.random.poisson`)
mirrors the same parameters you'd use in a stats textbook — mean/std, n/p, and lambda — so
you can sanity-check a formula by simulating thousands of draws and comparing the sample
mean/variance to the theoretical ones, exactly like the examples below do.
:::

## Normal distribution

- Parameters: mean \(\mu\), std \(\sigma\)
- Symmetric bell curve

```python title="Normal samples" showLineNumbers{1}
import numpy as np

x = np.random.normal(loc=0, scale=1, size=10_000)
print(x.mean(), x.std())
```

## Binomial distribution

- Parameters: trials \(n\), success prob \(p\)
- Example: 100 visitors, conversion probability 0.03

```python title="Binomial samples" showLineNumbers{1}
import numpy as np

samples = np.random.binomial(n=100, p=0.03, size=10_000)
print(samples.mean())
```

## Poisson distribution

- Parameter: rate \(\lambda\)
- Example: number of support tickets per hour

```python title="Poisson samples" showLineNumbers{1}
import numpy as np

samples = np.random.poisson(lam=5, size=10_000)
print(samples.mean())
```

## Visualize it

The three distributions have distinct shapes: the **normal** is a smooth continuous bell,
the **binomial** counts successes in a fixed number of trials, and the **Poisson** counts
rare events over an interval. Seeing them side by side makes the differences click:

```p5 title="Three common distributions" desc="Normal is a smooth bell; binomial counts successes in n trials; Poisson counts rare events over an interval." height="300"
function factorial(k) { let r = 1; for (let i = 2; i <= k; i++) r *= i; return r; }
function binom(k, n, p) { return factorial(n) / (factorial(k) * factorial(n - k)) * Math.pow(p, k) * Math.pow(1 - p, n - k); }
function pois(k, lam) { return Math.pow(lam, k) * Math.exp(-lam) / factorial(k); }
function setup() {
  createCanvas(600, 300);
  textFont("monospace");
}
function panel(idx, pw, label, cont, col, pdf, pmf, kmax) {
  const gx = idx * pw + 20, gy = 30, gw = pw - 38, gh = height - 84;
  stroke(60, 70, 84);
  strokeWeight(1);
  line(gx, gy + gh, gx + gw, gy + gh);
  if (cont) {
    stroke(col[0], col[1], col[2]);
    strokeWeight(2.5);
    noFill();
    beginShape();
    for (let x = 0; x <= 1; x += 0.02) vertex(gx + x * gw, gy + gh - pdf(x) * gh * 0.9);
    endShape();
  } else {
    let mx = 0;
    for (let k = 0; k <= kmax; k++) mx = Math.max(mx, pmf(k));
    noStroke();
    fill(col[0], col[1], col[2]);
    const bw = gw / (kmax + 1);
    for (let k = 0; k <= kmax; k++) {
      const h = pmf(k) / mx * gh * 0.9;
      rect(gx + k * bw + 1, gy + gh - h, bw - 2, h);
    }
  }
  noStroke();
  fill(205);
  textSize(13);
  textAlign(CENTER, TOP);
  text(label, gx + gw / 2, gy + gh + 10);
}
function draw() {
  background(13, 17, 23);
  const pw = width / 3;
  panel(0, pw, "Normal", true, [75, 139, 190], (x) => Math.exp(-((x - 0.5) ** 2) / (2 * 0.02)), null, 0);
  panel(1, pw, "Binomial", false, [255, 211, 67], null, (k) => binom(k, 10, 0.5), 10);
  panel(2, pw, "Poisson", false, [120, 200, 120], null, (k) => pois(k, 3), 10);
  noLoop();
}
```

## Practical tip

When unsure:

- Plot a histogram of your data.
- Start with simple candidates (normal vs count distributions).
- Check mean/variance: for Poisson, mean ≈ variance.
