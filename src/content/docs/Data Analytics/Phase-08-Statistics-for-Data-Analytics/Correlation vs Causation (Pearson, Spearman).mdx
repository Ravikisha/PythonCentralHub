## Correlation measures association

Correlation answers:

- “Do variables move together?”

It does **not** answer:

- “Does X cause Y?”

## Pearson correlation

- Measures linear relationship
- Sensitive to outliers

```python title="Pearson" showLineNumbers{1}
import numpy as np
from scipy import stats

x = np.array([1, 2, 3, 4, 5, 6])
y = np.array([2, 4, 5, 4, 5, 7])

r, p = stats.pearsonr(x, y)
print("r:", r)
print("p:", p)
```

## Spearman correlation

- Uses ranks
- Captures monotonic relationships
- More robust to outliers and non-linearity

```python title="Spearman" showLineNumbers{1}
import numpy as np
from scipy import stats

x = np.array([1, 2, 3, 4, 5, 6])
y = np.array([10, 9, 7, 6, 3, 1])

rho, p = stats.spearmanr(x, y)
print("rho:", rho)
print("p:", p)
```

## Visualize it

Pearson's **r** measures how tightly two variables move together: near **+1** the points hug
a rising line, near **0** there's no pattern, near **−1** they hug a falling line. Watch the
cloud tighten and flip as `r` changes:

```p5 title="Correlation, from strong to none" desc="r near +1 means points follow a rising line, 0 means no linear pattern, -1 means a falling line." height="280"
let pts = [];
const rs = [0.9, 0.4, 0.0, -0.7];
let ri = 0;
let t = 0;
function gen(rr) {
  pts = [];
  for (let i = 0; i < 60; i++) {
    const x = randomGaussian();
    const y = rr * x + Math.sqrt(1 - rr * rr) * randomGaussian();
    pts.push({ x: x, y: y });
  }
}
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  gen(rs[0]);
}
function draw() {
  background(13, 17, 23);
  const cx = width / 2, cy = height / 2 + 6, sc = 40;
  stroke(60, 70, 84);
  strokeWeight(1);
  line(40, cy, width - 40, cy);
  line(cx, 34, cx, height - 30);
  noStroke();
  for (const p of pts) {
    fill(75, 139, 190, 200);
    ellipse(cx + p.x * sc, cy - p.y * sc, 8, 8);
  }
  fill(255, 211, 67);
  textSize(15);
  textAlign(CENTER, TOP);
  text("r ≈ " + rs[ri].toFixed(1), width / 2, 12);
  t++;
  if (t % 90 === 0) { ri = (ri + 1) % rs.length; gen(rs[ri]); }
}
```

## Practical guidance

- Plot scatter first.
- Consider transformations (log) if scales vary.
- Be cautious: confounders can create spurious correlation.

## Why correlation isn't causation

```mermaid title="Correlation can hide a confounder" desc="Two variables can move together purely because a third variable drives both."
flowchart LR
  Z["Confounder<br/>(e.g. summer heat)"] --> X["Ice cream sales"]
  Z --> Y["Drowning incidents"]
  X -.->|"correlated, not causal"| Y
```

:::tip[From the book]
`DataFrame.corr()` computes Pearson correlation across every numeric column pair in one
call — handy for a quick scan, but McKinney's own examples (like the `cov`/`corrcoef` pair
in NumPy) are careful to only *describe* linear association. Nothing in the correlation
matrix itself can tell you which variable, if any, is causing the other — that requires
domain knowledge or a designed experiment (see A/B Testing Basics).
:::
