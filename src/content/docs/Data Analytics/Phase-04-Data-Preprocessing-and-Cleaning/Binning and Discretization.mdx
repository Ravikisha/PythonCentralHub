## Why bin values?

Binning (discretization) converts numeric values into categories:

```
- Age → {0–18, 19–35, 36–60, 60+}
- Spend → {low, medium, high}
```

Use cases:

- Easier reporting and segmentation
- Non-linear relationship capture (sometimes)
- Feature engineering

## `pd.cut` (fixed bins)

```python title="cut" showLineNumbers{1}
import pandas as pd

age = pd.Series([12, 19, 25, 38, 52, 67])

bins = [0, 18, 35, 60, 200]
labels = ["0-18", "19-35", "36-60", "60+"]

age_group = pd.cut(age, bins=bins, labels=labels, right=True, include_lowest=True)
print(age_group)
```

## `pd.qcut` (quantile bins)

Quantile binning tries to put roughly equal number of rows in each bin.

```python title="qcut" showLineNumbers{1}
import pandas as pd

values = pd.Series([10, 15, 20, 25, 30, 40, 60, 100])

bucket = pd.qcut(values, q=3, labels=["low", "mid", "high"])
print(bucket)
```

## Tips

- Choose bins based on domain meaning.
- Quantile bins are useful when distributions are skewed.
- Always check counts per bin after binning.

```p5 title="Scattered ages sorted into bins" desc="Each age lands in exactly one bin based on the bin edges; dot color matches the band it falls into." height="240"
function setup() {
  createCanvas(600, 240);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const ages = [12, 19, 25, 38, 52, 67];
  const bins = [0, 18, 35, 60, 100];
  const labels = ["0-18", "19-35", "36-60", "60+"];
  const colors = [[75, 139, 190], [255, 211, 67], [110, 160, 205], [230, 185, 90]];
  const axisY = 160;
  const toX = (v) => map(v, 0, 90, 60, 540);

  stroke(90, 100, 116);
  strokeWeight(1);
  line(60, axisY, 540, axisY);

  for (let i = 0; i < bins.length; i++) {
    const x = toX(bins[i]);
    stroke(90, 100, 116, 150);
    drawingContext.setLineDash([3, 3]);
    line(x, axisY - 60, x, axisY + 40);
    drawingContext.setLineDash([]);
  }

  function binIndex(v) {
    for (let i = 0; i < bins.length - 1; i++) {
      if (v > bins[i] && v <= bins[i + 1]) return i;
    }
    return bins.length - 2;
  }

  noStroke();
  for (let i = 0; i < labels.length; i++) {
    const x0 = toX(bins[i]);
    const x1 = toX(bins[i + 1]);
    const c = colors[i];
    fill(c[0], c[1], c[2], 50);
    rect(x0, axisY + 10, x1 - x0, 20);
    fill(c[0], c[1], c[2]);
    textAlign(CENTER, CENTER);
    textSize(10);
    text(labels[i], (x0 + x1) / 2, axisY + 20);
  }

  for (const a of ages) {
    const idx = binIndex(a);
    const c = colors[idx];
    fill(c[0], c[1], c[2]);
    circle(toX(a), axisY - 30, 9);
  }

  fill(200);
  textAlign(CENTER, BOTTOM);
  textSize(10);
  text("ages scattered along a number line", 300, axisY - 45);
}
```

:::note[From the book]
McKinney points out the key difference: `pandas.cut` "will not usually result in each
bin having the same number of data points," since it slices by value range. `pandas.qcut`
uses sample quantiles instead, giving you roughly equally sized bins even when the
underlying data is skewed.
:::
