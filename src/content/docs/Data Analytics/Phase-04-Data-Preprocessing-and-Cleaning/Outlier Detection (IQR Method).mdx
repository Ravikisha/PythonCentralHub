## What is IQR?

The **Interquartile Range (IQR)** is:

- Q3 (75th percentile) − Q1 (25th percentile)

A common rule flags outliers outside:

- Lower bound = Q1 − 1.5 × IQR
- Upper bound = Q3 + 1.5 × IQR

## Example

```python title="IQR bounds" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({"amount": [100, 110, 120, 115, 105, 130, 125, 3000]})

q1 = df["amount"].quantile(0.25)
q3 = df["amount"].quantile(0.75)
iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

print("Q1:", q1)
print("Q3:", q3)
print("IQR:", iqr)
print("Bounds:", lower, upper)

outliers = df[(df["amount"] < lower) | (df["amount"] > upper)]
print(outliers)
```

## Flag outliers (keep rows, add a column)

```python title="Outlier flag" showLineNumbers{1}
df["is_outlier"] = (df["amount"] < lower) | (df["amount"] > upper)
print(df)
```

## Notes

- IQR is robust for skewed data.
- Outlier detection is not outlier removal.
- Always validate outliers with domain context.

A box plot is just this rule drawn as a picture: the box spans Q1 to Q3, the whiskers
reach out to the fences, and anything past them is plotted as its own dot.

```p5 title="Boxplot with IQR fences" desc="The box covers Q1-Q3, whiskers extend to the fences, and points beyond the fences are outliers." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const midY = 140;
  const toX = (v) => map(v, 0, 3000, 60, 540);
  const q1 = 600, q3 = 900, median = 750;
  const iqr = q3 - q1;
  const lowerFence = q1 - 1.5 * iqr;
  const upperFence = q3 + 1.5 * iqr;

  stroke(150, 160, 175);
  strokeWeight(1.5);
  line(toX(lowerFence), midY, toX(q1), midY);
  line(toX(q3), midY, toX(upperFence), midY);
  line(toX(lowerFence), midY - 12, toX(lowerFence), midY + 12);
  line(toX(upperFence), midY - 12, toX(upperFence), midY + 12);

  noStroke();
  fill(75, 139, 190, 170);
  rect(toX(q1), midY - 30, toX(q3) - toX(q1), 60, 4);
  stroke(230);
  strokeWeight(2);
  line(toX(median), midY - 30, toX(median), midY + 30);

  noStroke();
  fill(255, 211, 67);
  const outliers = [2550, 2800];
  for (const o of outliers) {
    circle(toX(o), midY, 8);
  }

  fill(190);
  noStroke();
  textSize(10);
  textAlign(CENTER, TOP);
  text("Q1", toX(q1), midY + 40);
  text("median", toX(median), midY + 40);
  text("Q3", toX(q3), midY + 40);
  fill(140);
  textAlign(CENTER, BOTTOM);
  text("lower fence", toX(lowerFence), midY - 22);
  text("upper fence", toX(upperFence), midY - 22);
  fill(255, 211, 67);
  text("outliers", toX(2675), midY - 44);
}
```

:::caution[From the book]
To flag outliers across several columns at once, McKinney's example is
`data[(data.abs() > 3).any(axis="columns")]`. The parentheses around the comparison
are required — Python must finish evaluating `data.abs() > 3` before `.any()` can be
called on the result.
:::
