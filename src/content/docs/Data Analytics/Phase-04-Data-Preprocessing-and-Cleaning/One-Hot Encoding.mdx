## What is one-hot encoding?

One-hot encoding converts a categorical column into multiple binary columns.

Example:

```
- city = {Pune, Delhi}
```

becomes:

- city_Pune (0/1)
- city_Delhi (0/1)

## One-hot encoding with Pandas

```python title="get_dummies" showLineNumbers{1}
import pandas as pd

df = pd.DataFrame({"city": ["Pune", "Delhi", "Pune"], "amount": [100, 200, 150]})

encoded = pd.get_dummies(df, columns=["city"], drop_first=False)
print(encoded)
```

### Avoid dummy variable trap (optional)

For some linear models, you can drop one category:

```python title="drop_first" showLineNumbers{1}
encoded = pd.get_dummies(df, columns=["city"], drop_first=True)
print(encoded)
```

## One-hot encoding with scikit-learn

```python title="OneHotEncoder" showLineNumbers{1}
import pandas as pd
from sklearn.preprocessing import OneHotEncoder

X = pd.DataFrame({"city": ["Pune", "Delhi", "Pune"]})

enc = OneHotEncoder(sparse_output=False, handle_unknown="ignore")

arr = enc.fit_transform(X[["city"]])
print(arr)
print(enc.get_feature_names_out(["city"]))
```

## Tips

- High-cardinality categories (thousands of unique values) can explode feature count.
- Consider grouping rare categories into "Other".

:::tip[From the book]
McKinney's pattern for merging dummies back with the rest of a DataFrame:
`dummies = pd.get_dummies(df["key"], prefix="key")` then `df[["data1"]].join(dummies)`.
Passing `prefix` keeps the new binary columns readable once they're joined back in —
useful if more than one column gets one-hot encoded.
:::
