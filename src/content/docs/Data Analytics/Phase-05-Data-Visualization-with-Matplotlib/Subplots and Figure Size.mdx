You can't draw straight onto a blank Figure — McKinney is explicit about this: "You
can't make a plot with a blank figure. You have to create one or more subplots." The
convenient shortcut `plt.subplots(nrows, ncols)` creates the figure *and* a NumPy array
of Axes in one call, so you can index into it like `axes[0, 1]` for "row 0, column 1."

```mermaid title="Building a subplot grid" desc="plt.subplots(rows, cols) creates one Figure containing a grid of independent Axes you can index into."
flowchart TD
  A["plt.subplots(2, 2)"] --> B["fig"]
  A --> C["axes - a 2x2 array of Axes"]
  C --> D["axes[0, 0]"]
  C --> E["axes[0, 1]"]
  C --> F["axes[1, 0]"]
  C --> G["axes[1, 1]"]
  D --> H["Each axes plots independently"]
```

## Subplots

```python title="2x2 subplots" showLineNumbers{1}
import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2, figsize=(10, 6))

axes[0, 0].plot([1, 2, 3], [1, 4, 9])
axes[0, 0].set_title("Line")

axes[0, 1].bar(["A", "B", "C"], [5, 2, 7])
axes[0, 1].set_title("Bar")

axes[1, 0].hist([1, 1, 2, 2, 2, 3, 4], bins=4, edgecolor="black")
axes[1, 0].set_title("Histogram")

axes[1, 1].scatter([1, 2, 3, 4], [10, 11, 9, 12])
axes[1, 1].set_title("Scatter")

fig.suptitle("Mini dashboard")
plt.tight_layout()
plt.show()
```

## Figure size rules

- Use larger figures for long labels and multiple subplots.
- Smaller is fine for single simple plots.

## Visualize it

A `Figure` is just the outer frame — each mini panel inside is its own independent
`Axes` with its own data, ticks, and title:

```p5 title="A figure made of a grid of Axes" desc="plt.subplots(2, 2) builds one Figure holding four independent Axes, each with its own chart." height="300"
function setup() {
  createCanvas(600, 300);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const fx = 20, fy = 20, fw = width - 40, fh = height - 40;
  noFill();
  stroke(90, 100, 116);
  strokeWeight(1.5);
  rect(fx, fy, fw, fh, 6);
  noStroke();
  fill(255, 211, 67);
  textSize(11);
  textAlign(LEFT, TOP);
  text("Figure", fx + 8, fy + 6);
  const pad = 16, cellW = (fw - pad * 3) / 2, cellH = (fh - pad * 3) / 2;
  const kinds = ["line", "bar", "hist", "scatter"];
  for (let r = 0; r < 2; r++) {
    for (let c = 0; c < 2; c++) {
      const ax = fx + pad + c * (cellW + pad);
      const ay = fy + pad + 22 + r * (cellH + pad);
      stroke(70, 80, 96);
      strokeWeight(1);
      noFill();
      rect(ax, ay, cellW, cellH, 3);
      drawMini(ax, ay, cellW, cellH, kinds[r * 2 + c]);
    }
  }
  function drawMini(x, y, w, h, kind) {
    noStroke();
    fill(150);
    textSize(9);
    textAlign(LEFT, BOTTOM);
    text("axes[" + Math.floor((y - fy) / (h + pad)) + ", " + Math.floor((x - fx) / (w + pad)) + "]  " + kind, x + 4, y - 3);
    if (kind === "line") {
      stroke(75, 139, 190);
      noFill();
      beginShape();
      for (let i = 0; i <= 4; i++) vertex(x + 8 + i * (w - 16) / 4, y + h - 10 - Math.sin(i) * (h - 30));
      endShape();
    } else if (kind === "bar") {
      noStroke();
      fill(75, 139, 190);
      const vals = [0.4, 0.8, 0.55];
      for (let i = 0; i < 3; i++) {
        const bh = vals[i] * (h - 20);
        rect(x + 12 + i * (w - 24) / 3, y + h - 10 - bh, (w - 24) / 3 - 6, bh);
      }
    } else if (kind === "hist") {
      noStroke();
      fill(255, 211, 67);
      const vals = [0.3, 0.6, 0.9, 0.5, 0.2];
      for (let i = 0; i < 5; i++) {
        const bh = vals[i] * (h - 20);
        rect(x + 6 + i * (w - 12) / 5, y + h - 10 - bh, (w - 12) / 5 - 2, bh);
      }
    } else {
      noStroke();
      fill(120, 200, 120);
      randomSeed(3);
      for (let i = 0; i < 12; i++) circle(x + 10 + random(w - 20), y + 10 + random(h - 20), 5);
    }
  }
}
```

:::tip[From the book]
McKinney warns that `fig.subplots_adjust(wspace=0, hspace=0)` (squeezing spacing to
zero) often makes tick labels overlap between neighboring panels — matplotlib won't
detect or fix this for you. `sharex=True` / `sharey=True` help, but check the rendered
figure before shipping it.
:::

## Tip

`plt.tight_layout()` prevents label overlaps in most cases.
