A scatter plot places one point per pair of values `(x, y)`, so you can see at a glance
whether two variables move together. McKinney uses this exact technique to check
relationships in economic data — for example, plotting the change in money supply
(`m1`) against the change in unemployment (`unemp`) to look for a pattern.

```mermaid title="Reading a scatter plot" desc="Each point is one observation; the overall pattern of points reveals the relationship between two variables."
flowchart LR
  A["Two numeric columns"] --> B["One point per row: (x, y)"]
  B --> C{"Points trend together?"}

```

## Basic scatter plot

```python title="Scatter" showLineNumbers{1}
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5, 6, 7]
y = [50, 55, 65, 70, 75, 78, 85]

plt.figure(figsize=(7, 4))
plt.scatter(x, y)
plt.title("Hours vs score")
plt.xlabel("Hours")
plt.ylabel("Score")
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## Handle overplotting

Use transparency:

```python title="Alpha" showLineNumbers{1}
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
plt.scatter(x, y, alpha=0.6)
plt.title("Scatter with alpha")
plt.tight_layout()
plt.show()
```

## Annotate points

```python title="Annotate" showLineNumbers{1}
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
plt.scatter(x, y)

plt.annotate("top", xy=(7, 85), xytext=(6, 88), arrowprops={"arrowstyle": "->"})

plt.title("Annotated scatter")
plt.tight_layout()
plt.show()
```

## Visualize it

Each dot below is one `(x, y)` observation — watch the cloud of points build up and
notice the upward trend:

```p5 title="A scatter plot shows one point per observation" desc="Every (x, y) pair becomes one dot; the pattern of dots reveals whether the two variables relate." height="280"
let pts = [];
let n = 0;
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  randomSeed(7);
  for (let i = 0; i < 60; i++) {
    const x = i / 60;
    const y = x * 0.7 + random(-0.12, 0.12) + 0.15;
    pts.push([x, y]);
  }
}
function draw() {
  background(13, 17, 23);
  const gx = 40, gy = 24, gw = width - 70, gh = height - 70;
  stroke(60, 70, 84);
  strokeWeight(1);
  line(gx, gy + gh, gx + gw, gy + gh);
  line(gx, gy, gx, gy + gh);
  noStroke();
  for (let i = 0; i < n; i++) {
    const px = gx + pts[i][0] * gw;
    const py = gy + gh - pts[i][1] * gh;
    fill(75, 139, 190, 210);
    circle(px, py, 8);
  }
  fill(150);
  textSize(11);
  textAlign(LEFT, TOP);
  text(n + " / " + pts.length + " points plotted", gx, 6);
  if (frameCount % 2 === 0 && n < pts.length) n++;
  if (n >= pts.length && frameCount % 90 === 0) n = 0;
}
```

:::tip[From the book]
McKinney reaches for `sns.regplot()` when a scatter plot needs a fitted line — it draws
the scatter *and* a linear regression line in one call, which is a fast way to eyeball
whether a relationship looks linear before running any real statistics.
:::
