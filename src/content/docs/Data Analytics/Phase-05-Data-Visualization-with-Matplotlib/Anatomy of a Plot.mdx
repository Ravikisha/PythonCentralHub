## Matplotlib anatomy

A typical plot has:

- Title
- X label / Y label
- Axes limits
- Ticks
- Legend (if multiple series)
- Grid (optional)

You can't make a plot straight onto a blank `Figure` — a `Figure` is just the canvas.
You always need at least one `Axes` (a plotting area) inside it before you can draw
anything. Most of the customization methods you'll use (`set_title`, `set_xlim`,
`set_xticks`, ...) live on that `Axes` object.

```mermaid title="The plot pipeline" desc="A Figure holds Axes; each Axes owns its own ticks, limits, labels, and plotted data."
flowchart TD
  A["fig = plt.figure()"] --> B["ax = fig.add_subplot(...)"]
  B --> C["ax.plot(...) / ax.bar(...) / ..."]
  C --> D["ax.set_title() / set_xlabel() / set_ylabel()"]
  D --> E["ax.set_xlim() / set_xticks()"]
  E --> F["plt.show() or fig.savefig()"]
```

## The Figure + Axes model

```python title="Figure + Axes" showLineNumbers{1}
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([1, 2, 3, 4], [10, 6, 8, 4])

ax.set_title("Anatomy")
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.grid(True, alpha=0.3)

plt.show()
```

## Limits and ticks

```python title="Limits and ticks" showLineNumbers{1}
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([1, 2, 3, 4], [10, 6, 8, 4])

ax.set_xlim(0, 5)
ax.set_ylim(0, 12)

ax.set_xticks([1, 2, 3, 4])
ax.set_yticks([0, 4, 8, 12])

ax.set_title("Limits and ticks")
plt.tight_layout()
plt.show()
```

## Visualize it

Every Matplotlib chart is built from the same nested parts: a **Figure** holds one or more
**Axes**, and each Axes carries the title, the x/y labels, the ticks, and the plotted data.
Here they are, labelled:

```p5 title="The parts of a Matplotlib figure" desc="A Figure holds one or more Axes; each Axes has a title, x/y labels, ticks, and the plotted data." height="320"
function setup() {
  createCanvas(600, 320);
  textFont("monospace");
  textAlign(LEFT, CENTER);
}
function draw() {
  background(13, 17, 23);
  const fx = 24, fy = 24, fw = width - 48, fh = height - 48;
  noFill();
  stroke(90, 100, 116);
  strokeWeight(1.5);
  rect(fx, fy, fw, fh, 6);
  const ax = 150, ay = 60, aw = 290, ah = 180;
  stroke(150, 160, 175);
  strokeWeight(1.5);
  line(ax, ay, ax, ay + ah);
  line(ax, ay + ah, ax + aw, ay + ah);
  const data = [40, 95, 60, 140, 85];
  const bw = aw / data.length;
  noStroke();
  for (let i = 0; i < data.length; i++) {
    fill(75, 139, 190);
    rect(ax + i * bw + 10, ay + ah - data[i], bw - 20, data[i]);
  }
  stroke(150, 160, 175);
  for (let i = 0; i <= 4; i++) {
    const yy = ay + ah - i / 4 * ah;
    line(ax - 5, yy, ax, yy);
  }
  noStroke();
  fill(150);
  textSize(9);
  textAlign(RIGHT, CENTER);
  for (let i = 0; i <= 4; i++) {
    const yy = ay + ah - i / 4 * ah;
    text(i * 40, ax - 8, yy);
  }
  fill(230);
  textSize(13);
  textAlign(CENTER, CENTER);
  text("Sales by Quarter", ax + aw / 2, ay - 16);
  fill(185);
  textSize(11);
  text("Quarter", ax + aw / 2, ay + ah + 24);
  push();
  translate(ax - 46, ay + ah / 2);
  rotate(-HALF_PI);
  text("Revenue", 0, 0);
  pop();
  stroke(255, 211, 67, 140);
  strokeWeight(1);
  line(fx + fw - 8, fy + 16, fx + fw - 74, fy + 16);
  line(ax + aw, ay + 8, ax + aw + 26, ay + 8);
  line(ax + bw * 3 + bw / 2, ay + ah - 140, ax + aw + 26, ay + 70);
  line(ax - 5, ay + ah - 90, ax + aw + 26, ay + 120);
  noStroke();
  fill(255, 211, 67);
  textSize(10);
  textAlign(LEFT, CENTER);
  text("Figure", fx + fw - 70, fy + 16);
  text("Axes", ax + aw + 30, ay + 8);
  text("data", ax + aw + 30, ay + 70);
  text("ticks", ax + aw + 30, ay + 120);
  noLoop();
}
```

## Tip

Use the object-oriented approach for consistent, reusable plotting.

:::tip[From the book]
McKinney notes that xlim, xticks, and similar methods all follow the same pattern:
called with no arguments they **return** the current value (`ax.get_xlim()`); called
with an argument they **set** it (`ax.set_xlim([0, 10])`). Once you know that pattern,
you already know most of the Axes API.
:::
