Bar charts compare a value across discrete categories — each category gets one bar,
and the bar's height (or length, for horizontal bars) shows its value. As McKinney
notes, `plot.bar()` and `plot.barh()` even work directly with a labeled `Series` or
`DataFrame`: the index becomes the category ticks automatically.


## Basic bar chart

```python title="Bar" showLineNumbers{1}
import matplotlib.pyplot as plt

cities = ["Pune", "Delhi", "Mumbai", "Bengaluru"]
sales = [120, 180, 90, 160]

plt.figure(figsize=(7, 4))
plt.bar(cities, sales)
plt.title("Sales by city")
plt.xlabel("City")
plt.ylabel("Sales")
plt.xticks(rotation=20)
plt.tight_layout()
plt.show()
```

## Sorted bars

```python title="Sorted bars" showLineNumbers{1}
import matplotlib.pyplot as plt

data = {"Pune": 120, "Delhi": 180, "Mumbai": 90, "Bengaluru": 160}
items = sorted(data.items(), key=lambda x: x[1], reverse=True)
labels = [k for k, _ in items]
values = [v for _, v in items]

plt.figure(figsize=(7, 4))
plt.bar(labels, values)
plt.title("Sales by city (sorted)")
plt.tight_layout()
plt.show()
```

## Horizontal bars

```python title="Horizontal bar" showLineNumbers{1}
import matplotlib.pyplot as plt

labels = ["Very long category A", "Long B", "C"]
values = [12, 19, 7]

plt.figure(figsize=(7, 4))
plt.barh(labels, values)
plt.title("Horizontal bar chart")
plt.xlabel("Value")
plt.tight_layout()
plt.show()
```

## Visualize it

Watch each category's bar grow to its value — the tallest bar is the easiest to spot
because bars share the same zero baseline:

```p5 title="A bar chart compares categories" desc="Each bar's height is proportional to its value, starting from a shared zero baseline." height="280"
const data = [["Pune", 120], ["Delhi", 180], ["Mumbai", 90], ["Bengaluru", 160]];
let grow = 0;
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
}
function draw() {
  background(13, 17, 23);
  const gx = 50, gy = 24, gw = width - 80, gh = height - 80;
  const mx = Math.max.apply(null, data.map(d => d[1]));
  const bw = gw / data.length;
  stroke(60, 70, 84);
  strokeWeight(1);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  textAlign(CENTER, TOP);
  for (let i = 0; i < data.length; i++) {
    const h = data[i][1] / mx * gh * grow;
    fill(75, 139, 190);
    rect(gx + i * bw + 12, gy + gh - h, bw - 24, h, 3);
    fill(200);
    textSize(10);
    text(data[i][0], gx + i * bw + bw / 2, gy + gh + 8);
    fill(255, 211, 67);
    text(Math.round(data[i][1] * grow), gx + i * bw + bw / 2, gy + gh - h - 16);
  }
  if (grow < 1) grow += 0.02;
  else if (frameCount % 100 === 0) grow = 0;
}
```

:::tip[From the book]
McKinney's tip: a stacked bar chart (`stacked=True`) is a quick way to see how a whole
splits across sub-categories — for example, party size share by day of week. But once
you have more than three or four stacked segments, a stacked bar becomes as hard to
read as a pie chart. Consider small multiples (separate subplots) instead.
:::

## Tip

Start y-axis at 0 for bar charts to avoid misleading comparisons.
