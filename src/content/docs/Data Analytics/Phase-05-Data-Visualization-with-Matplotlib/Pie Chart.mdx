## A warning about pie charts

Pie charts are often hard to compare precisely.

Prefer:

- Bar charts (best)
- Donut charts only for simple cases

Still, you may see pie charts in reporting, so here’s how to make one safely.

```mermaid title="How a pie chart is built" desc="Each category's share of the total becomes an angle; all the angles together sweep a full circle."
flowchart LR
  A["Category values"] --> B["Sum to get the total"]
  B --> C["Each value's share = value / total"]
  C --> D["Share * 360deg = slice angle"]
  D --> E["Slices drawn around a full circle"]
```

## Basic pie chart

```python title="Pie" showLineNumbers{1}
import matplotlib.pyplot as plt

labels = ["A", "B", "C"]
values = [50, 30, 20]

plt.figure(figsize=(6, 6))
plt.pie(values, labels=labels, autopct="%1.0f%%", startangle=90)
plt.title("Category share")
plt.tight_layout()
plt.show()
```

## Improve readability

```python title="Explode biggest slice" showLineNumbers{1}
import matplotlib.pyplot as plt

explode = [0.1, 0.0, 0.0]

plt.figure(figsize=(6, 6))
plt.pie(values, labels=labels, autopct="%1.0f%%", startangle=90, explode=explode)
plt.title("Category share")
plt.tight_layout()
plt.show()
```

## Visualize it

A pie chart divides a whole into slices, where each slice's **angle** is proportional to its
share of the total — so all the slices together make up 100%. Watch it build slice by slice:

```p5 title="A pie chart splits a whole into slices" desc="Each slice's angle is proportional to its share of the total; together they add up to 100%." height="300"
const data = [["A", 35], ["B", 25], ["C", 20], ["D", 12], ["E", 8]];
const cols = [[75, 139, 190], [255, 211, 67], [120, 200, 120], [220, 120, 90], [150, 120, 200]];
let sweep = 0;
let t = 0;
function setup() {
  createCanvas(600, 300);
  textFont("monospace");
}
function draw() {
  background(13, 17, 23);
  const cx = 205, cy = height / 2, R = 108;
  const total = data.reduce((s, d) => s + d[1], 0);
  let a = -HALF_PI;
  for (let i = 0; i < data.length; i++) {
    const ang = data[i][1] / total * TWO_PI;
    const a2 = Math.min(a + ang, -HALF_PI + sweep);
    if (a2 > a) {
      noStroke();
      fill(cols[i][0], cols[i][1], cols[i][2]);
      arc(cx, cy, R * 2, R * 2, a, a2, PIE);
      if (-HALF_PI + sweep >= a + ang) {
        const mid = a + ang / 2;
        const lx = cx + Math.cos(mid) * R * 0.62, ly = cy + Math.sin(mid) * R * 0.62;
        fill(18);
        textSize(12);
        textAlign(CENTER, CENTER);
        text(Math.round(data[i][1] / total * 100) + "%", lx, ly);
      }
    }
    a += ang;
  }
  textAlign(LEFT, CENTER);
  for (let i = 0; i < data.length; i++) {
    const ly = 72 + i * 32;
    noStroke();
    fill(cols[i][0], cols[i][1], cols[i][2]);
    rect(392, ly - 8, 16, 16, 3);
    fill(210);
    textSize(13);
    text(data[i][0] + "  (" + data[i][1] + ")", 416, ly);
  }
  t++;
  if (sweep < TWO_PI) sweep += 0.06;
  else if (t % 120 === 0) sweep = 0;
}
```

## Better alternative

If your goal is comparison, use a bar chart.

:::tip[From the book]
McKinney recommends a handy recipe for turning any categorical column into a chart:
`s.value_counts().plot.bar()`. It counts each unique value and plots the counts in one
line — and it's usually a better first look than a pie chart, since bar heights are far
easier for the eye to compare precisely than pie slice angles.
:::
