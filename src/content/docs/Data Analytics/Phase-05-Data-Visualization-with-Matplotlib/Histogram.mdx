A histogram is really a bar plot in disguise: McKinney describes it as "a discretized
display of value frequency." Your values get split into evenly spaced **bins**, and
the bar height for each bin is simply how many values landed inside it.

```mermaid title="From raw values to a histogram" desc="Values are split into evenly spaced bins, then a bar is drawn per bin showing how many values fall inside it."
flowchart LR
  A["Raw numeric values"] --> B["Split into N equal-width bins"]
  B --> C["Count values per bin"]
  C --> D["Draw one bar per bin"]
  D --> E["Shape reveals skew, outliers, spread"]
```

## Basic histogram

```python title="Histogram" showLineNumbers{1}
import matplotlib.pyplot as plt

values = [55, 60, 62, 63, 65, 67, 70, 72, 76, 80, 81, 85, 90, 92, 95]

plt.figure(figsize=(7, 4))
plt.hist(values, bins=8, edgecolor="black")
plt.title("Distribution")
plt.xlabel("Value")
plt.ylabel("Count")
plt.tight_layout()
plt.show()
```

## Try different bins

```python title="Bins" showLineNumbers{1}
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(10, 4), sharey=True)

axes[0].set_title("bins=4")

axes[1].hist(values, bins=12, edgecolor="black")
axes[1].set_title("bins=12")

plt.tight_layout()
plt.show()
```

## Visualize it

A histogram sorts your values into **bins** and draws a bar for each — the bar's height is
how many values landed in that bin. Together the bars reveal the shape of the distribution
(here, a bell centred near the middle):

```p5 title="A histogram bins your data" desc="Each value falls into a bin; the bar height is the count in that bin, revealing the distribution's shape." height="280"
let data = [];
const BINS = 12;
function gen() {
  data = [];
  for (let i = 0; i < 200; i++) data.push(randomGaussian() * 0.15 + 0.5);
}
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  gen();
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const gx = 40, gy = 24, gw = width - 70, gh = height - 70;
  const bins = new Array(BINS).fill(0);
  for (const v of data) {
    let b = Math.floor(v * BINS);
    b = constrain(b, 0, BINS - 1);
    bins[b]++;
  }
  const mx = Math.max.apply(null, bins.concat([1]));
  const bw = gw / BINS;
  noStroke();
  for (let b = 0; b < BINS; b++) {
    const h = bins[b] / mx * gh;
    fill(75, 139, 190);
    rect(gx + b * bw + 1, gy + gh - h, bw - 2, h);
  }
  stroke(60, 70, 84);
  strokeWeight(1);
  line(gx, gy + gh, gx + gw, gy + gh);
  noStroke();
  fill(150);
  textSize(11);
  textAlign(CENTER, TOP);
  text("value  ->", gx + gw / 2, gy + gh + 18);
  fill(107, 169, 221);
  textSize(12);
  textAlign(LEFT, CENTER);
  text(data.length + " values,  " + BINS + " bins", gx, 13);
}
```

:::tip[From the book]
McKinney also introduces the **density plot** (or KDE) as a smoother cousin of the
histogram — instead of discrete bars, it estimates a continuous curve that could have
generated your data. seaborn's `histplot()` can even draw both the histogram bars and
the KDE curve together, which is handy for spotting bimodal distributions (two humps
instead of one).
:::

## Tip

Histograms are a first check before transformations (like log scaling).
