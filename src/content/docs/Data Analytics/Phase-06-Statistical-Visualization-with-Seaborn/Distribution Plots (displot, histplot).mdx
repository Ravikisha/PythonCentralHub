## Why distribution plots matter

Distribution plots answer:

- What values are most common?
- Is the data skewed?
- Are there outliers?
- Do groups behave differently?

```mermaid title="How histplot builds a histogram" desc="Values are sorted into equal-width bins, counted, then drawn as bars — with an optional KDE curve laid on top."
flowchart LR
  A["Raw values"] --> B["Split into bins<br/>(equal-width ranges)"]
  B --> C["Count values<br/>per bin"]
  C --> D["Draw bars<br/>(histplot)"]
  D --> E["Optional: overlay<br/>a smooth KDE curve"]
```

:::tip[From the book]
McKinney describes a histogram as "a kind of bar plot that gives a discretized display of value
frequency" — the data is split into evenly spaced bins and each bar shows how many points fall in
that bin. seaborn's `histplot` can draw the histogram **and** a smooth density curve in the same
call, which is handy for spotting bimodal (two-peak) data.
:::

## `histplot` (single plot)

```python title="histplot" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

values = [55, 60, 62, 63, 65, 67, 70, 72, 76, 80, 81, 85, 90, 92, 95]

plt.figure(figsize=(7, 4))
sns.histplot(values, bins=8, kde=False)
plt.title("Histogram")
plt.xlabel("Value")
plt.ylabel("Count")
plt.tight_layout()
plt.show()
```

## Add KDE on top

```python title="histplot + kde" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
sns.histplot(values, bins=8, kde=True)
plt.title("Histogram + KDE")
plt.tight_layout()
plt.show()
```

## Visualize it

Bars count how many points land in each bin. The smooth curve is a KDE — an estimate of the
underlying probability density that doesn't depend on where the bin edges happen to fall:

```p5 title="Histogram bars with a KDE curve" desc="Amber bars are the binned counts; the blue curve is the smooth density estimate drawn over them." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const bars = [2, 5, 9, 14, 18, 16, 10, 6, 3, 1];
  const baseY = 210, left = 50, chartW = 500, chartH = 160;
  const barW = chartW / bars.length;
  const maxCount = Math.max(...bars);

  stroke(60, 68, 80);
  strokeWeight(1);
  line(left, baseY, left + chartW, baseY);

  noStroke();
  fill(255, 211, 67, 200);
  for (let i = 0; i < bars.length; i++) {
    const h = (bars[i] / maxCount) * chartH;
    rect(left + i * barW + 2, baseY - h, barW - 4, h);
  }

  // Smooth KDE-like curve over the bar tops
  stroke(75, 139, 190);
  strokeWeight(2.5);
  noFill();
  beginShape();
  for (let i = -1; i <= bars.length; i++) {
    const idx = constrain(i, 0, bars.length - 1);
    const x = left + idx * barW + barW / 2;
    const h = (bars[idx] / maxCount) * chartH * 1.05;
    curveVertex(x, baseY - h);
  }
  endShape();

  fill(200);
  noStroke();
  textSize(11);
  textAlign(CENTER, TOP);
  text("value bins", left + chartW / 2, baseY + 12);
  fill(255, 211, 67);
  textAlign(LEFT, TOP);
  text("histogram bars", left, 20);
  fill(107, 169, 221);
  text("KDE curve", left, 36);
}
```

## `displot` (figure-level)

`displot` can create more complex plots and handles facets.

```python title="displot" showLineNumbers{1}
import seaborn as sns

# Seaborn includes sample datasets

tips = sns.load_dataset("tips")

sns.displot(data=tips, x="total_bill", bins=20, kde=True)
```

## Compare distributions by group

```python title="Compare groups" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.histplot(data=tips, x="total_bill", hue="sex", bins=20, kde=True, element="step")
plt.title("Total bill distribution by sex")
plt.tight_layout()
plt.show()
```

## Tips

- Use the same bin settings when comparing groups.
- KDE is a smooth estimate; it can hide small details.
- For heavy outliers, consider log scaling.
