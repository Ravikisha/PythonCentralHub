## Why pair plots?

Pair plots are a fast way to inspect:

- Pairwise relationships between variables
- Distributions on the diagonal
- Group separation using `hue`

They are great early in EDA.

```mermaid title="How pairplot fills a grid" desc="pairplot builds an n×n grid: scatter plots off the diagonal, a distribution plot on the diagonal."
flowchart TD
  A["n numeric columns"] --> B["Build an n x n grid"]
  B --> C["Off-diagonal cells:<br/>scatter of column i vs j"]
  B --> D["Diagonal cells:<br/>histogram or KDE of column i"]
```

:::tip[From the book]
McKinney calls this a "pairs plot or scatter plot matrix" and notes that "making such a plot from
scratch is a bit of work, so seaborn has a convenient `pairplot` function" — it even supports
`diag_kind=\"kde\"` for smooth diagonal curves and a `plot_kws` dict to pass options (like
`{\"alpha\": 0.2}`) down to every individual scatter plot.
:::

## Basic pairplot

```python title="pairplot" showLineNumbers{1}
import seaborn as sns

penguins = sns.load_dataset("penguins").dropna()

sns.pairplot(penguins[[
    "bill_length_mm",
    "bill_depth_mm",
    "flipper_length_mm",
    "body_mass_g",
]])
```

## Pairplot with hue

```python title="pairplot with hue" showLineNumbers{1}
import seaborn as sns

penguins = sns.load_dataset("penguins").dropna()

sns.pairplot(
    penguins,
    vars=["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"],
    hue="species",
)
```

## Tips

- Pair plots can be slow for large datasets. Sample rows if needed.
- Use `hue` to check if groups separate naturally.
