## Box plot recap

Box plots show:

- Median (middle line)
- Q1 and Q3 (box)
- Spread (IQR)
- Outliers (points)

They are excellent for comparing a numeric variable across categories.

```mermaid title="From sorted values to a box plot" desc="Quartiles split the sorted data into four equal chunks; the box, whiskers, and outlier dots are drawn from those cut points."
flowchart LR
  A["Sort the values"] --> B["Find Q1, median, Q3"]
  B --> C["Box = Q1 to Q3"]
  B --> D["Whiskers = in-range min/max"]
  B --> E["Outliers = points<br/>beyond the whiskers"]
```

:::tip[From the book]
McKinney highlights `sns.catplot(..., kind=\"box\")` as a quick way to get box plots for
categorical data — "box plots (which show the median, quartiles, and outliers) can be an
effective visualization type" when you want to compare a numeric column across several groups at
once, like tipping percentage by day.
:::

## Seaborn boxplot

```python title="Boxplot" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.boxplot(data=tips, x="day", y="total_bill")
plt.title("Total bill by day")
plt.xlabel("Day")
plt.ylabel("Total bill")
plt.tight_layout()
plt.show()
```

## Add hue for a second grouping

```python title="Boxplot with hue" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.boxplot(data=tips, x="day", y="total_bill", hue="sex")
plt.title("Total bill by day and sex")
plt.tight_layout()
plt.show()
```

## Visualize it

A box plot is a compact summary of a distribution's shape. The box spans **Q1 to Q3** (the
middle 50% of the data), the line inside is the **median**, the whiskers reach to the
smallest/largest values still in range, and any dots beyond are **outliers**:

```p5 title="Anatomy of a box plot" desc="The box is Q1 to Q3, the inner line is the median, whiskers reach the in-range min/max, and dots beyond are outliers." height="240"
function setup() {
  createCanvas(600, 240);
  textFont("monospace");
}
function draw() {
  background(13, 17, 23);
  const y = 132, bh = 50;
  const xmap = (v) => 70 + v / 100 * 460;
  const q1 = 30, med = 45, q3 = 62, wlo = 12, whi = 88;
  const outliers = [3, 97];
  stroke(150, 160, 175);
  strokeWeight(1.5);
  line(xmap(wlo), y, xmap(q1), y);
  line(xmap(q3), y, xmap(whi), y);
  line(xmap(wlo), y - 12, xmap(wlo), y + 12);
  line(xmap(whi), y - 12, xmap(whi), y + 12);
  noStroke();
  fill(75, 139, 190, 170);
  rect(xmap(q1), y - bh / 2, xmap(q3) - xmap(q1), bh);
  noFill();
  stroke(107, 169, 221);
  strokeWeight(1.5);
  rect(xmap(q1), y - bh / 2, xmap(q3) - xmap(q1), bh);
  stroke(255, 211, 67);
  strokeWeight(3);
  line(xmap(med), y - bh / 2, xmap(med), y + bh / 2);
  noStroke();
  fill(220, 90, 90);
  for (const o of outliers) ellipse(xmap(o), y, 9, 9);
  fill(150);
  textSize(10);
  textAlign(CENTER, TOP);
  text("min", xmap(wlo), y + 16);
  text("Q1", xmap(q1), y + bh / 2 + 6);
  text("Q3", xmap(q3), y + bh / 2 + 6);
  text("max", xmap(whi), y + 16);
  fill(255, 211, 67);
  text("median", xmap(med), y - bh / 2 - 16);
  fill(107, 169, 221);
  textSize(11);
  text("IQR (middle 50%)", (xmap(q1) + xmap(q3)) / 2, y - bh / 2 - 34);
  fill(220, 90, 90);
  textSize(10);
  text("outlier", xmap(3), y - 16);
  noLoop();
}
```

## Tips

- Treat outliers as signals, not always as errors.
- If you need to see the raw points, add `stripplot`.
