## What you’ll learn in Phase 6

Seaborn is a high-level plotting library built on Matplotlib, great for EDA and statistical charts.

In this phase you’ll learn:

- Distributions: hist, KDE
- Categorical comparisons: box, violin, count, bar
- Relationships: regression, joint plots
- Multi-variable exploration: pair plots
- Small multiples: facet grids

## How the phase is organized

Each group of lessons builds on the one before it — start with the foundations, then move
from "one variable" plots toward "many variables at once" plots:

```mermaid title="Seaborn phase roadmap" desc="Lessons progress from foundations to distributions, categorical comparisons, relationships, and finally multi-variable/faceted views."
flowchart TD
  A["Foundations<br/>(Intro to Seaborn, Seaborn vs Matplotlib)"] --> B["Distributions<br/>(histplot / displot, KDE)"]
  B --> C["Categorical comparisons<br/>(box, violin, count, bar)"]
  C --> D["Relationships<br/>(regplot / lmplot, joint plots)"]
  D --> E["Multi-variable views<br/>(pair plots, facet grids)"]
```

:::tip[From the book]
In *Python for Data Analysis*, Wes McKinney introduces seaborn as the library you reach for once
plotting starts to need **aggregation** — like averaging `tip_pct` per day, or a confidence
interval on a bar. Doing that by hand in Matplotlib takes several lines; seaborn functions take a
`data=` DataFrame and column names, and handle the grouping and math for you.
:::
