## What is KDE?

A **Kernel Density Estimate (KDE)** is a smooth curve that approximates the probability density of a continuous variable.

Think of it as a “smoothed histogram”.

```mermaid title="Building a KDE curve" desc="Each data point contributes a small bump (a kernel); adding all the bumps together makes one smooth curve."
flowchart LR
  A["Data points"] --> B["Place a small<br/>bump (kernel) at each point"]
  B --> C["Add all the bumps<br/>together"]
  C --> D["One smooth curve<br/>(the KDE)"]
```

:::tip[From the book]
McKinney calls this "a mixture of kernels" — simpler distributions, usually normal curves,
stacked on top of each other at each data point. seaborn's `kdeplot`/`histplot` compute this for
you, but it needs SciPy installed under the hood to do the math.
:::

## KDE plot

```python title="kdeplot" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

values = [55, 60, 62, 63, 65, 67, 70, 72, 76, 80, 81, 85, 90, 92, 95]

plt.figure(figsize=(7, 4))
sns.kdeplot(values, fill=True)
plt.title("KDE plot")
plt.xlabel("Value")
plt.tight_layout()
plt.show()
```

## Visualize it

Each dot on the axis drops a small bump (its own mini bell curve). Stacking every bump together
produces the single smooth KDE line:

```p5 title="KDE as stacked bumps" desc="Each data point (dot) contributes a small bump; the blue line is the sum of all the bumps." height="240"
function setup() {
  createCanvas(600, 240);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const points = [80, 140, 150, 210, 260, 320, 330, 420, 470, 520];
  const baseY = 190, chartTop = 30, chartW = 520, left = 40;
  const bumpWidth = 34, bumpHeight = 46;

  stroke(60, 68, 80);
  line(left, baseY, left + chartW, baseY);

  // individual kernel bumps (amber, translucent)
  noStroke();
  fill(255, 211, 67, 40);
  for (const px of points) {
    beginShape();
    for (let dx = -bumpWidth; dx <= bumpWidth; dx += 4) {
      const g = Math.exp(-(dx * dx) / (2 * (bumpWidth / 2.2) * (bumpWidth / 2.2)));
      vertex(left + px + dx, baseY - g * bumpHeight);
    }
    vertex(left + px + bumpWidth, baseY);
    vertex(left + px - bumpWidth, baseY);
    endShape(CLOSE);
  }

  // sum curve (blue KDE line)
  stroke(75, 139, 190);
  strokeWeight(2.5);
  noFill();
  beginShape();
  for (let x = 0; x <= chartW; x += 4) {
    let sum = 0;
    for (const px of points) {
      const dx = x - px;
      sum += Math.exp(-(dx * dx) / (2 * (bumpWidth / 2.2) * (bumpWidth / 2.2)));
    }
    vertex(left + x, baseY - sum * 9);
  }
  endShape();

  // data points on the axis
  noStroke();
  fill(255, 211, 67);
  for (const px of points) ellipse(left + px, baseY, 7, 7);

  fill(200);
  textSize(11);
  textAlign(LEFT, TOP);
  text("dots = data points", left, 8);
  fill(107, 169, 221);
  text("line = KDE (sum of bumps)", left + 220, 8);
}
```

## Compare KDE across groups

```python title="KDE by group" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.kdeplot(data=tips, x="total_bill", hue="sex", fill=True, common_norm=False)
plt.title("KDE of total_bill by sex")
plt.tight_layout()
plt.show()
```

## Bandwidth matters

The “bandwidth” controls smoothing:

- Too small → noisy curve
- Too large → over-smoothed curve

Seaborn chooses a default automatically, but you can tune it.

```python title="Adjust bandwidth" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

plt.figure(figsize=(7, 4))
sns.kdeplot(values, bw_adjust=0.6, label="less smooth")
sns.kdeplot(values, bw_adjust=1.6, label="more smooth")
plt.legend()
plt.title("KDE bandwidth effects")
plt.tight_layout()
plt.show()
```
