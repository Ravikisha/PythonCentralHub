## What is `barplot` in Seaborn?

Seaborn’s `barplot` typically plots:

- An **aggregate** (default is mean)
- An uncertainty interval (confidence interval)

This is different from Matplotlib bars where you usually plot raw totals.

```mermaid title="How barplot builds one bar" desc="Every row in a category gets averaged into one bar height, plus a confidence interval line on top."
flowchart LR
  A["All rows for<br/>one category"] --> B["Aggregate<br/>(mean by default)"]
  B --> C["Draw one bar"]
  A --> D["Estimate uncertainty"]
  D --> E["Draw error bar<br/>(95% confidence interval)"]
```

:::tip[From the book]
McKinney runs `sns.barplot(x=\"tip_pct\", y=\"day\", data=tips, orient=\"h\")` and points out: "Because
there are multiple observations for each value in the day, the bars are the average value of
tip_pct. The black lines drawn on the bars represent the 95% confidence interval." Add `hue=` to
split each bar further by another category, like `time`.
:::

## Example: mean total bill by day

```python title="Seaborn barplot" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.barplot(data=tips, x="day", y="total_bill")
plt.title("Mean total bill by day")
plt.tight_layout()
plt.show()
```

## Add hue

```python title="barplot with hue" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.barplot(data=tips, x="day", y="total_bill", hue="sex")
plt.title("Mean total bill by day and sex")
plt.tight_layout()
plt.show()
```

## Change estimator (sum, median, etc.)

```python title="Custom estimator" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.barplot(data=tips, x="day", y="total_bill", estimator=np.median)
plt.title("Median total bill by day")
plt.tight_layout()
plt.show()
```

## Visualize it

The whisker on top of each bar is the confidence interval — it tells you how much the average
might wobble if you resampled the data:

```p5 title="Bars with confidence-interval error bars" desc="Bar height is the group mean; the whisker on top shows the uncertainty around that mean." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const labels = ["Thur", "Fri", "Sat", "Sun"];
  const means = [140, 120, 170, 200];
  const errs = [14, 22, 10, 16];
  const baseY = 220, left = 70, chartW = 460, chartH = 170;
  const maxV = 230;
  const barW = chartW / labels.length;

  stroke(60, 68, 80);
  line(left, baseY, left + chartW, baseY);

  for (let i = 0; i < labels.length; i++) {
    const x = left + i * barW + barW / 2;
    const h = (means[i] / maxV) * chartH;
    const errH = (errs[i] / maxV) * chartH;

    noStroke();
    fill(255, 211, 67, 200);
    rectMode(CENTER);
    rect(x, baseY - h / 2, barW * 0.5, h);
    rectMode(CORNER);

    stroke(75, 139, 190);
    strokeWeight(2);
    line(x, baseY - h - errH, x, baseY - h + errH);
    line(x - 8, baseY - h - errH, x + 8, baseY - h - errH);
    line(x - 8, baseY - h + errH, x + 8, baseY - h + errH);

    noStroke();
    fill(200);
    textSize(11);
    textAlign(CENTER, TOP);
    text(labels[i], x, baseY + 8);
  }

  fill(255, 211, 67);
  textAlign(LEFT, TOP);
  textSize(11);
  text("bar = mean", left, 10);
  fill(107, 169, 221);
  text("whisker = 95% confidence interval", left, 26);
}
```

## Tips

- Use `barplot` for comparing group summaries.
- Use `countplot` when you want raw counts.
- If you already aggregated your data with Pandas, consider Matplotlib bars.
