## What is a joint plot?

A joint plot shows:

- A bivariate relationship (scatter/KDE/hex)
- Marginal distributions on the sides

It’s a compact EDA tool.

```mermaid title="Anatomy of a joint plot" desc="A joint plot combines a center panel (the relationship) with two side panels (each variable's own distribution)."
flowchart TD
  A["x, y columns"] --> B["Center panel:<br/>scatter / KDE / hex"]
  A --> C["Top margin:<br/>histogram of x"]
  A --> D["Right margin:<br/>histogram of y"]
```

:::note
A joint plot is figure-level (like `pairplot` and `lmplot`), so it manages its own figure —
you can't easily drop it into an existing `plt.subplots()` grid the way you can with axes-level
functions like `regplot` or `scatterplot`.
:::

## Joint plot (scatter + hist)

```python title="jointplot" showLineNumbers{1}
import seaborn as sns

tips = sns.load_dataset("tips")

sns.jointplot(data=tips, x="total_bill", y="tip", kind="scatter")
```

## Joint plot with KDE

```python title="jointplot kde" showLineNumbers{1}
import seaborn as sns

tips = sns.load_dataset("tips")

sns.jointplot(data=tips, x="total_bill", y="tip", kind="kde", fill=True)
```

## Visualize it

The center shows how the two variables relate; the strips along the top and right edges show
each variable's own shape, on its own:

```p5 title="Scatter plot with marginal histograms" desc="The center panel is the x-y relationship; the top and right strips are each variable's own histogram." height="280"
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const left = 60, top = 70, w = 420, h = 180;
  const marginTop = 40, marginRight = 60;

  // scatter points
  const pts = [];
  for (let i = 0; i < 40; i++) {
    const x = left + Math.random() * w;
    const y = top + h - (x - left) / w * h * 0.6 - Math.random() * h * 0.35;
    pts.push([x, y]);
  }
  noStroke();
  fill(255, 211, 67, 190);
  for (const [x, y] of pts) ellipse(x, y, 6, 6);

  stroke(60, 68, 80);
  noFill();
  rect(left, top, w, h);

  // top marginal histogram (distribution of x)
  const topBins = [3, 6, 10, 14, 12, 8, 5, 3];
  const binW = w / topBins.length;
  const maxTop = Math.max(...topBins);
  noStroke();
  fill(75, 139, 190, 190);
  for (let i = 0; i < topBins.length; i++) {
    const bh = (topBins[i] / maxTop) * (marginTop - 8);
    rect(left + i * binW + 1, top - 8 - bh, binW - 2, bh);
  }

  // right marginal histogram (distribution of y)
  const rightBins = [4, 9, 15, 11, 7, 3];
  const binH = h / rightBins.length;
  const maxRight = Math.max(...rightBins);
  for (let i = 0; i < rightBins.length; i++) {
    const bw = (rightBins[i] / maxRight) * (marginRight - 8);
    rect(left + w + 8, top + i * binH + 1, bw, binH - 2);
  }

  fill(255, 211, 67);
  textAlign(LEFT, TOP);
  textSize(11);
  text("center = scatter (relationship)", left, top + h + 12);
  fill(107, 169, 221);
  text("edges = marginal histograms", left, top + h + 28);
}
```

## Tips

- For large data, `kind="hex"` is useful to reduce overplotting.
- Joint plots are figure-level, so customization is slightly different.
