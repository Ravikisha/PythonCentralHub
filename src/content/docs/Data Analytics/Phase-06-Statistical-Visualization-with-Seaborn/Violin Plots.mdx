## What is a violin plot?

A violin plot combines:

- A KDE distribution shape
- A box-plot-like summary inside

It’s useful when you want to see the *shape* of distributions (multi-modal, skew).

```mermaid title="Violin = box plot + KDE" desc="A violin plot mirrors a KDE curve left and right to form a shape, with a mini box plot drawn down the middle."
flowchart LR
  A["Numeric column<br/>per category"] --> B["Compute KDE<br/>for each category"]
  B --> C["Mirror the KDE curve<br/>left and right"]
  C --> D["Overlay a mini box<br/>plot in the middle"]
```

:::note
A box plot only shows five numbers (min, Q1, median, Q3, max). A violin plot shows the **entire**
shape of the distribution, so it can reveal things a box plot hides — like two separate peaks
(bimodal data) that would otherwise look like one wide box.
:::

## Violin plot in Seaborn

```python title="Violin plot" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.violinplot(data=tips, x="day", y="total_bill")
plt.title("Total bill distribution by day")
plt.tight_layout()
plt.show()
```

## Add inner summary

```python title="Violin with inner quartiles" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.violinplot(data=tips, x="day", y="total_bill", inner="quartile")
plt.title("Violin plot with quartiles")
plt.tight_layout()
plt.show()
```

## Visualize it

The width of the violin at any height shows how common values near that height are — wider means
more data points cluster there:

```p5 title="Anatomy of a violin plot" desc="The violin's width at each height mirrors the KDE density; the inner bar is a mini box plot." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const cx = 300, baseY = 230, topY = 30, h = baseY - topY;
  // density profile from bottom (0) to top (1): wider in the middle
  const widths = [6, 14, 26, 42, 60, 74, 82, 74, 56, 34, 16, 6];
  const n = widths.length;

  noStroke();
  fill(75, 139, 190, 130);
  beginShape();
  for (let i = 0; i < n; i++) {
    const y = baseY - (i / (n - 1)) * h;
    vertex(cx + widths[i], y);
  }
  for (let i = n - 1; i >= 0; i--) {
    const y = baseY - (i / (n - 1)) * h;
    vertex(cx - widths[i], y);
  }
  endShape(CLOSE);

  stroke(107, 169, 221);
  strokeWeight(1.5);
  noFill();
  beginShape();
  for (let i = 0; i < n; i++) {
    const y = baseY - (i / (n - 1)) * h;
    vertex(cx + widths[i], y);
  }
  endShape();
  beginShape();
  for (let i = 0; i < n; i++) {
    const y = baseY - (i / (n - 1)) * h;
    vertex(cx - widths[i], y);
  }
  endShape();

  // inner mini box plot
  const q1y = baseY - 0.35 * h, q3y = baseY - 0.65 * h, medY = baseY - 0.5 * h;
  stroke(255, 211, 67);
  strokeWeight(6);
  line(cx, q1y, cx, q3y);
  strokeWeight(3);
  stroke(13, 17, 23);
  point(cx, medY);
  noStroke();
  fill(255, 211, 67);
  ellipse(cx, medY, 8, 8);

  fill(200);
  textSize(11);
  textAlign(CENTER, TOP);
  text("width = how common values are at that height", cx, 6);
  fill(255, 211, 67);
  text("inner box = quartiles", cx, baseY + 14);
}
```

## When to prefer violin vs box

- Use **box plots** for quick comparisons and outlier focus.
- Use **violin plots** when the distribution shape matters.
