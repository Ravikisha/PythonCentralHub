## Correlation recap

Correlation describes how two numeric variables move together.

- +1: strong positive relationship
- -1: strong negative relationship
- 0: no linear relationship

```mermaid title="From a DataFrame to a heatmap" desc="A correlation matrix is a square grid of numbers, which sns.heatmap turns into a grid of colors."
flowchart LR
  A["Numeric columns"] --> B["df.corr()<br/>(square correlation matrix)"]
  B --> C["sns.heatmap(corr)"]
  C --> D["Color grid<br/>(+ optional annot=True numbers)"]
```

:::caution
A heatmap's color scale is only as trustworthy as the correlation numbers behind it. Always fix
`vmin=-1, vmax=1` (as in the example below) so the color scale is comparable across different
plots — otherwise a weak correlation can look just as "hot" as a strong one if the colormap
auto-scales to a narrower range.
:::

## Correlation heatmap

```python title="Correlation heatmap" showLineNumbers{1}
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

penguins = sns.load_dataset("penguins").dropna()

corr = penguins[[
    "bill_length_mm",
    "bill_depth_mm",
    "flipper_length_mm",
    "body_mass_g",
]].corr()

plt.figure(figsize=(6, 4))
sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1)
plt.title("Penguins correlation")
plt.tight_layout()
plt.show()
```

## Visualize it

Each cell's color encodes a correlation value from -1 to +1 — amber for strong positive, blue for
strong negative, and dim in the middle for near zero:

```p5 title="Correlation matrix as a color grid" desc="Each cell's shade encodes its correlation value: amber for positive, blue for negative, dim for near zero." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const labels = ["bill_len", "bill_dep", "flip_len", "mass"];
  const matrix = [
    [1.00, -0.24, 0.66, 0.60],
    [-0.24, 1.00, -0.58, -0.47],
    [0.66, -0.58, 1.00, 0.87],
    [0.60, -0.47, 0.87, 1.00],
  ];
  const n = labels.length;
  const cell = 48, left = 130, top = 40;

  for (let r = 0; r < n; r++) {
    for (let c = 0; c < n; c++) {
      const v = matrix[r][c];
      const x = left + c * cell, y = top + r * cell;
      let col;
      if (v >= 0) {
        col = lerpColor(color(20, 24, 30), color(255, 211, 67), v);
      } else {
        col = lerpColor(color(20, 24, 30), color(75, 139, 190), -v);
      }
      noStroke();
      fill(col);
      rect(x, y, cell - 2, cell - 2);
      fill(255);
      textAlign(CENTER, CENTER);
      textSize(10);
      text(v.toFixed(2), x + cell / 2, y + cell / 2);
    }
  }

  fill(200);
  textSize(9);
  for (let i = 0; i < n; i++) {
    textAlign(RIGHT, CENTER);
    text(labels[i], left - 8, top + i * cell + cell / 2);
    textAlign(CENTER, BOTTOM);
    text(labels[i], left + i * cell + cell / 2, top - 6);
  }
}
```

## Tips

- Correlation is not causation.
- Outliers can inflate correlations.
- For non-linear relationships, correlation can be misleading.
