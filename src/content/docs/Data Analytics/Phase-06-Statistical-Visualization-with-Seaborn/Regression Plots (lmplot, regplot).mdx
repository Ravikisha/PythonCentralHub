## Why regression plots?

Regression plots help you see:

- Trend direction
- Strength of relationship (visual)
- Outliers that affect the trend

```mermaid title="What regplot draws" desc="regplot combines a scatter plot with a fitted line and a shaded confidence band around it."
flowchart LR
  A["x, y columns"] --> B["Scatter every point"]
  A --> C["Fit a regression line<br/>(linear by default)"]
  C --> D["Shade a confidence<br/>band around the line"]
  B --> E["regplot figure"]
  D --> E
```

:::tip[From the book]
McKinney uses `sns.regplot(x=\"m1\", y=\"unemp\", data=trans_data)` to check the relationship between
two macroeconomic series — "seaborn's `regplot` method... makes a scatter plot and fits a linear
regression line." It's a fast way to eyeball whether two numeric columns move together before
building anything more formal.
:::

## `regplot` (axes-level)

```python title="regplot" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.regplot(data=tips, x="total_bill", y="tip")
plt.title("Tip vs total bill")
plt.tight_layout()
plt.show()
```

## `lmplot` (figure-level, great for facets)

```python title="lmplot" showLineNumbers{1}
import seaborn as sns

tips = sns.load_dataset("tips")

sns.lmplot(data=tips, x="total_bill", y="tip", hue="sex")
```

## Visualize it

The line summarizes the overall trend; the shaded band shows how confident the fit is — narrower
where data is dense, wider near the edges:

```p5 title="Scatter plot with a fitted trend line" desc="Dots are individual data points; the blue line is the fitted trend, with a soft confidence band around it." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const left = 60, top = 30, w = 500, h = 190;
  const baseY = top + h;

  stroke(60, 68, 80);
  line(left, baseY, left + w, baseY);
  line(left, top, left, baseY);

  // pseudo-random scattered points around a rising trend
  const seed = 7;
  noStroke();
  fill(255, 211, 67, 210);
  const pts = [];
  for (let i = 0; i < 28; i++) {
    const x = left + (i / 27) * w;
    const noise = (Math.sin(i * 12.9898 + seed) * 43758.5453) % 1;
    const y = baseY - (i / 27) * h * 0.75 - noise * 40 - 20;
    pts.push([x, y]);
    ellipse(x, y, 7, 7);
  }

  // confidence band
  noStroke();
  fill(75, 139, 190, 45);
  beginShape();
  for (let i = 0; i <= 27; i++) {
    const x = left + (i / 27) * w;
    const trendY = baseY - (i / 27) * h * 0.75 - 20;
    const band = 10 + Math.abs(i - 13.5) * 1.6;
    vertex(x, trendY - band);
  }
  for (let i = 27; i >= 0; i--) {
    const x = left + (i / 27) * w;
    const trendY = baseY - (i / 27) * h * 0.75 - 20;
    const band = 10 + Math.abs(i - 13.5) * 1.6;
    vertex(x, trendY + band);
  }
  endShape(CLOSE);

  // fitted line
  stroke(75, 139, 190);
  strokeWeight(2.5);
  line(left, baseY - 20, left + w, baseY - h * 0.75 - 20);

  fill(200);
  noStroke();
  textSize(11);
  textAlign(LEFT, TOP);
  text("dots = data points", left, 4);
  fill(107, 169, 221);
  text("line + band = fitted trend + confidence", left + 200, 4);
}
```

## Non-linear patterns

You can try polynomial fits.

```python title="Polynomial fit" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

plt.figure(figsize=(7, 4))
sns.regplot(data=tips, x="total_bill", y="tip", order=2)
plt.title("Quadratic trend")
plt.tight_layout()
plt.show()
```

## Tips

- Regression plots show association, not causation.
- Outliers can heavily affect the fitted line.
- Use transformations (log) if relationships are multiplicative.
