## What are facet grids?

Facet grids create **small multiples**:

- The same plot repeated for different subgroups
- Helps compare patterns across segments

Examples:

- Distribution by gender
- Trend by region
- Relationship by category

```mermaid title="How a facet grid is laid out" desc="One category maps to columns, another (optional) maps to rows, and the same plot type is repeated in every cell."
flowchart LR
  A["Dataset"] --> B["Split by col="]
  A --> C["Split by row= (optional)"]
  B --> D["One subplot<br/>per column value"]
  C --> D
  D --> E["Same plot type<br/>repeated in each cell"]
```

:::tip[From the book]
McKinney uses `sns.catplot(x=\"day\", y=\"tip_pct\", hue=\"time\", col=\"smoker\", kind=\"bar\", data=tips)`
to compare tipping across day, time, and smoker status all at once — "`catplot` supports other
plot types... For example, box plots... can be an effective visualization type." Swapping `row=`
in for (or alongside) `col=` expands the grid to two dimensions.
:::

## Facet with `displot`

```python title="Facet distribution" showLineNumbers{1}
import seaborn as sns

tips = sns.load_dataset("tips")

sns.displot(data=tips, x="total_bill", col="time", bins=20, kde=True)
```

## Facet with `relplot`

```python title="Facet relationship" showLineNumbers{1}
import seaborn as sns

tips = sns.load_dataset("tips")

sns.relplot(data=tips, x="total_bill", y="tip", col="time", hue="sex")
```

## Using `FacetGrid` directly

```python title="FacetGrid" showLineNumbers{1}
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

g = sns.FacetGrid(tips, col="time", row="sex")
g.map_dataframe(sns.scatterplot, x="total_bill", y="tip")

plt.tight_layout()
```

## Visualize it

Each small panel is the same chart type, just filtered to one combination of row/column
categories — easy to compare shapes side by side:

```p5 title="A facet grid of small multiples" desc="Each cell repeats the same chart type for one row/column combination, making side-by-side comparison easy." height="280"
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const cols = ["Lunch", "Dinner"];
  const rows = ["No", "Yes"];
  const cellW = 240, cellH = 110, gap = 16;
  const left = 90, top = 40;

  // synthetic bar heights per facet, per day (4 bars each)
  const data = [
    [[30, 40, 55, 45], [20, 35, 60, 50]],
    [[25, 45, 65, 58], [40, 30, 70, 62]],
  ];

  for (let r = 0; r < rows.length; r++) {
    for (let c = 0; c < cols.length; c++) {
      const x0 = left + c * (cellW + gap);
      const y0 = top + r * (cellH + gap);

      noFill();
      stroke(60, 68, 80);
      rect(x0, y0, cellW, cellH);

      const bars = data[r][c];
      const barW = cellW / bars.length;
      const maxV = 80;
      noStroke();
      fill(255, 211, 67, 200);
      for (let i = 0; i < bars.length; i++) {
        const h = (bars[i] / maxV) * (cellH - 10);
        rect(x0 + i * barW + 4, y0 + cellH - h - 4, barW - 8, h);
      }

      fill(200);
      textSize(10);
      textAlign(CENTER, BOTTOM);
      text(`smoker=${rows[r]}, time=${cols[c]}`, x0 + cellW / 2, y0 - 4);
    }
  }

  fill(107, 169, 221);
  textAlign(LEFT, TOP);
  textSize(11);
  text("col = time, row = smoker — same bar chart in every cell", left, 8);
}
```

## Tips

- Facets can get crowded—keep category counts small.
- Facets are excellent for storytelling and comparisons.
