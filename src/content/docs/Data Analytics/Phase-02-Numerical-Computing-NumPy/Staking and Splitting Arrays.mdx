## Combining arrays

### `np.concatenate`

Concatenate along an axis.

```python title="concat" showLineNumbers{1}
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(np.concatenate([a, b]))
```

For 2D arrays:

```python title="concat2d" showLineNumbers{1}
import numpy as np

a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])

print(np.concatenate([a, b], axis=0))  # stack rows
print(np.concatenate([a, b], axis=1))  # stack cols
```

### `np.vstack` and `np.hstack`

```python title="vstack-hstack" showLineNumbers{1}
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(np.vstack([a, b]))
print(np.hstack([a, b]))
```

### `np.stack` (adds a new axis)

Unlike `concatenate`, `stack` creates a brand-new axis instead of joining along an existing one.

```python title="stack" showLineNumbers{1}
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(np.stack([a, b], axis=0).shape)  # (2, 3)
print(np.stack([a, b], axis=1).shape)  # (3, 2)
```

```p5 title="Stacking two rows, then splitting back apart" desc="vstack joins two 1D arrays into rows of a matrix; split cuts a matrix back into the original pieces." height="280"
function setup() {
  createCanvas(600, 280);

    fill(75, 139, 190, 30);

    fill(255);

  }
  for (let c = 0; c < 3; c++) {
    stroke(255, 211, 67);
    strokeWeight(1);
    fill(255, 211, 67, 30);
    rect(30 + c * cell, 35 + cell + 10, cell, cell);
    fill(255);
    noStroke();
    textAlign(CENTER, CENTER);
    text(b[c], 30 + c * cell + cell / 2, 35 + cell + 10 + cell / 2);
  }

  // arrow down
  stroke(180);
  strokeWeight(1);
  line(30 + 1.5 * cell, 35 + 2 * cell + 20, 30 + 1.5 * cell, 35 + 2 * cell + 40);
  line(30 + 1.5 * cell, 35 + 2 * cell + 40, 25 + 1.5 * cell, 35 + 2 * cell + 32);
  line(30 + 1.5 * cell, 35 + 2 * cell + 40, 35 + 1.5 * cell, 35 + 2 * cell + 32);

  }
}
```

## Splitting arrays

### `np.split`

```python title="split" showLineNumbers{1}
import numpy as np

arr = np.arange(10)
a, b = np.split(arr, [6])
print(a)
print(b)
```

### `np.hsplit` and `np.vsplit`

```python title="hsplit-vsplit" showLineNumbers{1}
import numpy as np

mat = np.arange(16).reshape(4, 4)
left, right = np.hsplit(mat, 2)
print(left)
print(right)

top, bottom = np.vsplit(mat, 2)
print(top)
print(bottom)
```

:::caution
Split points must match the array dimensions.
For example, you can't `hsplit` a 4-column matrix into 3 equal parts.
:::

