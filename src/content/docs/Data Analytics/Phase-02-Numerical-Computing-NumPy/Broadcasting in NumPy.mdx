## What is broadcasting?

**Broadcasting** is NumPy's ability to perform operations on arrays with different shapes by automatically expanding (virtually) smaller arrays.

This is a major reason NumPy code is concise and fast. Nothing is actually copied in memory — NumPy just repeats the smaller array's values as if it were stretched to fit, without allocating that extra memory.

## Simple example: add scalar

```python title="scalar" showLineNumbers{1}
import numpy as np

arr = np.array([1, 2, 3])
print(arr + 10)  # [11 12 13]
```

Here, the scalar `10` is broadcast to match the shape `(3,)`.

## Example: add vector to matrix

```python title="vector-matrix" showLineNumbers{1}
import numpy as np

mat = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
vec = np.array([10, 20, 30])

print(mat + vec)
```

`vec` (shape `(3,)`) broadcasts across each row.

```p5 title="Broadcasting a row vector across a matrix" desc="The (3,) vector is virtually stretched down to match every row of the (2, 3) matrix — no extra memory is actually allocated." height="260"
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  noLoop();
}

function draw() {
  background(13, 17, 23);
  const cell = 60;
  const mat = [[1, 2, 3], [4, 5, 6]];
  const vec = [10, 20, 30];
  const matX = 60, matY = 80;
  const vecX = 60, vecY = 20;

  fill(255, 211, 67);
  noStroke();
  textAlign(LEFT, CENTER);
  textSize(13);
  text("vec (shape 3,) stretches down:", 260, 30);

  // vector row (the thing being broadcast)
  for (let c = 0; c < 3; c++) {
    let x = matX + c * cell;
    stroke(255, 211, 67);
    strokeWeight(2);
    fill(255, 211, 67, 40);
    rect(x, vecY, cell, cell);
    fill(255);
    noStroke();
    textAlign(CENTER, CENTER);
    text(vec[c], x + cell / 2, vecY + cell / 2);
  }

  // dashed stretch lines down to each matrix row
  stroke(255, 211, 67, 120);
  strokeWeight(1);
  drawingContext.setLineDash([4, 4]);
  for (let c = 0; c < 3; c++) {
    let x = matX + c * cell + cell / 2;
    line(x, vecY + cell, x, matY + cell * 2);
  }
  drawingContext.setLineDash([]);

  // matrix
  for (let r = 0; r < 2; r++) {
    for (let c = 0; c < 3; c++) {
      let x = matX + c * cell;
      let y = matY + r * cell;
      stroke(75, 139, 190);
      strokeWeight(1);
      fill(75, 139, 190, 25);
      rect(x, y, cell, cell);
      fill(255);
      noStroke();
      textAlign(CENTER, CENTER);
      text(mat[r][c], x + cell / 2, y + cell / 2);
    }
  }

  fill(180);
  noStroke();
  textAlign(LEFT, CENTER);
  textSize(12);
  text("mat (2, 3) + vec (3,)  ->  result (2, 3)", 60, 230);
}
```

## Broadcasting rules (must know)

When operating on two arrays, NumPy compares shapes from the **trailing dimension** (rightmost first) and works backward.

Two dimensions are compatible when:

1. They are equal, OR
2. One of them is `1`

If dimensions are incompatible → broadcasting error.

## Example: column vector + matrix

```python title="column" showLineNumbers{1}
import numpy as np

mat = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
col = np.array([100, 200]).reshape(2, 1)

print(mat + col)
```

`col` has shape `(2, 1)` and broadcasts across columns.

## Common broadcasting error

```python title="error" showLineNumbers{1}
import numpy as np

mat = np.zeros((2, 3))
vec = np.array([1, 2])

# mat + vec -> ValueError (shapes (2,3) and (2,) not compatible)
```

Fix by reshaping `vec` to a column vector if that's what you intend:

```python title="fix" showLineNumbers{1}
vec = vec.reshape(2, 1)
print(mat + vec)
```

:::caution[From the book]
McKinney treats broadcasting as one of NumPy's most powerful — and most confusing — features. The rule to memorize: compare shapes from the *last* axis backward; each pair of axis sizes must be equal or one of them must be `1`. When you hit a `ValueError`, it's almost always a shape mismatch on a non-trailing axis that needs a `reshape` or `[:, None]`.
:::


## Why broadcasting is useful in analytics

- Normalize columns: `X / X.max(axis=0)`
- Center data: `X - X.mean(axis=0)`
- Apply weights: `X * weights`
