## Understanding shape

`shape` tells the size of each dimension.

```python title="shape" showLineNumbers{1}
import numpy as np

arr = np.array([[1, 2, 3], [4, 5, 6]])
print(arr.shape)  # (2, 3)
```

## Reshape with `.reshape()`

Reshape changes the dimension layout **without changing the underlying data or copying it** — it just reinterprets the same flat block of memory with a new shape.

```python title="reshape" showLineNumbers{1}
import numpy as np

arr = np.arange(1, 13)  # 1..12
mat = arr.reshape(3, 4) # 3 rows, 4 cols
print(mat)
```

```p5 title="Reshaping (3, 4) into (4, 3)" desc="The same 12 values, read out in the same order, just wrapped into a different grid shape." height="260"
}

function drawGrid(originX, originY, cols, rows, cell, values) {
  let i = 0;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {

      let y = originY + r * cell;

    }
  }
}
```

### Using `-1` (auto infer)

```python title="reshape-auto" showLineNumbers{1}
import numpy as np

arr = np.arange(12)
mat = arr.reshape(3, -1)
print(mat.shape)  # (3, 4)
```

:::caution
The total size must match.
If the array has 12 elements, only shapes that multiply to 12 are valid.
:::

## Flattening arrays

### `.ravel()` (often a view)

```python title="ravel" showLineNumbers{1}
import numpy as np

mat = np.array([[1, 2], [3, 4]])
flat = mat.ravel()
print(flat)
```

### `.flatten()` (always copy)

```python title="flatten" showLineNumbers{1}
import numpy as np

mat = np.array([[1, 2], [3, 4]])
flat = mat.flatten()
print(flat)
```

:::tip[From the book]
`.reshape()` and `.ravel()` return **views** whenever possible — no data is copied. `.flatten()` always makes a copy. If you only need to read the flattened data (not mutate it), `.ravel()` is the cheaper choice.
:::

## Add or remove dimensions

### `np.newaxis` / `None`

Convert a 1D array into a column vector:

```python title="newaxis" showLineNumbers{1}
import numpy as np

arr = np.array([1, 2, 3])
col = arr[:, None]
print(col)
print(col.shape)  # (3, 1)
```

### `np.expand_dims`

```python title="expand" showLineNumbers{1}
import numpy as np

arr = np.array([1, 2, 3])
arr2 = np.expand_dims(arr, axis=0)
print(arr2.shape)  # (1, 3)
```

### `np.squeeze` (remove size-1 dims)

```python title="squeeze" showLineNumbers{1}
import numpy as np

arr = np.array([[[1], [2], [3]]])
print(arr.shape)           # (1, 3, 1)
print(np.squeeze(arr).shape)  # (3,)
```

## Transpose (swap axes)

Transposing is a special case of reshaping — it also returns a view, never a copy.

For 2D:

```python title="transpose" showLineNumbers{1}
import numpy as np

mat = np.array([[1, 2, 3], [4, 5, 6]])
print(mat.T)
```

```mermaid title="Shape-changing toolbox" desc="Different tools for growing, shrinking, or rearranging dimensions without touching the underlying data."

  A["ndarray"] --> B["reshape(r, c)<br/>same data, new grid"]
  A --> C["ravel() / flatten()<br/>collapse to 1D"]

```
