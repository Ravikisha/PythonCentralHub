## What is a dtype?

A **dtype** (data type) tells NumPy what kind of values an array contains, such as:

- integers (`int32`, `int64`)
- floats (`float32`, `float64`)
- booleans (`bool`)
- strings (`<U...`) and bytes (`|S...`)

Because NumPy uses a single dtype for the entire array, it can store values efficiently and run fast computations. A dtype name is really just a hint about memory layout: a type name (`int`, `float`) followed by the number of bits per element. A standard double-precision float takes 8 bytes (64 bits) — hence `float64`.

```mermaid title="How NumPy infers a dtype" desc="numpy.array walks the input data once and picks the narrowest common dtype that can hold every value."
flowchart TD
  A["np.array(data)"] --> B{"All values<br/>the same kind?"}
  B -- "All ints" --> C["dtype: int64"]
  B -- "Any float present" --> D["dtype: float64"]
  B -- "Any string present" --> E["dtype: string / object"]
  B -- "Explicit dtype= given" --> F["Use that dtype<br/>(cast or error)"]
```

## Checking dtype

```python title="check" showLineNumbers{1}
import numpy as np

arr = np.array([1, 2, 3])
print(arr.dtype)
```

## Common numeric dtypes

### Integers

```python title="ints" showLineNumbers{1}
a = np.array([1, 2, 3], dtype=np.int32)
b = np.array([1, 2, 3], dtype=np.int64)
print(a.dtype, b.dtype)
```

### Floats

```python title="floats" showLineNumbers{1}
a = np.array([1.5, 2.0, 3.25], dtype=np.float32)
b = np.array([1.5, 2.0, 3.25], dtype=np.float64)
print(a.dtype, b.dtype)
```

:::note
There are both **signed** and **unsigned** integer types. A signed integer (like `int8`) can represent negative and positive numbers (-128 to 127). An unsigned integer (`uint8`) only represents 0 and up (0 to 255) — the same 256 possible values, just shifted.
:::

## Memory usage and dtype

Smaller dtypes use less memory. Every element in a `float32` array takes 4 bytes; every element in a `float64` array takes 8 bytes — double the space for the same number of values.

```python title="memory" showLineNumbers{1}
import numpy as np

arr32 = np.ones(1_000_000, dtype=np.float32)
arr64 = np.ones(1_000_000, dtype=np.float64)

print("float32 bytes:", arr32.nbytes)
print("float64 bytes:", arr64.nbytes)
```

```p5 title="Memory layout: int8 vs int64" desc="Each block is one byte. A single int64 element takes as much memory as eight int8 elements." height="240"
function setup() {
  createCanvas(600, 240);
  textFont("monospace");

function draw() {
  background(13, 17, 23);
  const cell = 26;
  const gap = 4;

  fill(255, 211, 67);
  textSize(14);
  text("int8  (1 byte per element)", 20, 40);

  // Row of 8 separate int8 elements, each 1 byte
  for (let i = 0; i < 8; i++) {
    let x = 20 + i * (cell + gap);
    stroke(75, 139, 190);
    strokeWeight(1);
    fill(75, 139, 190, 90);
    rect(x, 55, cell, cell, 4);
    fill(255);
    noStroke();
    textSize(11);
    text("1B", x + 5, 55 + cell / 2 + 4);
  }

  fill(255, 211, 67);
  textSize(14);
  text("int64 (8 bytes per element)", 20, 140);

  // One int64 element spanning 8 bytes, drawn as one block
  let x = 20;
  stroke(255, 211, 67);
  strokeWeight(2);
  fill(255, 211, 67, 60);

  fill(255);

  text("one int64 element = 8 bytes", x + 10, 155 + cell / 2 + 4);

}
```

## Type conversion

### Using `.astype()`

```python title="astype" showLineNumbers{1}
import numpy as np

arr = np.array([1, 2, 3])
arr_f = arr.astype(np.float64)
print(arr_f, arr_f.dtype)
```

:::note
`.astype()` **always** creates a new array (a copy), even if you cast to the same dtype it already has.
:::

### Safe conversion (avoid overflow)

Converting large values into a smaller dtype can overflow.

```python title="overflow" showLineNumbers{1}
import numpy as np

arr = np.array([300], dtype=np.int16)
print(arr.astype(np.uint8))  # wraps around in many cases
```

## Dtype pitfalls in data analytics

### 1) Missing values

NumPy numeric arrays can’t store `NaN` in integer dtype.

```python title="nan-int" showLineNumbers{1}
import numpy as np

# This will upcast to float automatically because of np.nan
arr = np.array([1, 2, np.nan])
print(arr)
print(arr.dtype)
```

### 2) Mixed types

If you mix strings and numbers, dtype may become `object` or strings.

```python title="mixed" showLineNumbers{1}
import numpy as np

arr = np.array([1, "two", 3])
print(arr)
print(arr.dtype)
```

Arrays with `dtype=object` are slower for numerical operations.

:::caution[From the book]
Be careful with NumPy's fixed-size string type (`numpy.string_` / `"S10"`). It truncates input silently if a string is longer than the declared size — no error, no warning. Pandas handles non-numeric data far more intuitively than raw NumPy.
:::
