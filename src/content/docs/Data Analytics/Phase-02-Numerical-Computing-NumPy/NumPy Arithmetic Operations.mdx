## Element-wise arithmetic

NumPy operations between equal-size arrays apply the operation **element-wise** — this is what the book calls "vectorization," and it's what lets you skip writing `for` loops.

```python title="elementwise" showLineNumbers{1}
import numpy as np

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

print(a + b)
print(a - b)
print(a * b)
print(a / b)
```

## Scalar operations

Arithmetic with a scalar propagates that value to every element in the array (this is broadcasting in its simplest form).

```python title="scalar" showLineNumbers{1}
import numpy as np

arr = np.array([1, 2, 3])
print(arr * 10)
print(arr + 0.5)
```

## Power and modulo

```python title="power" showLineNumbers{1}
import numpy as np

arr = np.array([2, 3, 4])
print(arr ** 2)  # [4 9 16]
print(arr % 2)   # [0 1 0]
```

## Comparisons

Comparisons produce boolean arrays, applied element-wise just like arithmetic.

```python title="compare" showLineNumbers{1}
import numpy as np

arr = np.array([10, 20, 30])
print(arr > 15)       # [False True True]
print(arr == 20)      # [False True False]
```

```mermaid title="Same array, four kinds of results" desc="Arithmetic, comparison, and aggregation all start from the same element-wise machinery but end in different shapes."
flowchart LR
  A["Two equal-shape arrays"] --> B["Arithmetic (+ - * /)<br/>-> same-shape array"]
  A --> C["Comparison (> == <)<br/>-> boolean array"]
  A --> D["Aggregation (.sum/.mean)<br/>-> scalar or lower-dim array"]
  E["Two 2D arrays"] --> F["Matrix multiply (@)<br/>-> new matrix, NOT element-wise"]
```

## Aggregations (sum, mean, min, max)

```python title="agg" showLineNumbers{1}
import numpy as np

mat = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(mat.sum())          # sum of all
print(mat.sum(axis=0))    # column sums
print(mat.sum(axis=1))    # row sums

print(mat.mean(axis=0))
print(mat.min(axis=1))
print(mat.max(axis=1))
```

:::tip[From the book]
Read `axis=0` as "collapse the rows, keep one value per column" and `axis=1` as "collapse the columns, keep one value per row." So `mat.sum(axis=0)` is a column-wise sum, and `mat.sum(axis=1)` is a row-wise sum — the axis you name is the one that disappears.
:::

## Matrix multiplication vs element-wise multiplication

### Element-wise multiplication

`*` multiplies matching positions — it is **not** the same as matrix multiplication.

```python title="mul" showLineNumbers{1}
import numpy as np

a = np.array([[1, 2], [3, 4]])
b = np.array([[10, 20], [30, 40]])
print(a * b)
```

### Matrix multiplication

Use `@` operator or `np.matmul`.

```python title="matmul" showLineNumbers{1}
import numpy as np

a = np.array([[1, 2], [3, 4]])
b = np.array([[10, 20], [30, 40]])
print(a @ b)
```

## Rounding

```python title="rounding" showLineNumbers{1}
import numpy as np

arr = np.array([1.234, 5.678])
print(np.round(arr, 2))
print(np.floor(arr))
print(np.ceil(arr))
```
