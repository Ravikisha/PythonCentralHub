## When to reach for a line chart

A line chart is the go-to shape for **change over an ordered axis** — almost always time (days, months, years). The line itself draws attention to *trend*: is the metric rising, falling, or flat? Markers on top of the line let you also read off exact points without losing the trend shape.

## Basic interactive line

```python title="Interactive line" showLineNumbers{1}
import pandas as pd
import plotly.express as px

df = pd.DataFrame({
    "date": pd.date_range("2025-01-01", periods=7, freq="D"),
    "orders": [120, 140, 130, 160, 155, 170, 180],
})

fig = px.line(df, x="date", y="orders", markers=True, title="Daily orders")
fig.show()
```

Because this is Plotly (not Matplotlib), the rendered chart already lets you hover each marker for its exact date/value, drag to zoom into a date range, and double-click to reset.

## Multiple lines (color)

```python title="Multiple lines" showLineNumbers{1}
import pandas as pd
import plotly.express as px

df = pd.DataFrame({
    "date": list(pd.date_range("2025-01-01", periods=5, freq="D")) * 2,
    "orders": [120, 140, 130, 160, 155, 100, 110, 120, 125, 140],
    "product": ["A"] * 5 + ["B"] * 5,
})

fig = px.line(df, x="date", y="orders", color="product", markers=True, title="Orders by product")
fig.show()
```

Passing `color="product"` does two things at once: it splits the data into one line per group, *and* it adds a legend you can click to hide/show a series.

```p5 title="A line chart, traced point by point" desc="The line connects ordered points on an x-axis; the traveling dot mimics hovering along the series." height="260"
let pts = [];
function setup() {
  createCanvas(600, 260);
  textFont("monospace");
  pts = [120, 140, 130, 160, 155, 170, 180];
}
function draw() {
  background(13, 17, 23);
  const padL = 50, padR = 30, padT = 30, padB = 40;
  const w = width - padL - padR, h = height - padT - padB;
  const lo = 100, hi = 190;

  // axes
  stroke(90);
  strokeWeight(1);
  line(padL, padT, padL, padT + h);
  line(padL, padT + h, padL + w, padT + h);

  // grid + line
  noFill();
  stroke(75, 139, 190);
  strokeWeight(2.5);
  beginShape();
  const coords = [];
  for (let i = 0; i < pts.length; i++) {
    const x = padL + (i / (pts.length - 1)) * w;
    const y = padT + h - ((pts[i] - lo) / (hi - lo)) * h;
    coords.push({ x, y, v: pts[i] });
    vertex(x, y);
  }
  endShape();

  // markers
  for (const c of coords) {
    fill(255, 211, 67);
    noStroke();
    circle(c.x, c.y, 7);
  }

  // traveling "hover" dot along the line
  const t = (frameCount * 0.6) % (pts.length - 1);
  const i0 = floor(t), frac = t - i0;
  const a = coords[i0], b = coords[min(i0 + 1, coords.length - 1)];
  const hx = lerp(a.x, b.x, frac), hy = lerp(a.y, b.y, frac);
  const hv = lerp(a.v, b.v, frac);
  fill(255);
  noStroke();
  circle(hx, hy, 10);
  textAlign(CENTER, BOTTOM);
  textSize(12);
  fill(255, 211, 67);
  text(nf(hv, 0, 0), hx, hy - 12);

  fill(180);
  textAlign(LEFT, TOP);
  textSize(11);
  text("orders over 7 days", padL, 6);
}
```

## Tips

- Use `hover_data=[...]` to show extra fields (e.g. region, channel) in the tooltip.
- Use `fig.update_layout(...)` for axis labels, margins, and legend position.
- Sort your DataFrame by the x-axis column first — Plotly draws points in row order, so an unsorted date column produces a zig-zag line.

:::tip[Analyst's tip]
A line chart implies *continuity* between points — the eye reads the connecting segment as "what probably happened in between." Only connect points that are genuinely on the same continuous axis (like consecutive days); connecting unrelated categories with a line invents a trend that isn't there. That's what bar charts are for.
:::
