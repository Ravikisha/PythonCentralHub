## When to reach for a scatter plot

A scatter plot answers "how do these two numeric variables relate?" Each point is one row of data, positioned by two measurements at once. Add `color` for a third variable (a category) and `size` for a fourth (a number) — a scatter plot can honestly encode more information per point than almost any other chart type.

## Basic scatter

```python title="Interactive scatter" showLineNumbers{1}
import pandas as pd
import plotly.express as px

df = pd.DataFrame({
    "hours": [1, 2, 3, 4, 5, 6, 7, 2, 4, 6],
    "score": [50, 55, 65, 70, 75, 78, 85, 52, 69, 77],
    "group": ["A", "A", "A", "A", "A", "A", "A", "B", "B", "B"],
})

fig = px.scatter(df, x="hours", y="score", color="group", title="Hours vs score")
fig.show()
```

Every point is hoverable by default — Plotly shows `x`, `y`, and `color` for whichever point the cursor is nearest, with zero extra code.

## Add trend line

```python title="Trend line" showLineNumbers{1}
import plotly.express as px

fig = px.scatter(df, x="hours", y="score", color="group", trendline="ols", title="Trend line")
fig.show()
```

`trendline="ols"` fits an ordinary-least-squares regression line per color group and draws it on top — a quick way to see if a relationship looks roughly linear (requires `statsmodels` installed).

```p5 title="Scatter plot — hover finds the nearest point" desc="Move your mouse near any dot; the closest point locks on and shows its (x, y) values, like a Plotly tooltip." height="280"
const pts = [
  { x: 1, y: 50 }, { x: 2, y: 55 }, { x: 3, y: 65 }, { x: 4, y: 70 },
  { x: 5, y: 75 }, { x: 6, y: 78 }, { x: 7, y: 85 }, { x: 2, y: 52 },
  { x: 4, y: 69 }, { x: 6, y: 77 },
];
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
}
function toScreen(p) {
  const padL = 50, padR = 30, padT = 30, padB = 40;
  const w = width - padL - padR, h = height - padT - padB;
  const x = padL + ((p.x - 1) / 6) * w;
  const y = padT + h - ((p.y - 50) / 35) * h;
  return { x, y };
}
function draw() {
  background(13, 17, 23);
  const padL = 50, padT = 30, padB = 40;
  const w = width - padL - 30, h = height - padT - padB;

  stroke(90);
  line(padL, padT, padL, padT + h);
  line(padL, padT + h, padL + w, padT + h);

  let nearest = -1, bestD = Infinity;
  const screenPts = pts.map(toScreen);
  for (let i = 0; i < screenPts.length; i++) {
    const d = dist(mouseX, mouseY, screenPts[i].x, screenPts[i].y);
    if (d < bestD) { bestD = d; nearest = i; }
  }
  const hovering = bestD < 200 && mouseX > 0 && mouseY > 0;

  for (let i = 0; i < screenPts.length; i++) {
    const s = screenPts[i];
    const isNear = hovering && i === nearest;
    noStroke();
    fill(isNear ? color(255, 211, 67) : color(75, 139, 190, 200));
    circle(s.x, s.y, isNear ? 14 : 9);
  }

  if (hovering) {
    const s = screenPts[nearest];
    const p = pts[nearest];
    fill(255);
    textAlign(LEFT, BOTTOM);
    textSize(12);
    text("(" + p.x + ", " + p.y + ")", s.x + 10, s.y - 8);
  }

  fill(150);
  textAlign(LEFT, TOP);
  textSize(11);
  text("hours vs score", padL, 6);
}
```

## Tips

- Use `hover_data=[...]` to show more context (e.g. a name or ID column) in the tooltip.
- Trend lines can be sensitive to outliers — a single extreme point can tilt the whole fitted line.
- If points overlap heavily, lower `opacity` or switch to a 2D density/contour plot.

:::tip[Analyst's tip]
Correlation shown by a trend line is not causation — and a fitted line can look convincing even on random data with a small sample size. Always check the point cloud *around* the line, not just the line itself, before trusting the relationship it implies.
:::
