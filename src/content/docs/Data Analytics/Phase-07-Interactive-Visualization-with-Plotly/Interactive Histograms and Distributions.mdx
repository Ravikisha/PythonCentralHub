## Why interactive distributions

A histogram answers "how are these values spread out?" by grouping numbers into bins and counting how many fall in each. Interactive distributions help you:

- zoom into interesting ranges (drag across a busy region of bars)
- inspect outliers (hover a thin bar far from the rest)
- compare groups with hover tooltips (see the exact count per bin, per category)

## Histogram

```python title="Histogram" showLineNumbers{1}
import pandas as pd
import plotly.express as px

df = px.data.tips()

fig = px.histogram(
    df,
    x="total_bill",
    nbins=30,
    title="Total bill distribution",
)
fig.show()
```

`nbins` controls how many bins the range is split into — too few bins hide structure (everything looks like one lump), too many bins make the shape noisy (every bar is its own spike).

## Histogram by category

```python title="Histogram by sex" showLineNumbers{1}
import plotly.express as px

df = px.data.tips()

fig = px.histogram(
    df,
    x="total_bill",
    color="sex",
    nbins=25,
    barmode="overlay",
    opacity=0.6,
    title="Total bill distribution by sex",
)
fig.show()
```

`barmode="overlay"` stacks both distributions on top of each other (instead of side by side); lowering `opacity` lets you see where the two overlap.

```p5 title="A histogram is a bar chart of counts per bin" desc="Raw values are grouped into equal-width bins; bar height = how many values landed in that bin." height="280"
const values = [12, 15, 14, 18, 20, 22, 19, 25, 30, 28, 24, 21, 17, 16, 33, 35, 27, 23, 20, 19, 26, 31, 18, 22, 24];
const bins = 8;
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const lo = Math.min(...values), hi = Math.max(...values);
  const binW = (hi - lo) / bins;
  const counts = new Array(bins).fill(0);
  for (const v of values) {
    let idx = Math.floor((v - lo) / binW);
    if (idx >= bins) idx = bins - 1;
    counts[idx]++;
  }
  const maxCount = Math.max(...counts);

  const padL = 50, padB = 45, padT = 30;
  const w = width - padL - 30, h = height - padT - padB;
  const barW = w / bins;

  stroke(90);
  line(padL, padT, padL, padT + h);
  line(padL, padT + h, padL + w, padT + h);

  for (let i = 0; i < bins; i++) {
    const bh = (counts[i] / maxCount) * h;
    const x = padL + i * barW;
    const y = padT + h - bh;
    noStroke();
    fill(75, 139, 190, 210);
    rect(x + 2, y, barW - 4, bh);
    fill(255, 211, 67);
    textAlign(CENTER, BOTTOM);
    textSize(11);
    text(counts[i], x + barW / 2, y - 4);
  }

  fill(150);
  textAlign(LEFT, TOP);
  textSize(11);
  text("bins=" + bins + ", each bar = count of values in that range", padL, 6);
}
```

## Box plot (interactive)

```python title="Interactive box plot" showLineNumbers{1}
import plotly.express as px

df = px.data.tips()

fig = px.box(df, x="day", y="total_bill", color="sex", title="Total bill by day")
fig.show()
```

A box plot summarizes a distribution's median, quartiles, and outliers in one compact shape — useful when you're comparing *many* groups and a full histogram per group would be too much to look at.

## Tip

Start with a histogram, then add:

- category color
- hover fields
- facet columns/rows

:::tip[Analyst's tip]
Bin count is not a neutral choice — the same data can look unimodal or bimodal depending purely on `nbins`. Try a few bin counts before drawing conclusions about the shape of a distribution, and don't cherry-pick the one that best fits a story you already believe.
:::
