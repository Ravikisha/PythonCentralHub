## Two ways to create multi-plot layouts

1. **Facets (Plotly Express)**: easiest for grid layouts — one line of code repeats the *same* chart across a category, split into a grid of small panels ("small multiples").
2. **Subplots (`plotly.subplots`)**: full control — you place arbitrary, even *different*, chart types into any grid cell yourself.

Facets are for "show me this one chart, once per group." Subplots are for "let me hand-place several different charts into one figure" (this is exactly what the dashboard page does).

## Facets with Plotly Express

```python title="Facet example" showLineNumbers{1}
import plotly.express as px

df = px.data.tips()

fig = px.scatter(
    df,
    x="total_bill",
    y="tip",
    color="sex",
    facet_col="day",
    title="Tips by day (facets)",
)
fig.show()
```

`facet_col="day"` splits the data by the `day` column and draws one scatter panel per unique day, all sharing the same axis scale — so panels are directly comparable side by side.

```p5 title="Small multiples: same chart, repeated per group" desc="Faceting draws one identical mini-chart per category, all on the same scale, side by side." height="280"
const groups = [
  { label: "Thu", pts: [[10, 2], [15, 3], [20, 3.5]] },
  { label: "Fri", pts: [[12, 2.5], [18, 2], [25, 4]] },
  { label: "Sat", pts: [[20, 4], [30, 5], [40, 6]] },
  { label: "Sun", pts: [[15, 3], [22, 3.5], [35, 5.5]] },
];
function setup() {
  createCanvas(600, 280);
  textFont("monospace");
  noLoop();
}
function draw() {
  background(13, 17, 23);
  const panelW = 130, panelH = 160, gap = 15, top = 40;
  const maxX = 40, maxY = 6;

  for (let i = 0; i < groups.length; i++) {
    const g = groups[i];
    const x0 = 20 + i * (panelW + gap);
    const y0 = top;

    stroke(70);
    strokeWeight(1);
    noFill();
    rect(x0, y0, panelW, panelH);

    for (const [px_, py_] of g.pts) {
      const x = x0 + (px_ / maxX) * panelW;
      const y = y0 + panelH - (py_ / maxY) * panelH;
      noStroke();
      fill(255, 211, 67);
      circle(x, y, 8);
    }

    fill(200);
    noStroke();
    textAlign(CENTER, TOP);
    textSize(12);
    text(g.label, x0 + panelW / 2, y0 + panelH + 8);
  }

  fill(150);
  textAlign(LEFT, TOP);
  textSize(11);
  text("facet_col splits one chart into a panel per category", 20, 10);
}
```

## Manual subplots

```python title="Subplots" showLineNumbers{1}
import plotly.graph_objects as go
from plotly.subplots import make_subplots

fig = make_subplots(rows=1, cols=2, subplot_titles=["A", "B"])

fig.add_trace(go.Scatter(x=[1, 2, 3], y=[1, 4, 9], mode="lines", name="line"), row=1, col=1)
fig.add_trace(go.Bar(x=["x", "y", "z"], y=[5, 2, 6], name="bar"), row=1, col=2)

fig.update_layout(title_text="Two plots in one figure")
fig.show()
```

Unlike facets, the two panels here don't have to share a scale, an x-axis meaning, or even a chart type — `make_subplots` just gives you a grid of independent plotting areas.

## Tips

- Use facets when you're comparing the same chart across categories on a shared scale.
- Use subplots when mixing chart types, or when panels genuinely measure different things.
- Too many facet panels (more than ~6-8) get cramped — consider filtering to the most important categories first.

:::tip[Analyst's tip]
Small multiples (facets) are one of the most underrated chart choices: because every panel shares the same axes and scale, the *panel-to-panel differences* become the story, and there's no legend to decode — the category label is right above each panel. Reach for facets before reaching for one crowded chart with 6 overlapping colors.
:::
